# 前期拆合:局内配方转盘 + 生疏 — design

日期:2026-10-19 ・ 状态:用户 10-19 审阅意见已并入(5 选 1 转盘、11 层起、每 10 层两档、高档 10%、生疏手牌标记、不做图鉴、不做仿真)
上游:用户 10-19 体验反馈「前期过渡差、耐玩性不足,前期拆合没有意义」;调研 `scratchpad/early-game-research.md`(结论摘入 Plan F)。
缺字(5 层后字库约 3 张)**不动**(用户 10-19)。

## 现状与根因(调研)
- 局内只能合「已收集字及其配方闭包」(`ForgeEngine.cs:133-163`)。新手 10 张字的配方几乎都是「五行偏旁 + 专属声旁」,拆了只能合回原字,还多花 1 AP。
- 起手部件物理上能拼出更高阶的字,全被收集闸挡住;奇遇送的 炎 / 冰 / 林 拆了合不回来。
- 战利品 / 掉字 / 商店都只出已收集的字,每局没有新东西。

## §1 局内配方集
- 新增本局状态 **配方集** `RunRecipes`(字 id 列表,进 `RunSnapshot` / 续爬存档,换局清空)。
  局内可合成集 = 原收集闭包 ∪ 配方集(只放开配方目标字本身,不连带它的上游叠字链)。
- 奇遇直接送的未收集字(测字先生 炎、墨池 冰、书院 林、残碑 鍂、字摊叠字)自动记入配方集 —— 拆了能合回来。
- 拆合台 / 合成预览按新可合成集显示,不新增交互。

## §2 配方转盘(5 选 1)
- **时机**:**5 层起**(用户 10-20 由 11 改 5;分档不变,5–10 层同 11–20 用 蓝 / 紫)的 Boss 层与精英层战后(掉落时机同现有 Boss / 精英战利品,不改现有战利品),先转配方转盘,再进原有选字。
- **转盘内容**:5 格配方,按层段取两档稀有度 —— 4 格低档 + 1 格高档:

  | 层 | 低档 ×4 | 高档 ×1 |
  |---|---|---|
  | 11–20 | 蓝 | 紫 |
  | 21–30 | 紫 | 金 |
  | 31–40 | 金 | 橙 |
  | 41 起 | 橙 | 红 |

- **结果**:转盘随机落一格 —— **高档格 10%**,4 个低档格各 22.5%。落中的配方进配方集(玩家不自选,「5 选 1」由转盘决定)。
  落中即**得一张该字进字库**(用户 10-21):未收集的同时进配方集并生疏,已收集的不生疏;字库满时关转盘后弹换字面板(换一张 / 不要了),挂起再进仍要决议。
- **候选**:该档里**未收集**且不在配方集里的字;优先「配方部件能从本局已收集字拆出凑齐」的(拿到就有机会合),不够再用同档其他未收集字补。
  未收集的不足时,从**同档**已收集 / 已在配方集的字随机补足,维持 5 格(用户 10-21;取代原「相邻低一档补」)。落在已收集字上不记配方、不生疏。该档整档无字时才少格,两档都无字时跳过转盘。
- 抽候选与转盘结果走带种子的独立随机流(不平移主随机序列)。
- 转盘 UI 交 `designer` 出稿(§4)。

## §3 生疏(防跃迁)
- 由转盘得到的配方目标字,合出来后在本局为 **生疏**:所有效果数值 ×70%,卡等级按 Lv1 计(不吃局外卡等级)。
  生疏字本局之后的战斗也进掉字牌组(回合掉字 + 斩获),掉下来照旧生疏,换局即清(用户 10-21)。
  奇遇送的未收集字也生疏(用户 10-20 改);已收集的字永不生疏。转盘配方不附送部件(用户 10-20:11–30 层合不出也不发)。
- 70% 与分档是起值,体验后再调(用户 10-19:不做仿真)。
- **手牌标记**:生疏字在手牌 / 字库卡面上要有标识,详情写「生疏:效果 ×70%,按 Lv1 计」—— 一并交 `designer`。

## §4 设计稿(交 designer)
1. 配方转盘:5 格(4 低档 + 1 高档,高档格视觉上明显、但不暗示 20% 面积 —— 面积与 10% 概率的关系由 designer 定,别误导)、转动与落定动效、结果卡(字形 + 配方部件 + 「已记入本局配方」)。两档屏比验算。
2. 生疏手牌标记 + 详情一行。
稿拍板前 Core 先行;Presentation 只做能编过的最小接线(转盘未落地前,结果用现有提示文案显示)。

## 不做
- 图鉴「已发现」(用户 10-19:不需要)。仿真 / 新手画像(用户 10-19:不做)。缺字 / 掉字数量。部件单独出手效果。侧向合字新字。
