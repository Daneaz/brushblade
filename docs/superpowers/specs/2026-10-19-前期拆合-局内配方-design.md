# 前期拆合:局内配方 + 生疏 — design

日期:2026-10-19 ・ 状态:待用户审阅
上游:用户 10-19 体验反馈「前期过渡差、耐玩性不足,前期拆合没有意义」;调研 `scratchpad/early-game-research.md`(结论摘入 Plan F)。
用户 10-19 拍板方向:「配方当局内战利品」+「未收集字局内打折」;缺字(5 层后字库约 3 张)**不动**;要同时顾可玩性与平衡(前期合出「林」不能变无敌)。

## 现状与根因(调研)
- 局内只能合「已收集字及其配方闭包」(`ForgeEngine.cs:133-163`)。新手 10 张字的配方几乎都是「五行偏旁 + 专属声旁」,拆了只能合回原字,还多花 1 AP。新手画像:合 0.3 次/局,16 次里 14 次是还原原字。
- 起手部件物理上能拼出 24 个更高阶字,全被收集闸挡住;奇遇送的 炎 / 冰 / 林 拆了合不回来。
- 战利品 / 掉字 / 商店都只出已收集的字,每局没有新东西。

## §1 局内配方
- 新增本局状态 **配方集** `RunRecipes`(字 id 列表,进 `RunSnapshot` / 续爬存档,换局清空)。局内可合成集 = 原收集闭包 ∪ 配方集(只放开配方目标字本身,不连带它的上游叠字链)。
- **来源 1 · 配方战利品**:Boss 层与精英层战后,在选字之前多一步「配方 三选一(可跳过)」。
  - 候选 = 未收集、且配方部件全部能从**本局已收集字拆出的部件**凑齐的字(保证「拿到就有机会合」),按稀有度分段放开:
    1–10 层 ≤ 紫;11–30 层 ≤ 金;31 层起 ≤ 橙;红不出。候选不足 3 个时有几个出几个,0 个时跳过这一步。
  - 抽取走带种子的独立随机流(不平移主随机序列)。
- **来源 2 · 奇遇送字**:奇遇直接送的未收集字(测字先生 炎、墨池 冰、书院 林、残碑 鍂、字摊叠字)自动记入配方集 —— 拆了能合回来。
- 拆合台 / 合成预览按新可合成集显示,不新增交互。

## §2 生疏(防前期跃迁)
- 由「配方战利品」得到的配方目标字,合出来后在本局为 **生疏**:所有效果数值 ×70%,卡等级按 Lv1 计(不吃局外卡等级)。
  奇遇送的字不生疏(维持原强度)。已收集的字永不生疏。
- 70% 与稀有度分段是起值,按 §5 读数调。
- 卡面 / 详情需要「生疏」标识与打折后数值 → 交 `designer` 出稿(角标或数值旁小签),拍板后实现;拍板前 Core 先行,UI 只在详情文案里写「生疏 ×70%」。

## §3 首次合成 → 图鉴「已发现」
- 局内首次合出一个未收集的字,记入存档 `DiscoveredChars`(只增不减),不进收集、不给卡。
- 收集 / 卡组界面若已有「未收集灰显」,改为对已发现的字显示字形 + 「已发现」;没有该界面则只记存档,UI 另议。交 `designer` 一并出稿。

## §4 机器人 / 仿真
- `tools/balance` 加 **新手画像**(收集 = `Meta` 初始 10 张、角色 1 级、卡 Lv1),奖励池 / 掉字 / 合字闸按真实规则(收集闭包 ∪ 配方集)。
- 机器人选配方:按现有 `CardAppraiser` 对目标字打分取最高(生疏 ×70% 计入)。
- 报 1–15 层逐层:回合、开场字库、掉血;每局「合出新字 / 还原原字」次数。

## §5 验收目标(快档新手画像 60 种子,对比改前)
- 合出新字 ≥ 1.5 次 / 局(改前 0.1);还原原字占比 < 50%。
- 均卒层变化 ≤ +2 层(改前 10.2):拆合变得有意义,但不靠它把前期变简单(缺字不动)。
- 五系随机(核心)Lv1 / 5 / 8 变化 ≤ +2 层。
- 超标先调 §1 分段与 §2 系数,再报用户。

## 不做
- 缺字 / 掉字数量(用户 10-19:不动)。部件单独出手效果。侧向合字新字(读数出来再议)。

## 验证
coretests(配方集进出存档、可合成集并集且不连带叠字链、候选只含凑得齐的字 / 分段 / 不足与为空、独立随机流、生疏 ×70% 与 Lv1、奇遇字不生疏、首次合成记 DiscoveredChars)、prescompile、三工装、pytest 七目录、字体子集、trace 两档新基线;§5 读数。
UI(配方三选一、生疏标识、已发现)先交 designer,拍板后再实现 Presentation。
