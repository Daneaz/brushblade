## §1 移除「融会」,斩获升为终极技

- 删除跨树节点「融会」(`cross_edge`,暴击按机制节点数缩放)及其文案、图标引用、测试。
- 「斩获」从广纳枝移出,广纳枝回到 2 层:广纳(wide_1,字库不足 2 张 +1)→ 集腋(wide_2,不足 3 张 +1)。
- 斩获成为**终极技**,占原融会的位置,图标与节点样式参考融会(跨树节点那套),两级:
  - **一级**:前置 = 机制树**全部**节点已解锁;每击杀一名敌人 **50%** 概率掉 **1** 张字。
  - **二级**:前置 = 一级;每击杀 **70%** 概率掉 **2** 张字。
  - 每回合上限**两级都是 2 张**(用户 10-18);二级一次掉 2 张会直接到顶。字库满不掉。
  - 概率与抽字都走 `_traitRandom`(不平移主随机)。
  - 解锁等级 / 墨价:一级取融会原值,二级在其上按跨树 / 被动树同比递增(注释写明来源)。
- 节点 id:`ult_killdraw_1` / `ult_killdraw_2`(存档不需兼容);`PerkInfo` 三处、`PerkLayout`、`PerkNodeIcons`、文案同步;技能页现状卡、第 19 章同步。

## §2 掉字飞入(按 killdrop 稿实现)

- 以稿为准:击杀得字(斩获、折桂)从阵亡格冒出 → 停到批尾 → 弧线飞入字库落位 → PopTile + MarkFresh;回合开始掉字仍右侧滑入;敌人回合击杀同走此路径(先击杀得字、后回合掉字)。
- Core:斩获掉字统一发 `CharGranted`(Amount = 字库下标,TargetIndex = 阵亡敌人下标),敌人回合也发;字库满新增 `CharGrantBlocked`(每回合首次);上限到顶不发。概率未中不发。
- Presentation:token 挂常驻浮层;FlyGlyph 加弧高参数;TraitCueAt 无面印变体;字库满划线签 + 计数闪;当拍胜利原地淡出。新文案「字库满」1 条,重跑字体子集。

## §3 图鉴新增「头领」筛选

- 图鉴筛选行新增一类「头领」(用现有筛选组件,不新增视觉元素);两档屏宽验算筛选行放得下,放不下用 `Ui.HScrollFill`。
