# 快速施法(设置开关)· design

2026-10-20。需求:用户原话「在 setting 中新增开关,快速施法,选中我方为五行面,选中敌方为攻击面,开启后无需提前翻转」
(原话两边都写成五行面,已向用户确认:**我方 = 五行面、敌方 = 攻击面**;两面都能落敌方时**按当前朝上的面**)。

## 1. 行为

- 设置页新增开关「快速施法」,**缺省关**(第一次玩的人先学翻面这个基本概念)。存在 `SettingsState.QuickCast`,跟存档走,即改即存。
- 开启后,两面字(`CardFaceRules.HasTwoFaces`)出字时**由落点所在阵营决定面**,不必先翻:
  - 落 / 点**敌方** → 攻击面;
  - 落 / 点**我方**(玩家、木灵、空召唤位、嫁接木灵、尸体)→ 五行面。
  - 某一侧两面都能落(当前真实字表只有「溃」Lv5+ 的五行面也能落敌方)→ 这一侧按**当前朝上的面**。
  - 某一侧只有一面能落 → 用那一面;两侧都只有同一面 → 等同未开快速施法、按那一面单向出字。
- ~~已选中的两面字再点一次 = 进入敌我同时点亮的选目标态~~ **2026-10-21 用户改口径**:再点两面字仍 = 翻面(不论开关);
  并且**全局出字只靠拖动** —— 拆合台「出」钮移除,再点单面字 / 部件不再直出,点选目标只剩拖拽之后的第二段。快速施法只作用于拖拽。
- 教程锁面(`LockedFace`)期间,被锁的字不走快速施法,行为与现状一致。
- 部件池的牌(卡位 −1)没有面,行为不变。
- 关闭时一切与现状一致。

## 2. 规则落 Core(TDD)

`CardFaceRules.QuickCastFace(CharDef def, FaceSide side, CardFace faceUp, int cardLevel) → CardFace?`
(`FaceSide { Enemy, Ally }`):
- 这一侧的可落面 = `Landing(def, face, lv)` 与该侧落点位(Enemy = `FaceLanding.Enemy`;Ally = Self|Summons|EmptySlot|Graft)有交集的面;
- 只有一面 → 那一面;两面 → `faceUp`;没有 → null。
- 单面字恒返回 null(不适用)。

测试:真实字表的攻击面 → Enemy 恒为 Attack;各系五行面 → Ally 恒为 Feature;「溃」Lv5 Enemy 侧按 faceUp;
单面字 null;手造「五行面只打敌」的字 → Ally 侧 null、Enemy 侧按 faceUp。`SettingsState.QuickCast` 缺省 false、
经 `SaveSerializer` 往返保留。

## 3. 表现层

**拖拽**(`AttachFaceDrag` 一族):把单个 `_faceDragFace` 拆成敌侧面 `_faceDragEnemyFace` 与友侧面
`_faceDragAllyFace`(未开快速施法时两者都等于朝上的面,行为逐字节不变);落点 = 敌侧面落点的 Enemy 位 ∪ 友侧面落点的非 Enemy 位。
所有原先读 `_faceDragFace` 的地方按所在侧改读对应的面(敌人描环 / 预估签 / 溅射预览 / 打全体判据读敌侧;玩家条 / 木灵 /
空位 / 嫁接 / 复活 / 结果签读友侧);描环色按该侧的面取(攻击面墨色、五行面字形色);松手按命中的落点类型取对应侧的面派发。
⚠ 按 CLAUDE.md「共享交互状态赋予新含义要回头查所有读取点」:`_faceDragFace` 的每一处读写都要逐条归侧。

**点击**:2026-10-21 起没有点选出字入口(见 §1),快速施法不涉及点击路径。

**手牌提示**:选中两面字时提示后缀的「拖出」半句改为快速施法专用的一句(文案由设计稿定),走字符串表。

**设置页**:`SettingsView` 加一行带说明小字的开关(现成的 `ToggleRow(title, desc, …)`)。

(两色描环)、选中提示文案。两档屏宽验算。未拍板不动 Presentation。
