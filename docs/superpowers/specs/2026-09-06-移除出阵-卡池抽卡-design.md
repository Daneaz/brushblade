# 移除出阵 · 卡池抽卡

2026-09-06 拍板。分支 `worktree-remove-deck-cardpool`。

## 动机

「出阵」(Deck)让玩家在登塔前从收集里编 5~15 字,登塔的一切内容都从这份名单取。
本次废止它:每场的卡直接来源于**已解锁的卡池**(`OwnedCards`),宝箱开得越多卡池越大,
稀有度越高的字被抽中的概率越低。

等价说法(用户原话):把 Deck 的上限改到无限大。

## 一、稀有度权重表(唯一来源)

```
MetaRules.RarityWeights = { 150, 350, 300, 130, 50, 15, 5 }   // 千分比,索引 = rarity−1
//                          白    绿    蓝    紫   金  橙  红
```

重心在绿/蓝,两头稀。这张表**同时**供起手抽卡与战后 5 选 2 使用。

`RunEngine.RewardRarityWeights`(现为 `{0, 80, 15, 5, 0, 0, 0}`)删除,改指向 `MetaRules.RarityWeights`。
后果:白字会进 5 选 2 的候选,金/橙/红字也能作为战利品露面 —— 一条曲线管到底,不再有两套。

## 二、起手 6 张

`MetaRules.StartingLibrary` 重写。候选 = `OwnedCards` 中的**可收集字**
(排除 `IsComponent` 的部件,以及无稀有度的中间产物字)。

1. **前 5 张**:金/木/水/火/土 各一张。每系在**本系候选**里按 `RarityWeights` 加权抽一张。
   某系一个字都没有则跳过 —— 起手不足 6 是合法状态,不做补齐。
2. **第 6 张**:候选里**实际存在的最高稀有度档**中均匀抽一张。
   卡池最高只到蓝,就从蓝里抽。
3. **不去重**。第 6 张撞上前 5 张里的字,就是同一张字拿两份。
   字库本来就允许重复条目(见 `BattleEngine.cs:207` 注释「同字多张也不会认错卡位」),
   消耗按下标走,不需要额外改造。
4. 无属性(心系)字不参与前 5 张,只能经第 6 张或战利品进场。

签名从 `StartingLibrary(meta)` 变为 `StartingLibrary(meta, graph, random)`。
`GameRoot` 复用它在 `RollStartingPool` 处已经造好的那个 `GameRandom`。

**博闻技能**(`PerkRules.LibraryBonus`,现为「起手上限 +1/级」):
新规则起手是固定的 5+1,所以博闻的每一级追加**一张自由加权抽**
(全卡池按 `RarityWeights`,同样不去重)。

## 六、已知代价(已裁定接受)

**档内稀释**:权重按稀有度档分配、档内均分,所以开箱开出的同档字越多,
每一张特定字被抽中的概率越低。开箱变强的同时,「想用某张牌」的确定性单调下降。
用户裁定:就要这个手感。
