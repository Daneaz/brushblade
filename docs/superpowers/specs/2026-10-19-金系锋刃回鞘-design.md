# 金系「锋刃回鞘」— design

日期:2026-10-19 ・ 状态:用户 10-19 拍板(「不用跑慢档,直接做」)
上游:Plan F F3「五系强弱 · 金最弱」;诊断草稿 `game-wt-metal/docs/superpowers/specs/2026-10-19-金系诊断-草稿.md`(未入库,结论摘入 Plan F)。
诊断结论:金不是输出或反击预算不够,而是「字不够用 + 没有回复」导致逐场磨死;快档两项同补才 +20 层以上。

## §1 规则(基础规则,不需要技能树)
战意满 5 层(`MoraleCap`)时,打出**金系字的攻击面**且该面带伤害效果(部件不算、纯 buff 不算)→ 触发「锋刃回鞘」:
1. 本张字伤害 +100%(与断金技能叠加,见 §2);
2. 本张字造成的伤害吸血 35%(按实际扣血量,含溢出前的护盾吸收?—— 按实际对敌造成的 HP 损失,不含护盾吸收;回复玩家生命,不超上限);
3. 本张字结算中击杀至少 1 个敌人 → 这张字回到字库(每次触发至多回 1 张;字库满则不回,同斩获口径);
4. 结算后清空战意。
- 进门时判定(同断金:本张结算途中因暴击涨满的不算本张)。
- 只认玩家出字;木灵出手、特性反应(TriggerDepth > 0)不触发。

## §2 与技能树「断金」(metal_4,`MoraleReleasePercent`)
- 裁定:断金并入锋刃回鞘 —— 有断金时锋刃回鞘伤害 +(100 + N)%;触发条件统一为 §1(只认攻击面)。
- 断金描述改「锋刃回鞘的伤害再 +{value}%」;详情同步。

## §3 表现
- 触发时飘「锋刃回鞘」名签(复用现有特性名签 / 上状态动效通路);吸血走现有治疗飘字;回库走现有掉字入库动效(斩获同款)。
- 战意 chip 详情 / 状态说明、词条(若有「战意」词条)补一句锋刃回鞘规则。
- 文案走字符串表,重跑字体子集。用户 10-19 要求直接做,不走 designer(无新 UI 元素,只复用现有名签 / 飘字)。
