# 木灵尸体标识 · 复活清状态 — design

## §1 尸体标识(按稿)
- 尸体格同活木灵结构:立绘(locked-bg + text-faint 字形)、头行(字名 text-dim + 属性徽章原色 +「阵亡」)、chip 行(攻 + 本命,压 locked-bg / text-dim)、血条空轨「0/上限」、行动条位留白。
- 常显:字库里有带复活的面(`BattleEngine.HasRevive` 扫字库)时淡态(立绘 + 头行,α .5);否则平时不画。选目标 / 拖放 / 召唤选位时全量。
- 复活点选:可救尸体翠玉 10% 底 + 1.5pt 描环,血条翠玉斜纹预演 ⌈上限 × N%⌉ + 叠字「→ n/上限」。
- 复活拖放:可救尸体挂 FaceMark;悬停预估签「复活 {name} · 生命 {n}」+ 本命名第二段压浅;复活全部(㵘)悬停任一具全体加深,签「复活全部 · {n} 只」(受存活上限截断写实际只数)。
- 召唤到尸体格:选位态 chip 行换提示「召唤到这里会覆盖它」(wood-fg),字库有复活字时「覆盖后无法复活」(cinnabar-dark);拖生面悬停签「覆盖 {name}」+「 · 无法再复活」。
- 长按尸体详情:「复活后:生命 n/上限,本命 X 照旧;状态、护盾与行动条清零」。
- 新文案 7 条(稿列出)+ 详情 1 条;重跑字体子集。

## §2 复活清状态(用户 10-18)
- `ReviveAt`:复活时清空该木灵的**全部状态**(StatusBag),护盾、行动条照旧清零;保留字、属性(含嫁接后)、攻击、生命上限、本命。
- 清在复活那一刻(不在阵亡时):阵亡时的特性挂点仍可读身上状态。
- 复活后若有「复活时」特性挂的状态(如复活盾 ReviveShield、泽润等),在清空之后再施加,不被清掉。
- 测试:阵亡前挂格挡 / 战意 / 灼 / 磐固 → 复活后全无;复活盾照常;identity / trace 若变如实记录。
