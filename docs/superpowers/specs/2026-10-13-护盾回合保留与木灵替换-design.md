# 护盾回合保留、三条土系新特性、木灵替换 / 嫁接二选一 — design

日期：2026-10-13 ・ 状态：待用户审阅
上游：`docs/superpowers/specs/2026-10-03-字卡五特性体系-design.md`（v7）§3、§3.1、§9；Plan F 立项讨论（F1 机器人之前的前置修复）。
用户指示：本批界面不经过 designer，按本文直接实现（2026-10-13）。

## 0. 为什么

1. **护盾回合清空自相矛盾**：U1（2026-10-04）规定玩家下一回合开始时清空普通护盾，而战斗结束时护盾按 `ShieldCarryPercent`（基础 50%，固本 75%）带进下一场 —— 结果是「跨场的最后一回合能带走一半，战斗内的回合反而全清」。
2. **木灵无法定点替换**：木字的五行面（生面）拖到活木灵上一律嫁接；想把后排的「花」换成「林」做不到，只有召唤位满时才会弹「替换最前面那只」。
3. F1 机器人要把「替换木灵」作为候选动作，前提是游戏里先有这个动作。

## 1. 护盾：战斗内不再按回合清空

- **删除** U1 回合清盾：`BattleEngine.BeginPlayerTurn` 里清空玩家普通护盾与全部召唤物护盾的那段整体移除。护盾在一场战斗内一直保留，直到被打掉、被消耗（`ShieldSpend` 等）或被 Boss「倾覆」清空。
- **战后不变**：战斗结束按 `ShieldCarryPercent` 带入下一场（玩家与召唤物同口径），固本 +25 照旧。
- **上限不变**：护盾 ≤ 最大生命（Plan C）。
- **取消「留存护盾」**：只剩一个护盾桶。删除留存桶（`_shieldPersist`、`ShieldPersist` 读口及其快照字段、`persistOnce` / `persist` 配置项）、`GlossaryTerm.KeptShield` 与 `term.kept_shield.*` 文案、spec §3 词条表「留存护盾」一行。存档不需兼容（项目未上线），快照结构直接改。
- 依赖「回合清盾」的机制一并处理：
  - 塔·浮屠（`ShieldCarry`，清盾时加回）—— 由 §2 新特性替换；`EffectKind.ShieldCarry`、`StatusKind.ShieldCarry` 及其 chip、详情文案、E3 触发反馈（`JuiceWaterEarth` 浮屠段）、E4 词条 / 预估引用全部删除。
  - `DropShieldRecoilIfEmpty`（两桶都空 → 反震失去载体）改为单桶判空，挂点保留在护盾被打空 / 被消耗的时刻。
  - `RunSnapshot` 中「已开始的玩家回合数」若只为清盾服务则删除；仍有别处读取则保留。
- spec v7 改写：§3.1 第 ① 条裁定改为「护盾战斗内不随回合清空；战斗结束按保留比例带入下一场」；§3 词条「护盾」改为「先于生命扣除。战斗内持续保留；战斗结束保留一部分（比例由技能树定，基础 50%）」。

## 2. 三条土系 Lv8 固面特性换新

原三条都建立在「回合清盾 / 留存桶」上，§1 之后空转，按用户指示换成全新特性。数值为起值，交 Plan F3 定标。

| 字 | 槽 | 原 | 新名 | 新效果 | 配置（草案） |
|---|---|---|---|---|---|
| 垒 | Lv8 固 · 主动 | 垒砌 | **积土成山** | 本次护盾 +30%；之后 3 个玩家回合开始时，各获得护盾 X | `Amplify 30` `scope Shield` + `TurnPulse` `turns 3` [`Shield X`]（X 起值 = 垒本体护盾 × 25%，按等级缩放同本体） |
| 塔 | Lv8 固 · 主动 | 浮屠 | **七级浮屠** | 出字结算完后，玩家护盾每有最大生命的 10%，护甲 +8，最多 7 层，持续 4 回合 | `DefenseBuff 8` `turns 4` `perShieldTenth` `cap 7`（新取值方式：层数 = ⌊玩家当前护盾 × 10 / 最大生命⌋，钳 0..cap；层数 0 时不挂） |
| 㙓 | Lv8 固 · 主动 | 厚德载物 | **厚德载物**（同名） | 本次护盾 +100%；本场之后每个玩家回合开始时，全部存活木灵获得「玩家当前护盾 × 10%」的护盾 | `Amplify 100` `scope Shield` + `TurnPulse` `turns -1` [`ShieldSummons 10` `ofPlayerShield`]（`TurnPulseAllows` 放行 `ShieldSummons`；新增 `ofPlayerShield` 取值：按脉冲兑现时玩家当前护盾计） |

- 新增机制只有两处：`perShieldTenth`（按护盾计层）与 `ofPlayerShield`（按玩家当前护盾取值）+ 回合脉冲放行 `ShieldSummons`。数据走详表 → `extract_values` → `export_chars` 管线（`chars.json` 是产物，不手改）；特性表 `docs/design/字选型/特性表/土.md` 三行同步改。
- 同类取最强（spec §5.2-1）：七级浮屠的护甲与其他护甲加成同轴照现口径；积土成山与厚德载物的回合脉冲各自独立（不同载荷）。
- 显示：
  - 状态 chip：回合脉冲已有 chip（水系大雨滂沱），沿用；七级浮屠的护甲走现有护甲显示，不新增 chip。
  - 字卡详情 / 预估签 / 词条：文案按新效果写，走 `CharInfo` 效果拼句与字符串表；`EffectsText` 新分支不得落 default（不能印出英文枚举名）。
  - 触发反馈：回合脉冲兑现时沿用现有脉冲反馈；七级浮屠出字时随主动特性出字飘名（E4 TriggerFx）。
  - 新增文案后重跑字体子集。

## 3. 木灵：嫁接或替换二选一

### 3.1 交互

- **触发**：木字五行面（生面）拖到**活木灵**上松手，且「嫁接」「替换」两个选项都可用时，弹出二选一。
- **弹窗**：复用现有「召唤位满，是否替换」确认弹窗的样式与组件，不新造。
  - 标题：「{木灵名}：嫁接还是替换？」
  - 按钮一：「嫁接」，下附一行结果说明（复用 E4 预估签对木灵的结果文案，如「嫁接 · 格挡 +1」）。
  - 按钮二：「替换为{新木灵名}」，下附一行「替换 · 召唤{新木灵名}」。
  - 点弹窗外 = 取消：不扣 AP，不消耗字，字回到手上，选中态复位。
- **只有一个选项可用时不弹窗**，直接执行该选项（例：这张字的生面不具备嫁接条件 → 直接替换）。
- 拖到空格 = 召唤、拖到自己 = 普通召唤、召唤位满的既有替换确认，这三条照旧。
- 部件池路径不涉及（部件不能召唤木灵）。

### 3.2 规则

- **替换**：移除该格木灵，在**同一格**召唤本字的木灵（含本命、光环、入场效果，与普通召唤一致）。
- 被替换的木灵按**现有满员替换口径**移除：不算阵亡，阵亡触发（秋实、落木、藻荇等）不兑现；其护盾与状态一并丢弃。
- 替换不吃「召唤位满」校验（格子数不变）。
- 教程锁翻面、AP 校验、出字即消耗等既有口径不变。

### 3.3 Core

- `Cast` 新增显式参数表达「对活木灵：嫁接 / 替换该格」（例如 `SummonDropMode { Auto, Graft, Replace }`，缺省 `Auto` = 现行为：可嫁接则嫁接）。`Replace` 走现有顶替路径，目标由「最前面那只」改为 `allySlot` 指定的格。
- 新增只读查询供 UI 判定是否弹窗：某字某面对某活木灵格是否可嫁接、是否可替换。
- `EstimateCast` 同步支持该参数（预估签与弹窗说明同源）。
- trace / balance 机器人不传新参数（`Auto`）。

## 4. 不做的

- 不调任何既有数值（归 Plan F3），三条新特性只给起值。
- 不改敌人护盾（敌人护盾本来就不在回合清盾之列）。
- F1 机器人（含「替换木灵」候选动作）另写 spec，在本批合并之后。

## 5. 验证

- **Core（TDD，coretests）**：
  - 护盾跨回合保留：玩家与召唤物护盾在第 2、3 个玩家回合开始时不变；战后按保留比例带入下一场（玩家、召唤物、固本 75%）；倾覆仍清空；上限仍钳最大生命。
  - 反震载体：护盾被打空 / 消耗时失去载体，跨回合不再因清盾失去。
  - 三条新特性：积土成山 3 次脉冲各给盾、第 4 回合不再给；七级浮屠层数边界（0 层不挂、恰 10%、超 70% 钳 7）；厚德载物脉冲按兑现时玩家护盾的 10% 给每只存活木灵、无木灵时空转、本场持续。
  - 替换：指定格被替换、未触发阵亡事件、新木灵本命与光环生效；`Auto` 与旧行为逐位一致；查询接口在只可嫁接 / 只可替换 / 两者皆可三种情况下的返回。
- **trace**：护盾规则是有意的行为改变，trace 基线**会变**。提交拆两步：先落「接线 / 替换 / 新特性数据」并确认 trace 两档恒等，再单独落「删除回合清盾」并更新基线，新 sha 写进执行记录。
- **管线**：pytest 六目录；`chars.json` 可再生；三行特性表与导出一致。
- **Presentation**：prescompile 0 error；新 / 删文案后字体子集比 cmap；`StatusText.Of` / chip 列表 / `CharInfo` 三处同步删浮屠、留存护盾；grep `ShieldCarry`、`KeptShield`、`ShieldPersist`、`persist` 零残留（`ShieldCarryPercent` 除外）。
- **balance**：跑一次报新读数（不调数值），单系·土与木混·木土的变化写进执行记录，交 Plan F。
- 设计验收按 2026-10-11 起的口径：跳过截图，体验清单照写。
