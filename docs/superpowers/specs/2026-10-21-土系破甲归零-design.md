# 土系破甲归零 · 设计

> 状态：待用户审阅（2026-10-21）。
> 起因：卡详情「?」五系说明写到土系时，用户要求把破甲改成真正意义上的破甲。
> 用户已拍板（2026-10-21）：① 只改土系；② Boss 减半；③ 崩·崩裂 / 㙓·厚壤改成按厚加回合；④ 敌人对玩家的破甲也归零。
> 标 〔代拍〕 的是本稿代为决定、审阅时可改的细节。

## 1. 现状

`EffectKind.ArmorBreak` 现在是「扣护甲 Value 点，限时，可叠加，各自计时」（`BattleEngine.cs` 的 `case EffectKind.ArmorBreak`）。
使用它的字有三个系：

| 系 | 字 · 位置 | 现值 |
|---|---|---|
| 土 | 垚 圭 塔 碉 垒 堡 壁 杜 碎 · 攻击面本体 / Lv3 破甲·强化 | 10~35 点，2 回合，强化后 4 回合 |
| 土 | 垚·山岳（Lv6 五行面）、圭·圭角（Lv8）、垒 / 堡·劈山（Lv8） | 18~38 点，2 回合 |
| 土 | 崩·崩裂（Lv6）、㙓·厚壤（Lv6） | 每消耗 1 层厚削 2 / 3 点，全体，2 / 3 回合 |
| 金 | 铡 剑 剿 利·破甲（Lv5）、四金 / 鍂·金石（Lv5 逐击）、千钧（Lv8） | 15~45 点，3 回合 |
| 火 | 焚·焚甲（Lv6） | 35 点，2 回合 |

## 2. 新规则

### 2.1 破甲（土系专属）

- 持续期间，目标护甲**按 0 算**；**Boss 按一半算**（与封禁、斩杀同一条纪律：高价值控制对 Boss 降级，不失效）。
- 持续结束，护甲恢复原值。护甲本体从未被改动，「恢复」是自然结果。
- 不再有点数。重复施加：剩余回合取较长者，不叠加 〔代拍〕。
- 回合数沿用现有配置：本体 2 回合，Lv3 破甲·强化 4 回合；山岳 / 圭角 / 劈山 2 回合。
- 与封禁同时在身上：杂兵 0；Boss 仍是一半，不叠成四分之一 〔代拍〕。
- 与削甲（§2.2）同时在身上：先按破甲 / 封禁取基础护甲，再扣削甲点数，最低 0。
- 相克即破甲（wuxing-reference）不变，它针对的是单击，与本状态无关。

### 2.2 削甲（金、火保留原机制，改名）

- 金、火两系的破甲特性改名为**削甲**：机制、数值、回合一律不变（扣点数，可叠加，各自计时）。
- 改名是为了「一个词只有一种意思」：破甲 = 归零，削甲 = 扣点。
- 特性名也叫「破甲」的（铡 / 剑 / 剿 / 利 Lv5）改名「削甲」。

### 2.3 崩·崩裂、㙓·厚壤：按厚加回合

改成「全体破甲，基础回合 + 每消耗 k 层厚多 1 回合」〔代拍，数值待审〕：

| 特性 | 新规则 | 消耗 3 层 | 消耗 10 层（满） |
|---|---|---|---|
| 崩·崩裂 | 全体破甲 1 回合，每 3 层厚 +1 回合 | 2 回合 | 4 回合 |
| 㙓·厚壤 | 全体破甲 1 回合，每 2 层厚 +1 回合 | 2 回合 | 6 回合 |

没有消耗厚时（厚为 0）仍按基础 1 回合生效 〔代拍〕。

### 2.4 敌人对玩家施加的破甲

同样归零：持续期间玩家护甲按 0 算（`EffectivePlayerDefense` 里护甲增益、富甲一并算 0）〔代拍：增益也归零才叫真破甲〕。
目前没有敌人配置破甲，不影响现有平衡。

## 3. 显示与文案

- 敌人护甲 chip 与详情弹窗的护甲数都读 `DisplayedEnemyDefense`，破甲期间显示 0（Boss 显示一半）。
- 状态 chip：
  - 破甲沿用现有 `icon_armorbreak`（盾牌 + 裂纹），不用另画；
  - 削甲需要一枚新图标（designer 出稿，走 `tools/icons` 三处对账）。在新图标落地之前，削甲暂用同一枚图标并在 chip 上显示点数。
- 字符串：
  - `status.armorbreak.desc`：「护甲归零，Boss 护甲减半；持续结束后恢复。」
  - `term.armor_break.desc`：「持续期间目标护甲归零（Boss 减半）」
  - `char.effect.armorbreak`：「破甲 {turns} 回合」（不再显示数值）
  - 新增削甲一组（status / term / char.effect / augment），文案沿用原破甲的点数写法。
- 新增文案后重跑字体子集。

## 4. 平衡影响（需留意）

- 土系各档破甲的差距原来在点数上（碉 10 ~ 垚 35），归零后只剩伤害和回合的差距，低档土字的破甲相对变强。
- 打高护甲的敌人时土系明显变强；打 Boss 时折成一半，提升幅度较小。
- 实现后用五系随机画像跑一批仿真，对比土系的爬层数。

## 5. 验收

- Core 单测：破甲期间杂兵护甲为 0、Boss 为一半；结束后恢复；重复施加取较长回合；与封禁、削甲的叠加顺序；崩裂 / 厚壤的回合公式；玩家侧归零。
- 金、火的削甲：已有破甲测试原样改名后继续通过（数值、叠加不变）。
- 「新增战斗状态三处接线」（CLAUDE.md）：`StatusText.Of`、`BattleView` chip 列表、`CharInfo.EffectsText` 都要有削甲。
- 管线：土系破甲条目不再带 value；`extract_values` 的映射表核对新标记（见记忆「管线 token 表静默丢弃」）。
