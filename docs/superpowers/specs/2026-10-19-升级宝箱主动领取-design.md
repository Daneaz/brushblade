# 升级宝箱主动领取 · 设计

日期 2026-10-19 · 拍板稿 `docs/design/drafts/character-chest-claim/`(`f47af3df`)· 上游 spec `2026-10-02-角色页-统计与等级奖励-design.md` §2.1 / §5.1

## 1. 为什么改

现在每级宝箱在回地图、段末结算、登塔结算时由 `LevelRewardRules.GrantLevelChests` 自动塞进空箱位,箱位满了就先欠着。玩家控制不了箱子什么时候进箱位,也看不清还欠几只。

改成升级只记一只「待领」,玩家在角色页的等级轨道上**一只一只主动领**。

## 2. 目标 / 非目标

- 目标:
  - 每级宝箱不再自动发放,改为在角色页领取。
  - 轨道改为每级一格,和里程碑并在同一条轨道上。
  - 打开角色页时聚焦到还没领的格子。
- 非目标:
  - 档位规则不动(Lv.2–5 竹简 · 6–10 青瓷 · 11–20 紫檀 · 21–30 鎏金 · 31–40 朱漆 · 41+ 赤霄,不掷随机)。
  - 不做「全部领取」。
  - 里程碑奖励的规则与领取弹窗不动。
- 反目标:
  - 待领箱因箱位满而作废。
  - 领取占用暂存位(暂存位只留给爬塔结算箱)。

## 3. Core 规则(`LevelReward.cs`,走 TDD)

**存档字段**

- `MetaState.LevelRewardGranted` 删除,换成 `List<int> ClaimedLevelChests`,记已领的等级。
- 改成集合,是因为现在可以按任意顺序领。
- 不写迁移:项目未上线,存档结构直接改。旧存档里这个字段会成为未知键被忽略,Lv.2 起的箱子会重新变成待领。

**规则函数**

| 函数 | 规则 |
| --- | --- |
| `HasChest(level)` | `level >= 2`。Lv.1 不发箱。 |
| `IsChestClaimable(meta, lv)` | 有箱,且 `lv ≤ 当前等级`,且 `lv` 不在已领集合里。 |
| `PendingChestCount(meta)` | Lv.2..当前等级里未领的只数。取代 `OwedChests`。 |
| `TryClaimChest(meta, lv, cardPool, time)` | 不可领,或 `meta.Chests.Count ≥ SlotLimit`,就返回 false、不改任何状态。否则走 `ChestRules.TryAwardChest(TierForLevel(lv))` 放进空箱位,记入已领集合,返回 true。**从不占暂存位。** |
| `HasClaimableReward(meta)` | 有可领里程碑,或待领宝箱 > 0。地图红点改读它。箱位满时照样算可领,因为东西确实在等你。 |
| `TrackEnd(meta)` | 轨道末端 = max(当前等级 + 5, 当前等级之后的下一个里程碑等级)。轨道起点恒为 Lv.2。 |
| `FocusLevel(meta)` | 首次打开时聚焦的等级:Lv.2 起第一个有可领宝箱或可领里程碑的等级;都领完了,返回当前等级。 |

**删除**

- `GrantLevelChests` 与 `LevelChestGrant`。
- `GameRoot` 里三处调用:`ShowMap`、段末结算、登塔结算。
- `TakeLevelUpSummary` 及升级弹窗的触发时机不变。

## 4. Presentation(按拍板稿实现,尺寸取稿)

1. **角色页轨道**(`CharacterView`)
   - 里程碑面板改成「等级奖励」长轨道,每级一格,范围 Lv.2 → `TrackEnd`。
   - 普通格与里程碑格的画法、底行五态(领奖励 / 领取·领宝箱 / 箱位已满 / 已领 / 差 N 级)、里程碑优先、标题行、三位数等级缩字号,都照稿 README §1。
   - 里程碑面板移出 `HScrollFill`,轨道用独立的横向 `ScrollRect`;`HScrollFill` 只包统计面板。
   - 首次打开滚到 `FocusLevel`,左边留 1 格;都领完时当前等级落在视口约 60% 处。
   - 领取后重建页面时用 `_trackScrollX` 恢复滚动位置。
   - 两侧纸色渐隐;屏外还有可领时,贴边出「◂ N 待领 / N 待领 ▸」小签,点了滚过去。
   - 左栏删掉欠箱 chip。
   - 删 `Window()`,原 10 格窗口作废。
2. **升级弹窗**(`LevelUpPopup`):撤掉「已放进箱位 n/4」和欠箱 chip,换成「回主界面后在角色页领取」(复用 `levelup.milestone_hint`);列表高不再扣 chip。
3. **地图红点**(`MapView`):条件改为 `HasClaimableReward`。
4. **文案**:按稿 README 的「文案」节增、改、删,改完重跑字体子集。
