# 字卡特性 Plan D2-木：木系专属特性 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地木系 46 条专属特性（spec v7 §9 木表），共 51 行。连同实现它们所需的木灵光环、木灵生死与受击挂点、敌人侧标记、木灵编队操作，以及 14 项共用小扩展（E37–E50）。

**Architecture:** 推进顺序为：共用小扩展（含 E37 本命追加这一地基）→ 光环族 → 受击 / 阵亡 / 守护 / 标记 → 编队与敌人侧 → 表现层 → 数据。木系的新分支集中放进新 partial `Core/BattleEngine.Wood.cs`。

trace 卡池里有箭 / 林 / 藻 / 森，全 1 级，且机器人恒选生面，所以治疗、护盾、嫁接、魅惑、种、荆棘本命这些路径 trace 一次都不走。这些路径**必须靠「无新状态逐位恒等」的单元对照测试**守住（附录 §3 末 8 项）。`DamageSummon`、`DamagePlayerDirect`、`RefreshSummonAura`、`EffectiveAttack`、Summon 分支、`CaptureAliveSummons` 这几条共享必经路径，仍以 trace 两档 sha 作为每个任务的硬验收。

**Tech Stack:** Unity 6000.5.2f1；Core/Data 纯 C# 9；NUnit（`tools/coretests`）；Python 3 管线；`tools/trace` / `tools/balance`。

## 已定口径

**用户授权**（2026-10-08 夜起沿用；2026-10-11 用户指示「完成 D2-土 后继续 D2-木」）：待裁定项由 controller 按推荐口径自行决定，事后汇报。附录 §4 Q1–Q30 **全部采用推荐口径**。要点如下：

- **Q1 箭灵**：全部木灵本场远程（M1 `SummonRanged`，含之后召出的）。
- **Q2 「X灵」身份**：主动特性读 `SourceChar == 本字 && Char != 苗` 的存活木灵。本命光环跟本命字段走，会随嫁接转移。
- **Q3 本命转移**：E37 合并的 Lv4–Lv8 本命随嫁接转移。
- **Q4 嫁接计数**：嫁接算「本次召出」（E42）。
- **Q5 E38 生面精进的作用范围**：
  - 作用于：召出木灵的血与攻、HealSummons、ShieldSummons。
  - 不作用于：幼苗百分比、嘲讽、保命。
- **Q6 增攻光环取最强**：林立 / 擎天 / 桂冠对同一只木灵取最强。参天之力（本命）与成林在同一加法段相加。
- **Q7 光环计时**：光环是玩家袋状态，按玩家回合递减。
- **Q8 减伤合成**：林荫 / 森严与 DamageCut 取最强，即 `min(60, 格挡 + max(DamageCut, 林荫, 森严))`，算完后再算 HitCap。
- **Q9 守护**：
  - 转移量 = 玩家这一击过完护甲 / 格挡 / 减伤 / HitCap 后 × 30%。
  - 只扣柘灵的盾与血，不再过护甲 / 生克；不算挥击；可以致死。
  - 镜 / 格挡反击 / 反震 / 碎玉的基数用转移前的量。
  - 免疫先消耗；多只柘灵时取槽位最小的。
- **Q10 良弓**：
  - 伤害 = 柘灵 `SummonDefense` × 200%，心属性，无视护甲。
  - 60% 预算的顺序：荆棘 → 反弹 → 格挡反击 → 良弓。
  - 吞噬或打空时不触发。
- **Q11 荆刺**：攻击者身上的标记 % 并入两条反弹管线的 Reflect 合计，钳 60%。持续 2 次该敌人行动，同源刷新。
- **Q12 荆天棘地**：光环荆棘与本命荆棘取最强。披荆只认荆灵自己的本命荆棘。
- **Q13 攀附**：
  - 目标 `pick HighestHp`（不摇号）；藤灵取本次召出的第一只或被嫁接者。
  - 每次敌人行动开始时结算（同种），先于冻结判定。
  - 藤灵阵亡 / 被顶替 / 被并入时解除。Boss 也可以被缠。
- **Q14 一叶知秋**：TurnPulse 3 回合，施加当回合不触发；每个玩家回合开始给随机一名敌人挂标记 30%，持续 1 次行动；楸灵不在场就空转（E50）。
- **Q15 阵亡类（秋实 / 落木 / 藻荇）**：
  - 阵亡 = `OnSummonDeath`，含吞噬、灼烧、守护转移致死；顶替和绿潮并入不算。
  - 秋实：满池时不入。
  - 落木：伤害 = 有效攻击 × 300%，作反应兑现，不暴击。
  - 藻荇：只对敌人 killer 生效。
- **Q16 折桂**：
  - 从玩家已拥有字里档位最高的一档取候选（没有就取全字表非部件的最高档），用 `_traitRandom` 抽 1 张，入本场字库。
  - 满库时不入，也不计次；随字库延续到之后的战斗；每场 1 次（E49）。
- **Q17 水草**：出字级。每次顶层出字结束后，按本次实际治疗量（不含给藻灵自己的部分）让每只带水草的藻灵回复等量。种 / 桂香 / 反应里的治疗不算。
- **Q18 绿潮**：
  - 并入本次召出的藻灵。小藻 = `Char == 苗 && SourceChar == 藻`。生命 / 上限 / 攻击按当前值相加，小藻直接移除（不触发阵亡）。
  - `Taunt 2 pick SummonedThisCast`，按 D2-0 现口径随木灵出手递减。
  - 木灵限时状态的时钟统一问题另开一项，见 Plan F / E。
- **Q19 丛藻**：生成的小藻不受丛生上限限制，但计入名下数量。
- **Q20 林深**：同轴相乘，全体 50% × (100 + 10n)%（E39）。
- **Q21 林立**：本体由 1 只 100% 变为 2 只各 60%（血与攻都乘 60%）。光环 +20% 给全部木灵（含之后召出的），持续 3 个玩家回合。
- **Q22 擎天**：给出字时在场、且不是本次召出的木灵，逐只挂；之后召出的不吃。
- **Q23 月桂 / 蟾宫**：月桂只给玩家。蟾宫给玩家 + 全部木灵，暴击率以「桂灵在场」为闸门。
- **Q24 四木成林**：每只木灵按自己的目标规则额外出手一次。不推进行动条、不递减状态、不触发光环治疗 / 丛生 / 灼烧。独木生林的幼苗血与攻都按 30%。
- **Q25 藻缚**：`Slow 2 pick Adjacent`，含主目标。
- **Q26 秋风扫叶**：Row，主目标 `hitPercent 60`，其余 `shapePercent 60`。
- **Q27 花 Lv5 攻·寄生**：`TurnsInValue` 加 `Charm = false`，即魅惑 +1 回合。数据不动。
- **Q28 万木回春**：维持书写顺序，本体召唤先落位。`Revive 0` = 全部尸体，受存活上限约束。
- **Q29 柘弓 / 硬弓 / 撼天**：加成基数取最强的那一只；柘弓只由最强一只射一箭。
- **Q30 数值起值**：按附录，Plan F 重定。

## Global Constraints

- **Core 与随机性**：Core / Data 禁止引用 UnityEngine；随机性走 Core RNG。**新挂点在状态或字段缺省时一次判断即短路，不多摇也不少摇。**
- **trace 恒等是每个任务的硬验收**：
  - 校验方式：数据行 `grep -v '^#' | shasum -a 256`。普通档应为 `7235e89f…`，`--flat-scale` 档应为 `883954a3…`。
  - 命令：`dotnet run --project tools/trace -c Release -- --out tools/trace/out/x.txt`；`... --out tools/trace/out/x-strict.txt --flat-scale`。
  - 木特有路径 trace 走不到。改动这些路径时**额外**要写「无新状态逐位恒等」对照测试，期望值取自改动前代码，用 `git archive <base>` 导出后实跑验证。

## Review Focus

1. **槽位身份与生命周期**：攀附、擎天 / 桂冠按槽位挂的光环、丛藻 / 绿潮的 `SproutParentSlot`，在以下五种情况下的清理是否正确：木灵阵亡、被顶替召唤覆盖、尸体槽复用、绿潮并入、跨场携带重排。
2. **减伤与反伤两份 60% 预算**：
   - 减伤：林荫 / 森严 / DamageCut 取最强后加格挡、钳 60%，再算 HitCap。
   - 反伤：荆棘、反弹（含荆刺标记）、格挡反击、良弓的顺序，合计不超过 60%。
   - 守护转移的位置在减伤之后、护盾之前，转移量不得为负，也不得重复计入。
3. **木灵暴击与 RNG**：没有蟾宫时，`RollCritForSummon` 不摇号；有蟾宫时只在桂灵存活期间摇。四木成林额外出手的随机消费只在特性存在时发生。
4. **本命追加（E37）× 嫁接 × 跨场**：
   - Lv4–Lv8 本命合并进本体召唤的被动。
   - 嫁接时整体转移。
   - 存档往返不丢字段。
   - 木灵限时状态不跨场（E44），入场护甲照常携带。
5. **无新状态时逐位恒等**：`DamageSummon`（荆棘 / 反弹 / 反击全段）、`DamagePlayerDirect`、`RefreshSummonAura` / `EffectiveAttack`、`OnSummonDeath`、魅惑反打、嫁接、HealAlly、各 Summon 系效果分支。
