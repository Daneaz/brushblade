> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 2026-10-04 至 10-11 用户已拍板、但还没实现的稿落进游戏。包括：
- 水土状态 chip 8 枚，加 10-04 补的反击加倍、保命两枚，另有封字代价态；
- 水土与嫁接的提示反馈；
- 部件印记角标，以及「山」全体落点；
- 字形特性飘字；
- 花灵形象；
- Boss 格 chip 放到 3 行；
- 顺带修掉 `gen_char_doc` 对已删接口的引用。

**Architecture:**
- Core 只做两类事：发出现在缺的信息（3 个新事件、2 个 EffectSource 标签、Graft 回复量），以及补只读接口（印记、本回合实际效果表、字形特性的「本场已用」）。全部走 TDD。
- 新事件只写在新状态存在的分支内，trace 两档必须恒等。
- Presentation 按稿接上 chip、飘字和角标。

**Tech Stack:** Unity 6000.5.2f1；Core/Data 纯 C# 9；NUnit（`tools/coretests`）；Python 3（图标、召唤物素材、字体子集管线）。

**Spec:** `docs/superpowers/specs/2026-10-03-字卡五特性体系-design.md`（v7）§3、§12。

**拍板稿:** `docs/design/drafts/traits/` 下的以下几份。设计依据与回填写在同目录 `README.md`，其中 10-11 的拍板记录列出了各批定下的点。

## 体验对照清单(场景 → 顺序)

1. **拦截 · 玩家**
   - 场景:玩家身上有濯身 / 浇熄 / 杜绝,敌人挥击附带减速或灼(或灯花自灼)。
   - 顺序:
     1. 敌人下扑,飘伤害。
     2. 玩家底栏的 `ward`(只拦灼时是 `wardburn`)chip 白闪弹一下。
     3. 被挡的状态名(如「灼烧」)从该 chip 飘出:朱砂色、60%、压横线。
     4. 停 0.18s。
     5. 浇熄转出的「盾+N」在屏幕中下飘出。护盾角标的终值在重绘时更新。
   - 杜绝每挡一次数字减一,减到 0 后重绘时 chip 消失。
2. **拦截 · 木灵**
   - 场景:木灵身上有濯身 / 浇熄,敌人打木灵附带减速。
   - 顺序:
     1. 木灵格的免疫 chip 闪。
     2. 「减速」从 chip 飘出(墨蓝、60%、删除线)。
     3. 停 0.18s。
     4. 「盾+N」飘在**这只木灵**身上。
3. **拦截 · 敌人(禁增益)**
   - 场景:敌人身上有洗尽铅华,它给自己加攻。
   - 顺序:
     1. 敌人格的 `buffblock` chip 闪。
     2. 「增攻」类状态名从 chip 飘出(赭金、60%、删除线)。
   - 不停拍。
4. **杜塞**
   - 场景:Boss 身上有大招削弱,放大招。
   - 顺序:
     1. Boss 格的 `skillcut` chip 闪,「杜塞」(土色)从 Boss 飘出。
     2. 同一拍开始放招演出(前摇、扑击)。
     3. 伤害飘字照常,数字是削过之后的。
     4. 演完重绘,chip 消失。
5. **浮屠**
   - 场景:玩家挂了浮屠,上回合末有护盾,本回合开始。
   - 顺序:
     1. 回合初这批事件里,`shieldcarry` chip 闪。护盾角标若还在也闪。
     2. 「浮屠」从 chip 飘出。
     3. 停 0.18s。
     4. 「盾+N」在屏幕中下飘出。
     5. 演完重绘,chip 数字 3 → 2,护盾角标显示新的值。
6. **碎玉**
   - 场景:玩家护盾带碎玉,敌人一击把护盾打空。
   - 顺序:
     1. 敌人下扑,飘「盾吸收 / 掉血」。
     2. 玩家立绘左下的护盾角标闪,「碎玉」(土色)从角标飘出。
     3. 停 0.18s。
     4. 攻击者身上飘「-N」(土字形色),白闪掉血。
7. **嫁接**
   - 场景:把木字的生面拖到活木灵上。
   - 出字路径是先重绘再播,所以新本命 chip 已经在格子上。以下几件同时发生:
     - 木灵立绘白闪弹一下;
     - 「+回复量」(翠玉)飘出,伴随回血光圈。满血时回复量为 0,不飘数字;
     - 换上的本命 chip 闪。本命没有图标时不出 chip,也就不闪;
     - 「嫁接」从格子飘出,左侧带木色「生」印;
     - 播放回血音。
   - 底部消息条不再追加嫁接那句。
