# 护盾回合保留与木灵替换 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 护盾战斗内不再按回合清空（取消留存护盾），垒 / 塔 / 㙓 三条 Lv8 固面特性换新，木字生面拖到活木灵时可选嫁接或替换该格。

**Architecture:** Core 先落不改行为的部分（替换参数与查询、新取值方式、数据换行、删留存桶），每步 trace 两档恒等；最后单独一步删除回合清盾并更新 trace 基线。Presentation 接二选一弹窗、删浮屠 / 留存显示、新特性文案。

**Tech Stack:** Unity 6000.5.2f1；Core/Data 纯 C# 9；NUnit（`tools/coretests`）；Python 3 数据管线（`tools/pipeline`）与字体子集。

**Spec:** `docs/superpowers/specs/2026-10-13-护盾回合保留与木灵替换-design.md`（实现者必读全文；本 plan 与 spec 冲突时以 spec 为准）。上游 `docs/superpowers/specs/2026-10-03-字卡五特性体系-design.md` v7 §3、§3.1。

## Review Focus

1. **`Auto` 逐位不变**：不传新参数的出字（trace / balance / 旧 UI 路径）与改前事件流、RandomState 逐位相同。
2. **替换不触发阵亡**：被替换木灵的秋实 / 落木 / 藻荇等不兑现，光环随之移除；新木灵本命、光环、入场效果完整生效。
