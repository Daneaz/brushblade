## Review Focus
1. 可合成集并集只放开目标字本身:配方集里的「炎」不得让「焱/燚」变可合。
2. 生疏只作用于转盘配方得来的字;同一字若后来经奇遇送 / 本来已收集,不生疏(已收集优先)。
3. 生疏 ×70% 作用于所有效果数值且套在卡等级 Lv1 之后;Estimate 预估同口径。
4. 转盘只在 depth ≥ 11 的 Boss / 精英层战后出现;续爬存档时转盘未处理的状态要能恢复(或在战后结算同一步完成,不留悬空态)。
5. tools/balance 的 BotRunner 若复现 RunEngine 奖励流程,要么接入(机器人取转盘结果)要么明确跳过,不能编译失败。

## Task 1:Core —— 配方集 + 生疏
- `RunEngine` / `RunSnapshot` / `EndlessSaveState`:`RunRecipes`、`UnfamiliarChars`(生疏集)。
- 可合成集计算处(`ForgeEngine.ComposableSet` / `BattleEngine.ComposableChars` 及 BattleConfig 传参)并入配方集。
- 奇遇送未收集字 → 记入配方集(不进生疏集)。
- 生疏:BattleConfig 带生疏集;出字时该字卡等级取 1、效果值 ×70%(常量 `UnfamiliarPercent = 70`)。
- TDD,Commit `feat(run): 局内配方集与生疏`。

## Task 2:Core —— 配方转盘
- `RecipeWheel` 纯函数:输入 depth、已收集、配方集、字表、RNG → 5 格(4 低 + 1 高,分档表、候选优先可凑齐、不足补位、全空返回空)与落点(高档 10%)。
- `RunEngine` 战后流程:depth ≥ 11 且 Boss / 精英层 → 生成转盘结果,目标字进配方集 + 生疏集;暴露给 Presentation 的只读结果(5 格 + 落点下标)。
- TDD(含 10000 次抽样落点分布容差、分档、11 层前不出、普通层不出)。Commit `feat(run): 配方转盘`。

## Task 3:最小接线
- Presentation:战后若有转盘结果,先用现有提示 / 弹窗文案显示「获得配方:X(本局)」,再进选字;生疏字详情加一行文案。卡面标记与转盘 UI 等 designer 稿(`docs/design/drafts/recipe-wheel/`)。
- tools/balance:BotRunner 按真实流程接入(机器人自动收下转盘结果)或显式跳过,并说明。
- prescompile 0 error,三工装 build,pytest 七目录,字体子集,trace 两档新 sha。Commit `feat(battle): 配方转盘最小接线`。
