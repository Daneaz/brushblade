# 字卡特性 Plan D2-土：土系专属特性 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地土系的 35 条专属特性（spec v7 §9 土表），连同它们需要的护盾操作、受击挂点（单次伤害上限、受击护盾、碎盾反伤）、敌人 / 回合侧机制（溢出溅射、Boss 技能削减、AP 代价）与十项共用小扩展。

**Architecture:** 按「共用小扩展 → 护盾操作族 → 受击挂点族 → 敌人 / 回合侧 → 表现层 → 数据」推进。土系新分支集中到新 partial `Core/BattleEngine.Earth.cs`。复用 D2-火 / 金 / 水的通用件：水 W4 `DebuffWard`（`WardCount`，杜绝）、E14 `IsBoss` / `NotBoss`（杜塞）、W7 `TurnPulse`（重土）、Ruling 12 拍尾队列、金的格挡附带与斩杀族、火的 Retaliate / PerHit / 开局登记、Ruling 14 修订版（Reshape 叠加设计，碉 / 壁 / 垒 已有守护测试）。水预留的 W5「护盾载荷」与 W6「伤害载荷」只是注释，堡垒、碎玉各新建状态（G3 / G4），沿用原挂点位置。塔 / 堡 / 垒 / 崩 在 trace 卡池里，但 trace 杂食画像的 Shield 事件为 0——土的 Lv1 护盾路径不受 trace 守护，**必须靠「无新状态时逐位恒等」的单元对照测试**；`DamagePlayerDirect`、`BeginPlayerTurn` 等共享必经路径仍以 trace 两档 sha 为每个任务的硬验收。

**Tech Stack:** Unity 6000.5.2f1；Core/Data 纯 C# 9；NUnit（`tools/coretests`）；Python 3 管线；`tools/trace` / `tools/balance`。

**Spec:** `docs/superpowers/specs/2026-10-03-字卡五特性体系-design.md`（v7 + 2026-10-06 补充裁定，含「杜门不出压到 60%」）。**附录（逐条映射、拟写的特性表行、机制设计）：** `docs/superpowers/plans/2026-10-11-字卡特性-D2-土-附录-机制映射.md` —— 下文「附录 §x / E27–E36 / G1–G9 / Qn」均指它。附录与本 plan 冲突时以本 plan 为准。前序执行记录：D2-火 / 金 / 水 plan 末尾。管线保序（Ruling 13）已于 2026-10-11 合入 main。

## 已定口径

**用户授权**（2026-10-08 夜起沿用）：待裁定项由 controller 按推荐口径自行决定，事后汇报。附录 §4 Q1–Q22 **全部采用推荐口径**，要点：

- **Q1** 铜墙铁壁「单次受伤 ≤ 最大生命 10%」计入 §5.2 第 4 律 60% 非护甲减伤预算（与格挡、DamageCut 合计钳 60%）；玩家与木灵各按自身最大生命。
- **Q2** 杜门不出：AP 代价 = Buff 极性 Seal（G7：不被杜绝拦、不被净化清，复用封字 chip / 文案），`TurnsLeft 2`；「每场 1 次」= 整条特性每场一次（E35）。
- **Q3** 杜塞：杂兵 `Silence 0 turns 2 if NotBoss`；Boss `SkillCut 50 if IsBoss`（下一次大招伤害 ×50%，清盾 / 封字照常，吞噬秒杀不受影响，用掉即移除）。
- **Q4** 浮屠：加回「回合开始时被清掉的普通桶」× 50%，作普通桶，不攒厚，之后 3 个回合开始各一次，加回在判空移除载体之前。
- **Q5** 地裂：读出字前护盾（R3）；总击数 ≤ 5；除数 100；多打的每一击都是完整全体；伤害之后清两桶（G1，不触发冰晶 / 碎玉）。
- **Q6** 碎玉：打破 = 敌人挥击让两桶归零；量 = 该击吸收量 × 50%；同步结算、进 60% 反伤预算（镜 → 格挡 → 反震 → 碎玉）；心属性无视护甲；触发后移除。
- **Q7** 堡垒：只认玩家被敌人挥击命中（damage > 0）；每次都给、不限次数；量出字时定死；进普通桶并攒厚；多来源取最强。
- **Q8** 堵截「跳过下一次行动」= `Freeze 1`（R1：小怪冻结 + 霜抗，Boss 冰滞）。
- **Q9** 粉身碎骨：溢出 = 致死一击过护甲 / 敌盾后的实际伤害 − 击杀前生命；平分给其余存活敌人（Boss 算 1）；土属性、过生克与护甲、不暴击；溅射击杀不入队击杀时（R4）。
- **Q10** 塔倾：本体伤害之后两桶合计 × 50% 向下取整扣除，先扣普通桶，留存护盾也扣。
- **Q11** 塔基：攻面 `Reshape armorStrike 300`；固面 `Reshape armorShield 300`（E30，护甲取结算时 `EffectivePlayerDefense`）。
- **Q12** 山岳：护甲门槛 50（`EffectivePlayerDefense`）；`Retaliate 1 turns 4`；我方（玩家 / 木灵）受击都算；门槛不满足不扣次数。
- **Q13** 三山与移山同面：三山散射覆盖移山贯穿；移山的 shieldStrike 30 留在三山首发（叠加设计）；镇压逐发结算（E31）。
- **Q14** 对峙：`Taunt 1 pick Self` 给玩家；吞噬仍杀最前木灵（维持现口径）；开局护甲 `DefenseBuff 38 turns 4 battles 5`。
- **Q15** 碉楼 / 载物「护盾同时给全部木灵」：50% × 本次出字名义护盾量（E28），每只存活木灵，不额外攒厚，吃木灵护盾上限。
- **Q16** shieldStrike 在 Column / All 下维持现实现（每个主目标第一段加）。
- **Q17** 垒砌 / 厚德载物拖到木灵上：persist 空转、护盾照给。
- **Q18** 土生金：扣两桶合计 30%，战意 + ⌈扣除量 / 100⌉（≥1，钳上限，不计溢出）；不触发冰晶 / 碎玉。
- **Q19** 落石「获得护盾」= 本体护盾；减攻 `Weaken 20 turns 1 pick All`。
- **Q20** 减伤 chip：`drafts/traits/StatusChips.dc.html` 里「减伤 / 反击加倍 / 保命」三枚自 2026-10-04 `待审`，**需用户拍板**；拍板前不画（V5 门控），不阻塞合并。
- **Q21** 不发新稿：HitCap 复用减伤 chip（门控同上）；ApCost 复用封字 chip；HurtShield、ShieldShatter、SkillCut、ShieldCarry 先隐藏进豁免表。
- **Q22** 数值起值按附录（Plan F 重定）。
- **Ruling 15（本 plan）**：管线 `_attach_battles` / `_positional_hosts` 按 `` `Kind `` 字样回找宿主，kind 与 token 不同名时（`MoraleFill` / `WellspringFill` / `DispelAll`）可能静默挂错——Task 1 改为用 Ruling 13 记下的真实位置找宿主，chars.json 重新生成须逐字节不变。
- **E34**：删除 `RunEngine` 战后携带白名单中的 DefenseBuff 项（否则圭臬会变成整段永久护甲）；现数据下恒等，须测试钉住。
