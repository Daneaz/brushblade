> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地破甲 6 字与穿甲 3 字,让「甲」这个既有的承伤系数第一次可被玩家操作。

**Architecture:** 不新建护甲概念——复用 `EnemyState.DamageTaken`。破甲是挂在敌人身上的 `Debuff` 状态

承伤结算拆成「减免」与「加成」两条路径,前者遭克失效、后者始终生效。

**Interfaces:**
- Consumes: `EnemyState.DamageTaken`(float,`< 1` 即减伤)、`WuxingResolver.KeMultiplier`
- Produces: `DamageEnemy` 内部的 `taken` 变量结构,后两个任务在此基础上加分支

**背景**:现有写法把「减免」与「加成」混在一个条件里:

```csharp
// 承伤减免(坚壁/「山」类)遇属性克制失效:被克(×1.5)直接按克制结算,不再乘减免
if (enemy.DamageTaken != 1f && WuxingResolver.KeMultiplier(attacker, enemy.Element) < 1.5f)
    damage = (int)Math.Floor(damage * enemy.DamageTaken);
```

判断是 `!= 1f`。等 Task 2 把承伤升到 `1.25`,同样满足 `!= 1f` ——
于是**用克制属性打破了甲的敌人,破甲加成会被这条规则一起吃掉**。本任务先把结构拆好。

⚠️ 本任务**不改变任何现有行为**:当前引擎里没有任何 `DamageTaken > 1` 的来源,
所以改动只影响「加成 + 克制」这个当前不可达的组合。580 条测试必须全绿且断言一条不改。
