# 土系破甲归零 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 土系破甲改为「持续期间护甲归零（Boss 减半）」，金/火原扣点破甲改名削甲、机制不变。

**Architecture:** 新增 `EffectKind.Sunder` / `StatusKind.Sunder`（枚举末尾追加）承载新破甲；现有 `ArmorBreak`（扣点）机制原样保留，只把玩家可见名改成「削甲」。土系数据从 `ArmorBreak N` 改写为 `Sunder`；Sunder 在护甲计算里作为「基础护甲改写」，削甲点数在其后扣。

**Tech Stack:** C#（Core/Data 纯 C#，dotnet 工装）、Python 数据管线、Unity Presentation。

**Spec:** `docs/superpowers/specs/2026-10-21-土系破甲归零-design.md`

## Global Constraints

- 枚举只在末尾追加（存档 / 配置按序号）。
- Core 与 Data 禁引 UnityEngine；测试断言禁用 `Is.AnyOf`、非 string 的 `Does.Not.Contain`、Newtonsoft、`AppContext.BaseDirectory`（见 CLAUDE.md）。
- `chars.json` 是管线产物：改详表 / 特性表 → `extract_values` → `export_chars`，不手改。
- 玩家可见文案走 `strings.zh-CN.json`；改完重跑 `python3 tools/fonts/subset_fonts.py`。
- 新战斗状态三处接线：`StatusText.Of`、`BattleView` chip 列表、`CharInfo.EffectsText`。
- worktree 里 prescompile 加 `-p:ProjectAsm=/Users/eugenewu/code/game/Brushblade/Library/ScriptAssemblies`。
- 只提交自己改的文件。

## Review Focus

- Boss 同时带封禁 + 破甲：护甲应为 `Defense/2`，不是 `Defense/4`。→ Task 1 测试 `Sunder_WithSilence_BossStillHalf`。
- 破甲 + 削甲叠加：先归零/减半再扣点，结果下钳 0（Boss 护甲 100、削甲 30 → 20）。→ Task 1 `Sunder_ThenShred_BossHalfMinusPoints`。
- 第二次施加更短的破甲不得缩短剩余回合。→ Task 1 `Sunder_ReapplyShorter_KeepsLonger`。
- 崩裂/厚壤厚为 0 时仍给 1 回合；Sunder.Value（每 k 层）不吃卡等级。→ Task 1 `Sunder_PerSpent_*`。
- 护甲 chip / 详情弹窗显示数与实际结算一致（都读 `DisplayedEnemyDefense`）。→ Task 1 `DisplayedEnemyDefense_HonorsSunder`。
