# 字卡特性 Plan D2-火：火系专属特性 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地火系 11 字的 44 条专属特性（spec v7 §9 火表），连同它们需要的灼操作、灼附着、敌人出手前挂点等机制，并修掉调研中发现的四个现存问题（烟熏在燃面空转、开局登记未落地、特性减攻与本体同源合并、致盲相加）。

**Architecture:** 机制按「共用小扩展 → 灼操作族 → 灼附着族 → 出手前 / 受击挂点 → 单点效果 → 表现层 → 数据」推进。火系新分支集中到新 partial `Core/BattleEngine.Fire.cs`，避免 `ApplyEffects` 的 switch 继续膨胀；开工前先把 `ApplyEffects` 的十余个出字瞬时字段收拢成一个 cast-context（D2-0 E13）。所有新挂点在没有对应状态 / 字段时一次判断即短路、不摇随机数，因此对 trace 恒等（数据全在 Lv4+，trace 用全 1 级卡组）。

**Tech Stack:** Unity 6000.5.2f1；Core/Data 纯 C# 9；NUnit（`tools/coretests`）；Python 3 管线；`tools/trace` / `tools/balance`。

**Spec:** `docs/superpowers/specs/2026-10-03-字卡五特性体系-design.md`（v7 + 2026-10-06 补充裁定）。**附录（逐条映射、拟写的特性表行、机制设计、行号）：** `docs/superpowers/plans/2026-10-08-字卡特性-D2-火-附录-机制映射.md` —— 下文「附录 §x / E1–E5 / N1–N13」均指它。前序执行记录：D1、D2-0、E1 plan 末尾。
