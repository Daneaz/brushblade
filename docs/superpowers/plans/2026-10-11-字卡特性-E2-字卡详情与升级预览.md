- **C1「此刻的场面」**：2026-09-05 用户曾要求移除（`d3cab4a2`），10-04 拍板稿又加了回来，2026-10-11 用户确认「designer 的稿全部可以」。按稿做，key `charsheet.section.field` 复活。

- **Q10 锁图标**：走管线新增 `lock`，三处对账，兜底字「锁」。
- **Q11 战斗版两面条压单行**：新写 `Ui.Truncate`。
- **Q12 木生面落点句**：用短句「空位召唤 · 木灵嫁接」，回填稿的 README。

- **Q14 升级预览两栏放不下**：两栏各包一层 `Ui.ScrollList`；左栏先列攻面差，再列五行面差。
- **Q15「不变」**：列已解锁特性名（等级 ≤ L），Lv1 不列。
- **Q16**：奖励阶段和战利品候选没有活着的敌人，右栏退回静态生克。
- **Q17 未解锁行的数值**：按 `max(卡等级, 解锁等级)` 印。

  - `LadderMarks(CharDef, int level)`
  - `FaceTraits(CharDef, CardFace, int cardLevel)`

  - `Deltas(CharDef, int fromLevel, int toLevel) → IReadOnlyList<StatDelta>`
  - `Lv3Change(CharDef, CardFace) → IReadOnlyList<StatDelta>`，供 Q2 的「本体差」使用。
- `BattleEngine.TraitSpentThisBattle(CharDef, TraitDef) → bool`

**测试**（读真实字表，用例照附录 §6，断言确定值）：
- LadderMarks：55 张字全量检查——Lv5 / Lv8 恰好两枚；Lv1 / 3 / 4 恰好一枚 Both；Lv6 一枚，等于该字 Lv6 的面；Lv2 / 7 / 9 / 10 为空。
- FaceTraits：
  - 炎 Attack L6 → [Lv5 火上浇油（已解锁）, Lv8 炎刃（未解锁）]
  - 炎 Feature → [Lv5 续火, Lv6 上炎, Lv8 炎炎]
  - Lv1 / Lv3 / Lv4 不出现，按槽位升序。
- SharedTraits：每张字恰好一行 Lv3；Lv4 分面的 22 张字合成一行，且 `Defs.Count == 2`；Lv1 不出现。
- UnlockedAt / NextUnlock：
  - UnlockedAt：L=5 → 2 行；L=6 → 1 行；L=2 / 7 / 9 / 10 → 0 行。
  - NextUnlock：(炎, 1) → 3；(炎, 6) → 8，两行；(任意字, 8) → (0, 空)。
- FaceStats.Body：
  - 炎 Attack L1 = [伤害 168, 灼 3]；L3 时灼为 4。
  - L10 伤害 = `ScaleByCardLevel(168, 10)`；层 / 回合不随等级缩放。
  - 55×2 面每面 1–3 格，生面也要有召唤的血 / 攻。
- Deltas：L1→L2 只有可缩放数值变化；L2→L3 出现层 / 回合的变化；没有变化时返回空表。
- Lv3Change：炎 Attack 返回「灼 3→4」。
- TargetOf / AreaOf：55×2 面全部落在四类之一；剑 Attack L8 为横扫、L1 为单体；木生面为 Summon，且 AreaOf 返回 null。
- TraitSpentThisBattle：杜 Lv8 生面出一次后为 true；下一场恢复为 false；快照往返后仍为 true；没有次数限制的特性恒为 false。
- **Review Focus 2**：断言 22 张字 Lv4 的两条 `Defs` 都在；断言 11 张字 Lv3 不同名时，两个名字都能取到。
