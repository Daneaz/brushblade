# 轮二 · 单位详情 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 战斗里点敌人 / 召唤物 / 执笔人，弹同一张详情——立绘 + 名与四条数值 + 左「身上的状态」右「特性·技能」+ 底部提示行；状态逐条带说明。

**Architecture:** 三类单位共用一个骨架，只换内容不换版式。`EnemyInfo` / `SummonInfo` 从「返回整段拼好的文本」改成「返回逐条结构」，新建 `UnitSheet` 负责画。**不做二级弹窗**——玩家点开详情正是为了对着战场看，弹窗上再弹一层就得先关掉才看得回去。

**Tech Stack:** Unity 6000.5.2f1（勿升版本）、uGUI、C#、Python 3（字体管线）。

**Spec:** `docs/superpowers/specs/2026-08-30-战斗屏与局内流程接稿-design.md`（轮二一节）

**权威稿:** `docs/design/ui/scenes/UnitFoe.dc.html` / `UnitAlly.dc.html` / `UnitMe.dc.html` / `StatusGlossary.dc.html`

## Global Constraints

- **Core 与 Data 禁止引用 UnityEngine**（asmdef `noEngineReferences: true`）。本轮改动主要在 Presentation。
- **随机性一律走 Core 内带种子的 RNG**，禁用 `UnityEngine.Random`。本轮不该新增随机。
- **玩家可见 UI 文案走字符串表**（`Brushblade/Assets/StreamingAssets/config/strings.zh-CN.json`），禁止硬编码。
- **新增任何玩家可见中文后必须重跑字体子集**：`python3 tools/fonts/subset_fonts.py`，然后 `python3 -m pytest tools/fonts/tests/ -q`。**光看 diff 大小说明不了变没变，要比 cmap。**
- ⚠ **注释里不要用半角双引号包中文**。`subset_fonts.py` 的 `_STRING_RE` 对 `.cs` 全文扫描、不区分注释，半角引号里的中文会被当成玩家可见文案进 charset，导致字体测试变红。用「」。（轮一栽过一次。）
- **新增 `.cs` 必须带 `.meta` 一起入库**（仓库里每个 `.cs` 都有）。
- **提交信息用 conventional commits**（feat/fix/docs/chore + 范围），中文正文，结尾 `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`。
- **提交前跑 `git status` 确认工作区干净**。字体产物落点是 `Brushblade/Assets/_Project/Presentation/Fonts/Resources/*.ttf` 与 `tools/fonts/charset.txt`。
- **单位换算 1pt = 2.093 逻辑单位**（稿基准 iPhone 16 Pro Max 横屏 932×430pt → 逻辑画布 1950×900）。写常量时在旁注明稿上的 pt 值。
