### Task 2: Core — 护甲格规则与锋刃回鞘显示百分比

**Files:**
- Create: `Core/ArmorCellRules.cs`
- Modify: `Core/Meta.cs`（或 `MetaRules` 所在文件）加 `EdgeSheatheShownPercent(MetaState)`
- Modify: `Core/BattleEngine.cs` 加实例属性 `public int EdgeSheatheShownPercent => EdgeSheathePercent + (_config?.MoraleReleasePercent ?? 0);`，并让 L~3477 的 `edgePercent` 读它（行为不变）
- Test: `Tests/ArmorCellRulesTests.cs`、`Tests/EdgeSheatheShownPercentTests.cs`

**Interfaces（Produces）:**
```csharp
public enum ArmorCellKind { Normal, Shred, Sunder }
public readonly struct ArmorCell { public bool Visible; public ArmorCellKind Kind; public int Value; public bool ShowValue; }
public static class ArmorCellRules {
    public static ArmorCell ForEnemy(EnemyState enemy);                       // Value = BattleEngine.DisplayedEnemyDefense(enemy)
    public static ArmorCell ForUnit(int baseDefense, int shownDefense, StatusBag statuses, bool isBoss);  // 玩家/召唤物共用
}
public static int MetaRules.EdgeSheatheShownPercent(MetaState meta);         // 100 + PerkRules.ElementBonus(meta, MoraleRelease, Metal)
public int BattleEngine.EdgeSheatheShownPercent { get; }
```
规则（取自稿规则表）：基准护甲（未减前，含增益）≤ 0 → 不出格；带 Sunder → `Sunder`，`ShowValue = isBoss`；否则带削甲（ArmorBreak 量 > 0）→ `Shred`，`ShowValue = true`（0 也印）；否则 `Normal`，`Visible = shownDefense > 0`（封禁让杂兵归零时隐藏，同现行）。
