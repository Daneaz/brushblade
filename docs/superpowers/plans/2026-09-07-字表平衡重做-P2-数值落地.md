> **这是全批的地基。** `extract_values.py` 全文零个 `raise`/`assert`/`SystemExit`,三类东西会静默消失:
> 1. **无数值 token** 不在 `VALUELESS_EFFECTS` 里、也没有专门分支 → 静默忽略;
> 2. **`turns N`** 挂在不属于 `DURATION_KINDS` 的 kind 上 → 静默丢弃(spec §3 第 20 项正是这条);
> 3. **召唤行上的非召唤 token** → 静默丢弃,因为召唤分支 `return [effect]` 提前返回(见 Task 2)。
>
> T4 要改 57 行数据。**没有这张网,改错了没人知道** —— 这正是项目记忆里那条「手写映射表认不得的标记会无声消失」。

### Task 2: 补齐目标表需要、而解析器不认的 token

**Files:**
- Modify: `tools/pipeline/extract_values.py`
- Modify: `tools/pipeline/tests/test_extract_values.py`

**Interfaces:**
- Consumes: Task 1 的报错防线(它会告诉你缺哪个)
- Produces: 解析器认得 `Charm` / `AuraAttack` / 限时增益的 turns / 召唤行上的非召唤效果

> **由 T1 的红灯驱动**:先把目标表里的新写法往详表里试写一行,看 T1 报什么错,再补对应的解析。**不要凭这份清单一次性猜完** —— 清单可能不全,红灯才是权威。

已知至少要处理这四类:

1. **`Charm`(魅惑)**:`EffectKind.Charm` 的 `Value` 不用、`Turns` 才是回合数。写法定为 `` `Charm 0`(turns 1) ``,并把 `Charm` 加进 `DURATION_KINDS`。
   ⚠ 不加进 `DURATION_KINDS` 的后果:`turns` 被 T1 的防线拦下报错(好),但如果有人为了绕过报错去删 `turns`,魅惑就变成了 0 回合 —— 引擎侧 `Math.Max(1, effect.Turns)` 会兜成 1 回合,**看起来能用、实际永远是 1 回合**,卡等级也不影响它。所以必须加。
2. **限时增益的 `turns`**:`利`(增攻 +30 × 2 回合)、`锋`(暴击 +20% × 3 回合)。`Empower` / `CritBuff` 要加进 `DURATION_KINDS`。
3. **`AuraAttack`(攻击光环)**:新的 `SUMMON_PASSIVE` 条目(`"AuraAttack": "auraAttack"`)。载体是 `𣛧`。
4. **召唤行上的非召唤效果** —— 这是**硬阻塞**:
   ```python
   summon = re.search(r"`Summon (\d+)`\((\d+) 血/攻 (\d+)\)", config)
   if summon:
       ...
       return [effect]      # ← 提前 return,同行其它 token 全丢
   ```
   spec §2 要求土系召唤字(`碉`/`堡`/`塔`)**补入场护盾** —— 写成 `` `Shield 40` `` 会被这个 `return` 静默吞掉。
   **改法**:召唤分支不再提前 return,把召唤效果**追加**进 `effects` 后继续走通用循环(通用循环里要跳过 `Summon` 本身与它的参数,免得重复解析)。
   ⚠ 改完必须确认既有召唤字(`枪`/`藤`/`楸`/`荆`/`林`/`柘`/`森`/`桂`/`藻`/`𣛧`/`碉`/`堡`/`塔`/`锥`/`剑`)的产物**逐字节不变**。

```python
# -*- coding: utf-8 -*-
"""chars.json 与 spec §6 目标表的对账(2026-09-07,P2 Task 3)。

P2 要改 57 字的数值与特性。人肉比对必错,所以把「改对了没有」变成一条测试。
目标表由 tools/design/rebalance_2026_09_05.py 从 §1.4 锚点 + §1.4.1 价目表推出
(改规则要回到 spec,不要改这里的期望值)。

⚠ 本测试在 P2 落地完成前会红 —— 那是进度条,不是故障。
"""
import json
import subprocess
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parents[3]
CHARS = ROOT / "Brushblade/Assets/StreamingAssets/config/chars.json"
SCRIPT = ROOT / "tools/design/rebalance_2026_09_05.py"

# gen_char_doc / export_chars 的 PUA 代理:增补平面字在 UGUI 显示不出代理对,
# 落配置时换成私有区码位。对账要还原回真实字,否则两边永远对不上。
PUA_BACK = {"": "𣛧", "": "𨰻"}
RARITY = {"白": "White", "绿": "Green", "蓝": "Blue", "紫": "Purple",
          "金": "Gold", "橙": "Orange", "红": "Red"}


def _target():
    out = subprocess.run([sys.executable, str(SCRIPT)], capture_output=True,
                         text=True, cwd=ROOT).stdout
    rows = {}
    for line in out.splitlines():
        if not line.startswith("| ") or line.startswith("| 字 ") or line.startswith("|---"):
            continue
        cells = [c.strip() for c in line.split("|")[1:-1]]
        rows[cells[0].split("(")[0]] = cells
    return rows


def _actual():
    chars = json.loads(CHARS.read_text(encoding="utf-8"))["chars"]
    return {PUA_BACK.get(c["id"], c["id"]): c
            for c in chars if not c.get("component")}


def test_roster_matches_target():
    """字表的字集与目标一致 —— 多一个少一个都要报出来。"""
    target, actual = set(_target()), set(_actual())
    assert not (target - actual), f"目标表有、配置里缺:{sorted(target - actual)}"
    assert not (actual - target), f"配置里有、目标表已移出:{sorted(actual - target)}"


def test_rarity_matches_target():
    target, actual = _target(), _actual()
    bad = [(k, actual[k]["rarity"], RARITY[target[k][2]])
           for k in sorted(set(target) & set(actual))
           if actual[k]["rarity"] != RARITY[target[k][2]]]
    assert not bad, "稀有度与目标表不符(字, 实际, 目标):\n  " + "\n  ".join(map(str, bad))
```
