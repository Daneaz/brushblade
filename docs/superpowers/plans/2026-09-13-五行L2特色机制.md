> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把五行技能树五枝的 L2 从同质的「战利品保底 1 张该系」改成五条各系专属的战斗机制(水=溢流、火=余烬、金=锋芒、木=归根、土=反震)。

**Architecture:** 五条机制全部走既有的 `PerkNodeDef.Value` → `PerkRules.ElementBonus` → `BattleConfig` 字段这条注入链,缺省 0 = 关。引擎侧各挂一个钩子,不新增 `StatusKind`、不新增 `BattleEventKind`、不改存档结构。战利品定向坑那条供给链路整条删除。

## Global Constraints

以下每条都是硬约束,每个任务的验收都隐含包含它们。

1. **Core 与 Data 禁止 `using UnityEngine`** —— asmdef 已设 `noEngineReferences: true`。用 `System.Math.Min`,不要 `Mathf.Min`。
2. **随机性一律走引擎内带种子的 `_random`(`GameRandom`)**,禁用 `UnityEngine.Random`。
3. **恒等性硬线**:五个 `BattleConfig` 新字段全为 0 时,引擎行为必须与改前**逐字节相同**。尤其是**一次随机数都不许多摇** —— `GameRandom` 的既有消费方只有 `StartTurn` 的回合掉字、`AttackHits`、`EnemyState` 构造时的 Boss 阈值浮动;多摇一次会平移整条随机序列,让所有依赖种子的既有测试一起变红。
4. **玩家可见中文一律走字符串表** `Strings.T(key, args)`,禁止硬编码。key **必须是字面量**,不能拼接(`Strings.T($"perk.detail.{x}")` 会让 key 被 `StringsTableTests.EveryTableKey_IsUsed` 判成孤儿)。
5. **改动任何玩家可见中文后必须重跑字体子集**:`python3 tools/fonts/subset_fonts.py`,然后 `python3 -m pytest tools/fonts/tests/ -q`。游戏打包的是子集字体,新字不在里面真机上就是豆腐块,而离线编译和 Core 单测都发现不了。
6. **NUnit API 限制(工装绿 ≠ 编辑器绿)**:禁用 `Is.AnyOf` / `Is.All.AnyOf`;`Does.Not.Contain(x)` 只在 x 是 string 时能用,集合判包含一律写成 `Assert.That(list.Contains(x), Is.True/False, "…")`;定位仓库根只能用 `TestContext.CurrentContext.TestDirectory`;测试**禁止引用 Newtonsoft**。
7. **只改 `Brushblade/Assets/StreamingAssets/config/strings.zh-CN.json`**。`Brushblade/Builds/iOS-Device/Data/Raw/config/strings.zh-CN.json` 是打包产物,不要手改。
8. **本任务不新增 `StatusKind`、不新增 `BattleEventKind`、不新增图标**。因此 CLAUDE.md 里「新增战斗状态三处必须同时接」那条纪律本次不适用。
9. **提交信息用 conventional commits**(`feat`/`fix`/`docs`/`chore` + 范围),结尾附 `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`。
