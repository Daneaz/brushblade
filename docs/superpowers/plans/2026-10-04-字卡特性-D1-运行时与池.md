## Task 1：反应队列、重入守卫与钩子口径（恒等）

**目的**：Plan A R8 阻断项。监听器只入队、不结算；`ApplyEffects` 不可重入；队列只在动作末尾排空。顺带修 Plan A / C 留下的钩子口径与嵌套恢复问题（附录 §1.2–§1.4）。

**Files**：

**Interfaces**（Produces）：
```csharp
// Core/BattleEngine.Traits.cs
public sealed partial class BattleEngine   // 若 BattleEngine 现为非 partial,改为 partial(两处声明一致)
{
    /// <summary>一条待结算的特性反应。只在安全点排空。</summary>
    internal readonly struct Reaction
    {
        public readonly string SourceCharId;
        public readonly Element Element;
        public readonly IReadOnlyList<EffectDef> Effects;
        public readonly int TargetIndex;   // 敌人下标;-1 = 不选敌
        public readonly int Depth;         // 入队时的 TriggerDepth + 1
        public Reaction(string sourceCharId, Element element, IReadOnlyList<EffectDef> effects, int targetIndex, int depth) { … }
    }

    private readonly Queue<Reaction> _reactions = new Queue<Reaction>();
    private bool _inApplyEffects;
    internal const int MaxReactionsPerDrain = 64;

    /// <summary>入队。战斗已分胜负时丢弃。</summary>
    internal void Enqueue(in Reaction reaction);

    /// <summary>FIFO 排空;每条走 ApplyDetachedEffects(深度 = reaction.Depth)。
    /// 单次排空超过 MaxReactionsPerDrain 抛 InvalidOperationException(死循环保险)。
    /// Phase 为 Won/Lost 时清空队列直接返回。</summary>
    internal void DrainReactions();

    internal int PendingReactionCount => _reactions.Count;
}
```
- `ApplyEffects` 进门：`if (_inApplyEffects) throw new InvalidOperationException("ApplyEffects 不可重入:特性反应必须入队,在安全点排空");`，进门置 true，`finally` 置 false。`ApplyDetachedEffects` 照旧调用 `ApplyEffects`，所以它只能在安全点（队列排空 / 构造函数开局效果）被调用。
- **安全点**（在每处末尾调用 `DrainReactions()`）：
  1. `Cast`：`ApplyEffects` 之后、`RefreshSummonAura` / `CheckWin` 之前。
  2. `ActEnemyTurn`：每次 `ActOneEnemy` 动作之后；三个 `return` 出口统一为「排空 → `Raise(TurnEnded)` → 再排空」。
  3. `ActSummonTurn` 末尾（含烧死的提前 return）。
  4. `BeginPlayerTurn`：`Raise(TurnStarted)` 之后。
  5. `Compose` / `Dismantle` 末尾。
  6. `YieldTurn`：`Raise(TurnEnded)` 之后。
  7. 构造函数：开局效果之后、开场 `AdvanceOnce` 循环之前。
- **嵌套恢复**（Plan C 交接项 2）：`ApplyEffects` 现在对 `_preCastConditions` 做保存 / 恢复；改为「外层快照优先」——`ApplyDetachedEffects` 调用时若外层快照非空（理论上排空时为空，保险起见）沿用外层。`_castCritBonus`、`_critMoraleGrantedThisCast` 一并在进门时保存、`finally` 恢复。
- **DOT 致死补发 TurnEnded**：`ActEnemyTurn` 里灼烧 / 流血结算致死的 `return`、`ActSummonTurn` 烧死的 `return`，都补 `Raise(TurnEnded)`（附录 §1.2 表）。
- **钩子口径**（Plan A 前置项）：
  - `AddPlayerCounter` 已有状态做增量时补发 `StatusApplied`（Amount = 增量后的总量，与首次挂上同口径）。
  - `GainStacks` 只在层数确实增加时调用 `ApplyStatus` / 发事件。
  - 铁画反噬调用 `DamagePlayerDirect` 时传 `source: EffectSource.IronBarb`（若无此枚举值则追加），PlayerHit 带上来源。
  - `HookArgs` 追加两个字段（构造参数带缺省值，既有调用不变）：`int Absorbed`（PlayerHit / SummonHit：护盾吸收量）、`string CastCharId`（EnemyHit / EnemyKilled：正在出字的字 ID，非出字时为 null）。引擎在 `Cast` 期间记 `_castingCharId`。
  - `BattleHooks.cs` 的 `HookKind` 注释改为 spec v7，并把每种钩子的 `Amount` 口径写清（附录 §1.2 末段）。

  using System;
  using System.Collections.Generic;
  using System.Linq;
  using Brushblade.Core;
  using NUnit.Framework;

  namespace Brushblade.Core.Tests
  {
      /// <summary>反应队列(Plan A R8):监听器只入队;ApplyEffects 不可重入;安全点排空;死循环保险。</summary>
      public class ReactionQueueTests
      {
          private static readonly CharDef Hit = new("击", Element.Heart,
              effects: new[] { new EffectDef(EffectKind.DamageSingle, 100) });

          private static BattleEngine Battle(params string[] library) =>
              RebalanceFixture.Battle(RebalanceFixture.Graph(Hit), library, RebalanceFixture.Mob(attack: 1));

          /// <summary>收到 EnemyHit 时入队一条「再打 10」的反应。</summary>
          private sealed class EchoOnHit : IBattleHookListener
          {
              public int Seen;
              public void OnHook(BattleEngine b, in HookArgs a)
              {
                  if (a.Kind != HookKind.EnemyHit || a.Depth > 0) return;
                  Seen++;
                  b.Enqueue(new BattleEngine.Reaction("回", Element.Heart,
                      new[] { new EffectDef(EffectKind.DamageSingle, 10) }, a.Subject.Index, a.Depth + 1));
              }
          }

          [Test]
          public void ListenerEnqueues_DrainedAtEndOfCast()
          {
              var b = Battle("击");
              var echo = new EchoOnHit();
              b.AddHookListener(echo);
              int hp = b.Enemies[0].Hp;
              b.Cast("击", 0);
              Assert.That(echo.Seen, Is.EqualTo(1), "深度 1 的回响不再触发回响");
              Assert.That(b.PendingReactionCount, Is.EqualTo(0), "出字结束时队列已排空");
              Assert.That(b.Enemies[0].Hp, Is.LessThan(hp - 100), "回响那一下也打出去了");
          }

          private sealed class SyncReentrant : IBattleHookListener
          {
              public Exception Caught;
              public void OnHook(BattleEngine b, in HookArgs a)
              {
                  if (a.Kind != HookKind.EnemyHit) return;
                  try { b.ApplyDetachedEffects("坏", Element.Heart, new[] { new EffectDef(EffectKind.DamageSingle, 1) }, 0); }
                  catch (InvalidOperationException e) { Caught = e; }
              }
          }

          [Test]
          public void SynchronousResolveInsideCast_Throws()
          {
              var b = Battle("击");
              var bad = new SyncReentrant();
              b.AddHookListener(bad);
              b.Cast("击", 0);
              Assert.That(bad.Caught, Is.Not.Null, "出字途中同步结算必须响亮失败");
          }

          private sealed class Forever : IBattleHookListener
          {
              public void OnHook(BattleEngine b, in HookArgs a)
              {
                  if (a.Kind != HookKind.EnemyHit) return;
                  b.Enqueue(new BattleEngine.Reaction("环", Element.Heart,
                      new[] { new EffectDef(EffectKind.DamageSingle, 1) }, a.Subject.Index, a.Depth + 1));
              }

          public void RunawayReactions_HitTheCap()
          {
              var b = RebalanceFixture.Battle(RebalanceFixture.Graph(Hit), new[] { "击" },

              b.AddHookListener(new Forever());
              Assert.Throws<InvalidOperationException>(() => b.Cast("击", 0));
          }

          [Test]
          public void NoListeners_TraceIdentical_QueueUntouched()
          {
              var b = Battle("击");
              b.Cast("击", 0);
              Assert.That(b.PendingReactionCount, Is.EqualTo(0));
          }
      }
