## 需设计 / 实机复核

- BattleView.cs:3954「出」现为石青,旁边「拆」是 `split-blue #194F81`——两颗蓝挨着,要看实机是否分得清。
- 战斗底栏同屏有「出」与「结束回合」两颗石青(出只在选中字时出现),是否违反「一屏最多一颗主钮」待定。
- BattleView.cs:5570「确认顶替召唤物」:顶替会让在场召唤物消失(战内不可逆),本次按「确认类主钮」给了石青;若要算不可逆,改 `Ui.DangerOutline`。
- BattleView.cs:4452 / 4602「再点一次收下」用 CinnabarDark 文字,语义是推进提示不是危险,下一步可考虑改色。
- `tokens.json` 的 `shadow-cta` / `shadow-cta-lg` 仍是朱砂色阴影(rgba(155,30,34,…)),设计卡改石青时要一起换。
- `.zd-btn--cta` 原本就是「主行动尺寸」类,本次在它上面补了石青底;两张旧卡(Button、HomeScreen 的「续爬」)仍写着 `.zd-btn--cta.zd-btn--cinnabar`,改卡时去掉 `--cinnabar`。
