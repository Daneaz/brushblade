技能星域的节点：52 逻辑单位见方、圆角 20（近乎正圆），里面一枚图标（22）+ 两字名（13 宋体），三段节点名下再加一排段位点；对应实现 `PerkView.BuildNode`。

## 画布上只分三类
| 类 | 画法 |
| --- | --- |
| `zd-node--own` 已点亮 | 枝色浅底（`--soft`）+ 2 逻辑单位枝色边；图标枝色，名 `text-main` |
| `zd-node--buy` 可解锁 | 白底 + 2 逻辑单位枝色边 + 枝色外发光（墨晕外扩 10）—— 全屏最亮的那一格 |
| 未解锁（默认） | `locked-bg` 纯灰底、不描边。墨锭不足时图标仍是枝色、名 `text-main`；前置未点 / 等级未到（`zd-node--gated`）图标与名一起压成 `text-faint` |

五种判据（已点 → 前置 → 等级 → 墨锭，`PerkView.StateOf`）在代码里仍然分开，但**差几级、差多少墨、缺哪侧前置只在详情弹窗里说**；画布要的是「能点 / 不能点 / 已经点了」这一眼的层次（2026-09-08 定）。

## 三段节点（五行 L1 / L2，2026-10-02）
- 画布上一个节点只画一格，判的是它的**当前段**（第一个未点亮的段；全点亮取末段）。
- 名字下面一排 3 枚段位点：点径 5、间距 2；已点亮的段用枝色（gated 时 `text-faint`），未点的段 `paper-dim`。
- **已点过至少一段**时：下一段可点 → 按「可解锁」画（白底 + 外发光，段位点照样显示进度）；下一段卡在等级或墨锭 → 按「已点亮」画（已经付过钱的节点不画成灰底）。三段全点亮自然是已点亮。

## 其余元素
- **跨树节点**：外圈 16 个小圆点（点径 5）的虚线环（离节点边 7），前置未点 / 等级未到时一起压成 `text-faint`，墨锭不足时仍是 `heart`；不画任何连线，前置关系在详情里说。
- **连线**：3 逻辑单位直线连同枝上一层。L2 以上按**上一层是否已点亮（任一段）**上色；L1 连树根，这一段按 **L1 自己是否已点亮（任一段）**上色（树根是分区标记、没有点亮态）。未点亮一律 `panel-border`。
- **中心「斗」**：直径 88 的 `ink` 圆，宣纸色宋体 34。**树根**：直径 64 的 `panel-inset` 圆，写树名（宋体 18 `text-dim`），不可点。
- **图标**（`PerkNodeIcons.KeyFor`）：17 枚撑起 43 个节点，三段节点三段共用一枚。
  - 五行 L1 专精按系：金 `crit` · 木 `perk_hp` · 水 `heal` · 火 `burn` · 土 `shield`
  - 五行 L2 本系效果值五系共用 `perk_amplify`（形状说效果、颜色说哪一系）
  - 五行 L3 专属机制：金 `morale` · 木 `perk_hp` · 水 `heal` · 火 `scorch` · 土 `shield`
  - 五行 L4：金 `morale` · 木 `focus` · 水 `perk_wellspring` · 火 `burn` · 土 `perk_heft`
  - 被动一枝一枚：元 `perk_hp` · 力 `attack` · 锋 `crit` · 御 `defense`
  - 机制一枝一枚：博闻 `perk_library` · 广纳 `perk_hand` · 慧眼 `perk_loot` · 调息 `heal`
  - 跨树用它放大的那个效果的图标：相济 `attack` · 融会 `crit` · 博采 `perk_draw`

## 枝色
五行脉 = 该系 `<el>`；被动 元 `cinnabar` · 力 `shop-nav` · 锋 `gold` · 御 `ink-soft`；机制 博闻 `split-blue` · 广纳 `water` · 慧眼 `gold` · 调息 `jade`；跨树统一 `heart`。浅底 = `panel-paper` 往枝色走 18%（五行用 `<el>-soft`）。

## 缩放
