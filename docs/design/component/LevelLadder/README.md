字卡等级条：10 格进度 + 每格上方的解锁记号，一眼看出「到第几级、哪几级解锁特性、解在哪一面」。实现是 `CardSheetParts.LevelLadder`（`Presentation/UI/CardSheetParts.cs:282`，2026-10-12 Plan E2 合并 `9e5d2cff`，取代旧的 `CharSheetSections.Level` Pips）；记号 `Mark`（同文件 317）。调用点：字卡详情战斗版（`CharPreview.cs:363`）、铺满版（`CharPreview.cs:380`，未拥有传 0 级）。设计稿 `drafts/traits` 的 `CardSheet`（`.ladder` / `.pip`）与 `CardSheetBattle`。

## 结构（每格自上而下）
1. **解锁记号**：这一级解锁特性才有，没有就留空位（高度照占，十格顶端对齐）。
2. **进度格**：圆角条。
3. **级数**：只在有记号的格下印数字 —— **1**、3、4、5、6、8（第 1 格的记号是「两面」空心：Lv1 本体两面都有），其余留空、高度照占。

## 记号
| 记号 | 画法 | 含义 |
| --- | --- | --- |
| 墨实 | `ink` 实心方块 | 解锁在攻击面 |
| 本系色实 | `<el>-glyph` 实心方块 | 解锁在五行面 |
| 空心 | 1.2pt `ink-soft` 内描边、无底 | 两面通用（Lv1 本体、Lv3 / Lv4，含数据里分面、按槽位合成一行的两条，E2 附录 Q3 / Q4） |

- **Lv5、Lv8 两面各解一条** → 同一格并排两枚，**左攻右五行**；第二枚窄 1pt，两枚加间距不超出格宽。
- 已到达的格（≤ 当前级）记号满色；未到达的记号 35% 不透明度。
- 和 `FaceSeal`、`TraitRow` 同一套颜色语义：墨 = 攻击，本系色 = 五行面，墨蓝 / 空心 = 两面。

## 进度格三色
| 态 | 颜色 |
| --- | --- |
| 已到达（≤ 当前级） | `ink-soft` |
| 下一级、且材料够升（只在卡组版） | `jade` |

## 尺寸（pt × 2.093 = 逻辑单位）
| 件 | 卡组 / 开箱 / 商城（铺满版） | 战斗长按版 |
| --- | --- | --- |
| 格宽 / 格距 | 19 / 3 pt → 40 / 6 | 17 / 3 pt → 36 / 6 |
| 进度条高 / 圆角 | 5 / 2.5 → 10.5 / 5 | 4 / 2 → 8 / 4 |
| 记号 | 7×7（第二枚宽 6），间距 1.5，圆角 1.5 → 15（12.6），3，3 | 6×6（第二枚 5），间距 1 → 12.6（10.5），2 |
| 记号 / 条 / 级数间距 | 3 → 6 | 2 → 4 |
| 级数字 | 7 → 15，`text-faint`，等宽数字 | 战斗版不印级数 |

整条宽 = 10 × 40 + 9 × 6 = **454**（铺满版）。16:9 下头部等级行余量只有约 26（E2 附录 §4.1），等级条本身定宽不缩，收缩让给右侧成本格。

## 使用方提供
字的定义、当前级（未拥有传 0，等级条全空）、是否可升（决定下一格是否 `jade`；战斗版恒 false）、尺寸档（`Sizes.Tall` / `.BattleSheet`）。每一级的记号由 Core 纯函数 `CardSheetRules.LadderMarks(def, level)` 给，表现层不自己推。
