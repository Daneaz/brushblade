胶囊/圆角按钮，**黑体、不加粗**（`ThemedLabel` 默认 `BodyFont`），底色与字色由调用点给；实现是 `Ui.PillButton`（圆角恒 24）与 `Ui.RoundButton`（圆角由调用点给，**默认 10**）。

⚠ 圆角**不是**高度的一半：主行动 523×109 配圆角 24（约 11.5pt），视觉上是圆角矩形而不是胶囊。

### AdBadge 的圆角与字号是派生的，不是自由档
`Ui.AdBadge`（`Ui.cs:860–909`）以「稿 .adbadge 高 63」为基准按高度整体缩放：
`scale = 高 ÷ 63`，字号 `21×scale`、圆角 `31×scale`、间距 `10×scale`、播放三角 `15×17 ×scale`，描边恒 1.5。
所以 72×46 那枚是**圆角 23 / 字号 15**，不是宝箱钮那档的 14 / 19。四个调用点的实际高度：
63（字库扩容，基准档，`BattleView.cs:4128`）· 67（败北复活，`BattleView.cs:3796`）· 64（商城补给两枚，`ShopView.cs:346` `356`）· 46（宝箱加速，`MapView.cs:516`）。

## 配色语义
`cinnabar` 推进或不可逆 · `ink-soft` 中性但改变状态 · `gold` 花钱 · `locked-bg` 取消与禁用（永远排在最右）· `exit-pink` 顶栏功能钮与「弃」。

⚠ **赭金底一律压 `gold-text`**（白字只有 2.5:1）。宝箱两枚钮与护盾角标都按这条做；
`PerkNodeSheet.cs:437` 的「解锁技能」主钮仍是 `gold` 底 **白字**，是实现侧违例，见对比度一节。

## 使用方提供
按钮文案（走字符串表）、`disabled`。
⚠ 触控高度：实现里最矮的可点件是弹窗关闭「×」28（13.4pt），弹窗/宝箱/战斗行动钮 46–52（22–25pt），
只有「续爬」109（52pt）与底部导航 92（44pt）到得了 44pt。`tokens.json` 的 `tap-min` 写的是 44**pt**
（＝92 逻辑单位），与实现现状差一个量级 —— 这条口径待拍板，不要拿它当已达成。
