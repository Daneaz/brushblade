升级确认弹窗：花墨锭把一张字升一级之前的那一张对照表。实现是 `CollectionView.ShowUpgradePreview`。

## 为什么单独立一张卡
它是局外唯一一处**花钱且不可撤销**的确认，而它解决的问题是「玩家得自己在两串长句子里找哪个数变了」。那套「旧 → 新 (+差)」的读法与「没变的收成一行灰字」的收尾，是这张卡真正要定下来的东西。

## 版面（逻辑单位 → 稿面 pt，1pt = 2.093）
- 外壳 `Ui.Sheet` 1088×670（520×320pt，定高），圆角 18、描边 1.5 `panel-border`、内边距 24、行距 14；遮罩 `scrim`（55%，局外模态用满档），`dismissable: true` —— 点遮罩即关，因为它是可选操作。
- 自上而下四段（正文那段 `flexHeight:1`，吃掉定高外壳的剩余高度）：

| 段 | 内容 | 尺寸 |
| --- | --- | --- |
| 头 | 「升级「冰」」+ 右侧警示句「确认后立刻扣除材料,不可撤销」，底对齐 | 行高 40、间距 15；标题 34（16.2pt）宋体 `text-main`；警示 19（9.1pt）黑体 `text-faint` |
| 牌行 | 旧牌 → `→` → 新牌 →「升到 Lv.N」chip，居中 | 两张都是 **`MiniGlyphTile`** 130×163（62×78pt：同一套稀有度框，字 0.46 牌高，**不印拼音、不挂光效与动效**）；旧牌把整张 `Image.color` 乘 `locked-paper`（同 GlyphTile 未拥有态的乘法）；间距 29；`→` 29 `exit-pink`；chip `jade` 底白字 21 |
| 正文 | 左「数值提升」/ 右「层数与特性」两栏并排，各 `flex:1` | 栏间 25，栏内行距 11 |
| 钮 | 「确认升级」（弹性宽）+「再想想」250 定宽 | 行距 21，高 71（34pt），字号 24 黑体 |

- 两栏的节标题走 `CharSheetSections.Section`（与详情弹窗、收集页右栏同一份）：19（9.1pt）黑体 `text-faint`，**右侧**一条 2 单位 `panel-border` 横线撑满余宽，节头行高 44。
- 「不变：…」那行**不是独立一段**：它挂在右栏「层数与特性」那节的末尾，18（8.6pt）`text-faint`、开 Wrap，折行宽按半张外壳（`UpgradeW × 0.5 − 50`）估。文案 `collection.modal.unchanged`「不变:{list}」，各项以「 · 」相接。右栏没有任何没变的特性时这一行不出。

## 差异行 `DeltaRow`（两栏共用，读法因此完全一致）
定高 54（25.8pt），`panel-inset` 底、圆角 12，左右内边距 17，元素间距 11。一行的顺序是：
**[chip] 名 ——— 旧 → 新 (+差)**

- chip：有图标的走 `CardTraits.ChipColor` 底 + 白色图标，**只出图标不带字**（36×30：padX 18 + 图标 18）；没图标的退成词组 chip（`locked-bg` 底压 `text-main`，字号 18）。数值栏不挂 chip。
- 名 19（9.1pt）`text-dim`，`flexWidth:1` 把右边那组顶到行尾。
- 旧值 25 宋体 `text-faint` → `→` 18 `text-faint` → **新值 29 宋体 `upgrade-text`** → 增量 19 `upgrade-text`（文案 `collection.modal.delta`「+{delta}」；特性栏不印增量，只有数值栏印）。
- 新值比旧值大一号、且是全行唯一的深绿 —— 一眼扫下去就是「变了的那一列」。

## 示例（卡片上那一张）
「冰」（金 · 水，攻面单体 152 对受控翻倍 + 冻结 1；护面自疗 152 + 急速 100% 1 回合）Lv.3 → Lv.4，按 `MetaRules.ScaleByCardLevel`（×(1 + 0.117×(级−1)) 向上取整）算：
- 数值提升：治疗 188 → 206 +18、攻击 188 → 206 +18（`CollectionStats.Of` 先扫护面再扫攻面，所以治疗在前）。
- 层数与特性：急速 +124% → +136%（`speed` 图标、木字形色底）；克制目标与冻结（Lv.3、Lv.4 都是 2 回合）没变，收进「不变:克制目标 · 冻结」。

## 硬规则
- **不印重复卡与墨锭消耗**（2026-09-04 拍板）。不够根本走不到这一页 —— 详情页那颗按钮就是灰的、点不动。印出来只是把「你付得起」再说一遍。
- **没变的东西必须写出来。** 那一行灰字回答的是「我会不会丢掉什么」，不是凑字数。
- **一栏没有任何变化时写一句话占位**（`collection.modal.no_numbers`「这一级没有数值变化」/ `collection.modal.no_traits`「这一级没有层数或特性变化」，19 `text-faint`、行高 40），不留空 —— 空白读起来像没加载出来。
- 主钮是**赭金底压 `gold-text`**：赭金是「花墨锭」的语义（墨锭条、价格、`IngotGold` 都在这一支）。取消档「再想想」排最右，`locked-bg` 底压 `text-main`。两颗钮都是 `PillButton`（圆角 24、黑体）。

## 使用方提供
字的定义、当前等级。前后两套数值与特性由 `CollectionStats.Of` / `CardTraits.Of` 各算一遍再逐条比对，调用方不用自己算差值。

## 关联
升完把详情弹窗重开（`ShowCharSheet`）——新等级与新数值就是这次操作的反馈。角标与牌脚见 CardFace，牌本身见 GlyphTile（MiniGlyphTile 一节）。

## 与实现的差异（本系统记录）
- 2026-09-21 把主钮从 `jade` + 白字（4.52:1，且与技能树的同语义钮是两套色）改成 `gold` + `gold-text`（5.47:1），与技能解锁钮并成一套。
- 同日把「+N」增量与新值的 `jade`（压 `panel-paper` 只有 4.26:1）换成 `upgrade-text`（8.32:1）。
- 卡片按 0.60 缩放画（520pt 宽的外壳缩成 312px），所有尺寸、圆角、内边距一并乘 0.60；旧牌的 `locked-paper` 乘法用 `zd-mini--dim` 的滤镜近似。
- **角色升级弹窗（`LevelUpPopup.cs`，稿 `drafts/character/LevelUp.dc.html`）不是这一张。** 那是**角色**升级（叠在安全层与登塔结算之上）；本卡是**字牌**升级。两件事别混。
