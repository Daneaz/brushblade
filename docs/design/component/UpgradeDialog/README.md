升级确认弹窗：花墨锭把一张字升一级之前的那一张对照表。实现是 `CollectionView.ShowUpgradePreview`（`CollectionView.cs:680`）；2026-10-12 Plan E2 按稿 `drafts/traits/UpgradePreview` 换了两栏内容，骨架、差行读法、主钮、警示句不动。

## 为什么单独立一张卡
它是局外唯一一处**花钱且不可撤销**的确认，而它解决的问题是「玩家得自己在两串长句子里找哪个数变了」。那套「旧 → 新 (+差)」的读法与「没变的收成一行灰字」的收尾，是这张卡真正要定下来的东西。

## 版面（逻辑单位 → 稿面 pt，1pt = 2.093）

- 自上而下四段（正文那段 `flexHeight:1`，吃掉定高外壳的剩余高度）：

| 段 | 内容 | 尺寸 |

| 头 | 「升级「炎」」+ 右侧警示句「确认后立刻扣除材料,不可撤销」，底对齐 | 行高 40、间距 15；标题 34（16.2pt）宋体 `text-main`；警示 19（9.1pt）黑体 `text-faint` |

## 左栏「数值提升」（`BuildUpgradeNumbers`）
数据取 `FaceStats.Deltas(def, L, L+1)`：逐面逐格、只给变了的，**先攻后五行**。一条都没有时写占位「这一级没有数值变化」（`collection.modal.no_numbers`）。

## 差异行 `DeltaRow`
定高 54（25.8pt），`panel-inset` 底、圆角 12，左右内边距 17，元素间距 11。一行的顺序是：
**[xs 面印] 名 ——— 旧 → 新 (+差)**

- 行首 **xs 面印**（21，`Ui.FaceSeal`，见 `FaceSeal`）：两面一起升，不标面就分不清涨的是哪一面的「伤害」。原先的状态 chip 已撤。
- 名 19（9.1pt）`text-dim`，`flexWidth:1`。「持续」按归属写成「减攻持续 / 护甲持续」（`collection.modal.duration_of`）。
- 旧值 25 宋体 `text-faint` → `→` 18 `text-faint` → **新值 29 宋体 `upgrade-text`** → 增量 19 `upgrade-text`「+{delta}」。**只有随等级缩放的量印增量**；层数、回合、减攻百分比这类阶跃量不挂增量（E2 裁定）。

## 右栏：新解锁小卡，或下一级预告（`BuildUpgradeTraits`）
- 节头按这一级解锁几条定：两条「新解锁 · 两面各一条」，一条「新解锁」，没有「特性」。
- **有新特性**（`CardSheetRules.UnlockedAt`）：小卡（Lv5 / Lv8 攻、五行面各一张，Lv3 / 4 / 6 一张）同在一圈**墨晕**里（`CardHalo`，`halo-new` 赭金，圆角 17；外包 `Theme.HaloPad` 留白，免得被 ScrollList 的遮罩裁掉）。
  - 小卡：圆角 13、内边距上 13 / 下 15 / 左右 19（两张时 11 / 13 / 17）；五行面那张垫本系淡底（`Theme.FaceTint`），其余 `card-face`。
  - 卡头：m 面印（36，两面通用出「两」）→ 落点（宋体 23）→ 名（宋体 27 `text-main`）→ 类别 18 `text-dim` → 弹簧 →「新」签（`gold` 底 `gold-text`，字 17、padX 25）。
  - 正文 21（两张时 20）`text-dim`，与字卡详情共用 `CardSheetParts.BodyLine` 的行高算法。
- **没有新特性**：占位「这一级没有新特性」+ **下一级预告框**（`CardSheetRules.NextUnlock`）：`panel-inset` 底、圆角 17、内边距 15 / 19；首行「Lv{n} 解锁」18 `text-dim`，下面逐条「s 面印 + 落点 20 `text-dim` + 名 宋体 23 `text-main`」，名过长截断补「…」（`Ui.Truncate`）。
- 局外没有「本场」，这里不画「本场已用」（Q19）。

## 「不变」行（`BuildUnchanged`）
列等级 ≤ 当前级、已解锁的特性名（Q15；Lv1 没有效果，不列），以「 · 」相接。一条都没有时退回「两面本体的层数与回合」；但 **Lv2 → Lv3 那一跳层数与回合恰恰在变**（Lv3 本体替换），兜底句会说反，这时整行不出。

## 示例（卡片上那一张）
「炎」（火 · 金档）Lv.4 → Lv.5：左栏「攻 伤害 199 → 209 +10」；右栏「新解锁 · 两面各一条」两张小卡 ——「攻 · 火上浇油」与「燃 · 续火」（五行面那张垫火系淡底），同在一圈墨晕里；底下「不变:强化 · 双焰」。正文为稿上的手写句，实际是 `TraitEffectsText` 的机械拼句。

## 硬规则
- **不印重复卡与墨锭消耗**（2026-09-04 拍板）。不够根本走不到这一页 —— 详情页那颗按钮就是灰的、点不动。印出来只是把「你付得起」再说一遍。
- **没变的东西必须写出来。** 那一行灰字回答的是「我会不会丢掉什么」，不是凑字数。
- **一栏没有任何变化时写一句话占位**（`collection.modal.no_numbers`「这一级没有数值变化」/ `collection.modal.no_traits`「这一级没有层数或特性变化」，19 `text-faint`、行高 40），不留空 —— 空白读起来像没加载出来。
- 主钮是**石青 `cta`（Primary）白字**：2026-10-04 五色语义拍板后，花墨锭的主钮也是这一屏的主推进钮，赭金只留给 Warning。取消档「再想想」排最右，`locked-bg` 底压 `text-main`。两颗钮都是 `PillButton`（圆角 24、黑体）。

## 使用方提供
字的定义、当前等级。数值差由 `FaceStats.Deltas`、新解锁与下一级预告由 `CardSheetRules.UnlockedAt` / `NextUnlock` 给（Core 纯函数，有测试），调用方不用自己算。

## 关联
升完把详情弹窗重开（`ShowCharSheet`）——新等级与新数值就是这次操作的反馈。角标与牌脚见 CardFace，牌本身见 GlyphTile（MiniGlyphTile 一节）。
