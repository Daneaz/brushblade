战斗飘字：打在格子上的粗体字，没有底色和描边，颜色本身就是信息；对应实现 `Juice.Popup`（`Juice.cs:1671`）。

## 形态
- 字体：系统黑体粗体（`Ui.Font`，非子集宋体）。常规 36 逻辑单位（≈17pt），`zd-pop--sm` 26（≈12.4pt）（`Juice.cs:1694–1695`）。
- 伤害越高字越大：`1 + 伤害/50`，封顶 1.9；暴击封顶 2.4、相克 2.1；被克下限降到 0.78（`Juice.cs:301–302`）。
- 相克专属金边 `zd-pop--ke`（`gold-border`，`Outline` 偏移 2.5 逻辑单位、跟着字一起淡出，`Juice.cs:303` `1704–1710`）：颜色已经给了五行，「打对了属性」只能靠这圈边说。
- 动效 0.7s：0.4 → 1.15 → 1 弹出（前 12%），悬停到 34% 再上浮淡出（`Juice.cs:1719–1745`）；
  同一锚点 0.55s 内连挨几记时按槽位往上叠成一列，步进 34、最多 4 层（`Juice.cs:1633–1667`）。
- 锚点：`null` = 玩家侧，钉在屏幕中下 0.32 处；其余锚在敌人格/召唤物格上。

## 串行演出
溢流、反震、余烬、锋芒、归根都各占一拍，不和挥击挤在同一帧（2026-09-18）：
- **溢流**：满血时也先播回血动效 → 停一拍 → 一注水从溢出者飞向敌人（0.3s）→ 落地水花 + 飘字 + 掉血。
- **反震**：敌人一击砸在盾上 → 停一拍 → 碎石从挡刀者（召唤物或玩家）砸回攻击者 → 震屏 + 闷响 + 飘字。
- 余烬、锋芒在本批末尾回放：火星跳到接手的敌人 / 金光从暴击落点飞回玩家。

## 对比度
基准档 36 逻辑单位 = 17.2pt，按本系统的门槛（≥19pt 粗体才算大字）仍要 4.5:1。逐条算下来：
五行字形色 5.3–6.5:1、`split-blue` 7.5、`ink-soft` 7.5、`ink` 16.1、`cinnabar` 4.7 —— 都过。
**只有两处不过，都是实现侧现状**（根 README 的例外清单已记）：
两条 **2026-09-21 已修**：免 / 分裂 / 涂改 / 补全从 `jade`（4.01:1）改 `upgrade-text`（7.85:1）；
破阶从 `gold-border`（4.36:1）改 `gold-deep`（4.70:1）。`jade` 作 chip 底压白字（4.52:1）与血条
填充**不动** —— 只改「当文字用」的那几处。相克金边仍走 `gold-border`：它是描边不是文字，
且始终贴着一个大字号的字形，不按正文判。

伤害飘字会随伤害放大（×1.9 → 32.7pt、暴击 ×2.4 → 41.3pt），越过 24pt 后门槛降到 3:1，
但基准那一档是每记都会出现的，按基准判。被克那支往 `paper` 褪 42% 后必然更低，
属于「这一记没使上劲」的刻意弱化，与非激活态同类，不计入。
