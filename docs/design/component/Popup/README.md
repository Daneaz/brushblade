战斗飘字：打在格子上的粗体字，没有底色和描边，颜色本身就是信息；对应实现 `Juice.Popup`（落地动效 `Juice.FloatAndFade`，叠层 `Juice.NextSlot`）。

## 形态
- 字体：`Ui.Font` = 子集黑体 `NotoSansSC-Subset`（取不到才退到系统黑体），`FontStyle.Bold` 合成粗体。常规 36 逻辑单位（≈17.2pt），`zd-pop--sm` 26（≈12.4pt），再乘 `sizeScale`。
- 伤害越高字越大，直伤（`Juice.ApplyBatch` 的 `Damage` 分支）：`clamp(起点 + 伤害/50, 下限, 上限)`

  | 这一记 | 起点 | 下限 | 上限 |
  | --- | --- | --- | --- |
  | 暴击（含暴克） | 1.35 | 1 | 2.4 |
  | 相克 | 1.18 | 1 | 2.1 |
  | 被克 | 0.78 | 0.78 | 1.9 |
  | 平 | 1 | 1 | 1.9 |

  灼烧结算 / 引爆：起点 1（被克 0.78），上限 1.9。溢流、流血、召唤物灼烧结算：`clamp(1 + 伤害/50, 1, 1.9)`。
  敌人打召唤物**不随伤害放大**：相克 1.18、被克 0.78、平 1。其余飘字都是 1。
- 相克专属金边 `zd-pop--ke`（`gold-border`，`Outline` 偏移 2.5 逻辑单位、`useGraphicAlpha` 跟着字一起淡出）：颜色已经给了五行，「打对了属性」只能靠这圈边说。直伤、灼烧结算、引爆、敌打召唤物四处都会挂。
- 动效 0.7s：0.4 → 1.15 → 1 弹出（前 12%），悬停到 34% 再上浮淡出。
- 同一锚点 0.55s 内连挨几记时按槽位往上叠成一列，步进 34、最多 4 层，封顶后停在顶层不绕回；第 0 层水平抖 ±24，往上收到 ±8。
- 锚点：`null` = 玩家侧，钉在屏幕中下 0.32 处（水平抖 ±60）；其余锚在敌人格 / 召唤物格上，起点再上抬 30。

## 串行演出
这几条各占一拍，不和挥击挤在同一帧（2026-09-18 起）：
- **溢流**：满血时也先播回血动效 → 停一拍 → 一注水从溢出者飞向敌人（0.3s）→ 落地水花 + 飘字 + 掉血。
- **盾反**（`JuiceSummons.ThornsFly`，2026-10-02）：召唤物挨打时举盾 → 一道金色回弹波从它身上沿原路打回攻击者（0.22s）→ 攻击者身上炸一圈金环 → 飘字 + 掉血。
- **归根**：召唤物倒下 → 停一拍 → 一团翠光从它的位置流回玩家 → 飘字 + 回血光效。
- 余烬、锋芒在本批末尾回放（`Juice.PlayDeferredProc`）：火星跳到接手的敌人 / 金光从暴击落点飞回玩家。

## 对比度
基准档 36 逻辑单位 = 17.2pt，按本系统的门槛（≥19pt 粗体才算大字）仍要 4.5:1。逐条算下来：
五行字形色 5.3–6.5:1、`split-blue` 7.5、`ink-soft` 7.5、`ink` 16.1、`cinnabar` 4.7、`upgrade-text` 7.85、`gold-deep` 4.70 —— 都过。
相克金边走 `gold-border`：它是描边不是文字，且始终贴着一个大字号的字形，不按正文判。

伤害飘字会随伤害放大（×1.9 → 32.7pt、暴击 ×2.4 → 41.3pt），越过 24pt 后门槛降到 3:1，
但基准那一档是每记都会出现的，按基准判。被克那支往 `paper` 褪 42% 后必然更低，
属于「这一记没使上劲」的刻意弱化，与非激活态同类，不计入。
嘲讽 / 蓄力两支是硬编码色，本系统没有 token，未逐条核对比度。
