## 16:9 行为（2026-10-04 按两档宽验算）
画布高恒 900、宽随屏比变；内容区 = 画布宽 − 两侧安全区 123×2：**基准机 1951 → 1705，16:9 的 1600 → 1354**。
Unity `Text` 不折行，字宽按 字数×字号（全角）/ ×0.55（数字拉丁）估。

| 横排 | 首选宽 | 基准机可用 | 16:9 可用 | 结论 |
| --- | --- | --- | --- | --- |
| 顶栏：标题 160 + 已录 ~122 + 待领赏 chip 158 + 墨锭 ~124 + 返回 130 + 间距 21×5 | ~800 | 1705 | 1354 | 放得下（弹簧吃余量） |
| 筛选栏：全部 208 + 字林 208 + 五段各 172 + Boss 266 + 间距 4×7 | 1516~1570 | 1705 | 1354 | **16:9 超 162~216** → 改横向滚动 |
| 怪物网格：4×195 + 3×17 | 831 | 1184 | 833 | 放得下，16:9 **只余 2** |
| 右栏（定宽 502，内宽 460）：数值三格各 146、克制两格各 224、四相四格各 109、名+chip 区 280 | — | 460 | 460 | 定宽、与屏比无关，放得下 |

页签宽是代码写死的 `32 + 字数×29 + 10 + chip 宽`（计数 `已录/总数` 已录过 10 时 chip 从 90 变 108，所以是个区间）。
- **筛选栏 = `Ui.HScrollFill`**：内容宽 = max(视口, 页签总宽)。基准机铺满、拖不动，与改前一模一样；
  16:9 按原尺寸排版，「Boss」与「词渊」右半截被裁在视口外，横向拖出来。页签尺寸、字号、配色都不动。
  改前 16:9 上横排布局组把每个页签按比例压到约 86%，页签名与计数 chip 叠在一起。
- 点页签会整页重建，筛选栏的横向滚动位置**保留**（点了右端的 Boss 不会弹回最左）；网格换筛选照旧归顶。
- 网格行宽 831 对 16:9 的 833 只余 2：格宽 / 列距 / 右栏宽任何一项加宽，16:9 第 4 列就被裁。
- 段数 ≤ 4 时出现的排序提示（约 285）也计入筛选栏最小排版宽，窄屏一起滚。
