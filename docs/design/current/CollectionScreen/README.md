收集页整屏（932×430pt 横屏），状态为「全部 · 稀有度排序」、选中过「冰」；对应实现 `CollectionView.cs`。

## 版面
- 顶栏 38pt：「收集」+ `收集 已有/总数` + 未拥有 chip（`panel-inset` 底、`text-dim` 字，2026-09-21 从 `text-faint` 压深）+ 新字 chip（`cinnabar` 底白字）；右侧墨锭计数与「返回地图」。四个外层页（收集 / 图鉴 / 技能 / 商城）顶栏逐数同款：标题 19pt 宋体、墨锭 12pt、返回键 62×30pt `exit-pink`。两枚 chip 都是「数为 0 就整个不画」。
- 筛选栏 27pt：六个属性页签（全部 + 金木水火土，各带 `已收集/总数` 与新字红点）| 拥有态三选一（全部 / 已拥有 N / 未拥有 N）| `排序` 小字标 + 排序三选一（稀有度 / 可升级 N / 新卡 N）。两组之间各一条 1pt 竖线。
  - 选中的**属性**页签铺该系 `<el>-soft` 浅底 + 底边 2pt `<el>` 色线，名字转 `<el>-fg`；选中的**「全部」**页签只铺 `panel-inset`、字转 `text-main`，**没有底边线**（它没有属性色可用）；这时页签底与计数 chip 的底同为 `panel-inset`，chip 改带一圈 1 逻辑单位（≈0.5pt）`panel-border` 描边，不然形状整个糊掉（`BuildFilterTab`，2026-09-21）。属性页签铺 `<el>-soft`，计数 chip 不描边。
  - 页签计数按该系全表算，拥有态与排序的计数按**全表**算，不跟着当前页签走 —— 页签说「这一系集了多少」，右边那两组说「全表还差多少 / 还能升几张」。
- 左：5 列收集网格，每格 103×128 的 CardFace + 牌脚，列距 8pt、行距 14pt，内部滚动。**未拥有沉底**是三种排序共有的第一层，其后才是排序主键，最后恒为「稀有度降序 → 字形（序数序）」。三种排序末两层一致，所以换排序时同档的牌相对位置不动，视线不会整片乱掉。
- 右栏 252pt：只有卡池概览 —— 按稀有度从高到低列「字数 · 起手抽中率」，下面一段说明，整栏内部滚动。

## 卡池概览的数怎么算
- 卡池 = 已拥有的**非部件**字（`MetaRules.PlayableCards`）。
- 抽中率是近似值：把 `MetaRules.RarityWeights`（白 150 / 绿 350 / 蓝 300 / 紫 130 / 金 50 / 橙 15 / 红 5）里**池中有字的那几档**加起来当分母，取千分比印一位小数。卡片上那组数是「白绿蓝紫金橙六档有字、红档空」的算例，分母 995 —— 空档不进分母，所以开出第一张红卡时全表的百分比都会动。
- 真实起手是「五行各一张、各系内部独立加权，外加最高一档保底一张」，严格算要按系分开；这里答的是「开箱怎么影响我的起手」这个方向。

## 交互
- 点任意牌 = 开字卡详情弹窗（与开箱、战斗长按同一屏，`CharPreview`），升级钮在弹窗底部；网格上留墨色镶边标记刚点过的那张。
- 点开新字即销掉红旗；筛选或排序变了网格归顶，其余重建保留滚动位置。

## 使用方提供
全部可收集字（**55 张**，另有 52 个部件不进这一页）、拥有表、等级与份数、未看过的新字、墨锭、卡池权重（`MetaRules.RarityWeights`）。

## 与实现的差异
- 静态再现；滚动、弹窗与呼吸光不在卡片里。
- 筛选栏六个页签 + 六个切换钮按首选宽相加约 880pt，超过 814pt 可用宽（再加上两条竖线、`排序` 小字与 15 个 4 逻辑单位的间距约 930pt），实机由横排布局按比例压缩；再加一项就会挤字。
- 类注释里「74 张可收集字」已过时，字表现为 55 张。
- 顶栏的「收集 N/55」「未拥有 M」用的是 `OwnedCards.Count`（不过滤部件、不过滤下架字），而筛选栏的「已拥有 N / 未拥有 M」是逐条遍历可收集字表算的 —— 两处口径不同，存档里一旦混进部件或幽灵字，同一屏会出现两个不一样的数。卡片按筛选栏那一份画。
