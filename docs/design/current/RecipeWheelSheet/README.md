## 交互与时长

| 拍 | 时长 | 实现 |
| --- | --- | --- |
| 待转 | — | 转盘停在 −12°(不让任何一格正对指针);结果早已由 Core 入账(配方集 + 生疏),这里只演 |
| 点「转」 | — | 轮毂变 `locked-bg` 底 `text-faint`「…」,不可再点 |
| 转动 | 3.6s | **顺时针**多转 5 圈,缓动 `cubic-bezier(.12,.62,.1,1)`(按 x 二分求参);落点 = 目标扇区中段 ±30%(抖动种子取自结果与层号,不碰游戏随机流) |
| 落定 | 0.7s | 中奖扇区 `cta` 6.7(3.2)描边 + 白 18% 提亮;其余扇区底改 `paper-dim`、字改 `text-mute`;轮毂「中」 |
| 结果卡 | 0.3s | 转盘以左缘为原点缩到 0.72 并移到最左;结果列从右 21(10pt)滑入、淡入(ease-out) |

- 转盘开着时 `BattleView.Refresh` 整个跳过(底下的选字页 / 奇遇页、层记账与落盘都顺延到关转盘那次 Refresh),免得新建的选字浮层盖到转盘上面。
- **续爬读档不重转**:结果在 `AdvanceAfterBattle` 同一步入账并进 `RunSnapshot`;读档停在选字页时新视图不经过 `AdvanceAfterSettle`,转盘不弹。
  转盘开着时被杀进程,重进后从打赢那一刻续上,同 (塔种子, 层) 的独立流转出同一格。
- 不加跳过钮;结果卡出来前点遮罩无效。

## 「生疏」标记(同一批实现,画在别的屏上)

- **字库牌**(`BattleView.DrawLibrary`,战斗与选字阶段的携带字库都画):左上「疏」签,`Ui.ShuBadgeOnTile` —— 见方 = max(牌宽 × 0.27, 20)(字库牌 96 → 26 / 12.4pt),
  `ink-soft` 实底白字宋体粗(字号 = 边长 × 0.62)、圆角 5、外描 1.5 `panel-paper`(描在边长之外)、向外骑出 4;挂在牌根最后,压在字之上。
  AP 不足的去饱和只染牌面那张图(`CardFrameView`),签不去色。判据 `RunEngine.IsUnfamiliar`(生疏表里且未收集)。
- **拆合台**:可合成行出字后挂 20 的小签(`Ui.ShuBadge`);选中详情的牌角同样挂签(元信息行写 `Lv.1`)。
- **字卡详情**(长按,`CharPreview` 战斗版):头行「Lv1(局外 LvN)」,括号半句 `text-faint`;其下一条 `panel-inset` 底 46 高的说明行:
  27 的「疏」签 +「**生疏**:效果 ×70%,按 Lv1 计」21(冒号前 `text-main` 粗,其余 `text-quiet`)。
  数值格、面头、Lv1 行正文按 Lv0(`MetaRules.UnfamiliarCardLevel`,×70%)缩放,特性按 Lv1 解锁 —— 与 `BattleEngine` 出字同一口径
  (`RunEngine.CardLevel` 对生疏字返回 Lv0;状态详情里来源字的载荷也不再夹到 ≥1)。

## 与拍板稿的差异(按代码画)

1. **转向**:稿 README 写「顺时针」,稿画板脚本实际是逆时针转(rot 取负);实现按 README 顺时针。
2. **落定压灰色**:稿用 `#E4DED2` / `#A8A296`(不是 token),实现取最近的 token `paper-dim` / `text-mute`。
3. **阴影**:稿外环 `0 3px 10px` 投影、指针 drop-shadow、轮毂投影,实现都没画(弹窗全站无投影)。
4. **结果卡入场**:稿 CSS 动画 0.25s,README 写 0.3s;实现 0.3s,转盘缩放与结果列滑入共用同一条 ease-out。
5. **配方部件着色**:稿每个部件都用目标字本系的淡底;实现按「部件池方块样式」各取部件自己的属性色(氵 水蓝、木 木绿)。
6. **勾**:稿是字符「✓」,实现用 `icon_check` 图标(字体子集里没有 ✓)。
7. **结果大字牌拼音**:稿 7.2pt,实现 `GlyphTile` 固定 12(5.73pt)。
8. **新增文案**(稿文案表里没有):`wheel.spinning`「…」、`wheel.result_meta`「{稀有度} · {属性}」、`wheel.result_meta_rare`「… · 稀有格」。
9. **副标分档**:恒写名义分档「低 ×4 + 高 ×1」;候选不足补位时实际格数 / 稀有度可能与之不同。
