技能页整屏（932×430pt 横屏）：一张 1220 见方的环形星域画布，屏幕只是它的视口，默认缩放 0.7；对应实现 `PerkView.cs` + `PerkLayout.cs`。

## 版面
- **43 个节点分四类**：五行 5 枝 × 4 层 = 20、被动 4 枝 × 3 层 = 12、机制 4 枝 × 2 层 = 8、跨树 3。跨树不是第四棵树 —— 它的三个节点 `Depth` 恒为 1、不在任何一条直链上，前置走显式谓词。
- **五行 L1 / L2 是三段节点**（2026-10-02）：每段一条独立的表项（id `{枝}_{层}_s1..s3`，共用 `NodeKey`），所以 Core 的表里共 63 段，画布按 `PerkRules.Faces` 每个节点只画一格（43 格）。五行四层自内向外 = L1 专精（三段）/ L2 本系效果值（三段）/ L3 专属机制 / L4 天花板：
  金脉 砺刃 · 锐锋 · 锋芒 · 断金，木脉 深根 · 荣木 · 归根 · 择伐，水脉 甘霖 · 润下 · 溢流 · 涌泉，火脉 添薪 · 炎上 · 余烬 · 燎原，土脉 筑垒 · 敦厚 · 固本 · 积土。
  被动：元 养元 · 固元 · 还元，力 运力 · 蓄力 · 极力，锋 藏锋 · 露锋 · 破锋，御 披甲 · 重铠 · 金城。机制：博闻 博闻 · 强识，广纳 广纳 · 兼收，慧眼 慧眼 · 明察，调息 调息 · 吐纳。跨树：相济 · 融会 · 博采。
- 画布满屏铺开（不套卡片），顶栏浮在画布之上，底下垫两层半透明宣纸渐隐（上半 0.90、下半 0.45），免得节点滑到标题后面糊成一团。顶栏与其余外层页同款（标题 40、副标题「角色 Lv.N」23、墨锭 25、「返回地图」130×63），左簇尾巴上多一个手势提示「双指缩放 · 拖动平移」（19，`text-faint`，与标题同一行）。
- 中心「斗」→ 半径 100 处三个树根 → 各枝向外。五行占上半圈（180°–360°），被动占右下（0°–108°），机制占左下（108°–180°）；枝在扇区内均分（第 i 枝落在 (i+0.5)/n 处）。三棵树第一圈半径不同（190 / 200 / 280），最外层共用 475。
- 跨树三节点在半径 545：相济、博采并排在五行正上方（262° / 278°），融会在机制扇区中线外沿（144°）。不画连线，只画虚线环。
- 右下角圆形缩略图（156，贴边 20）：43 个点（任一段已点亮用枝色，其余 `paper-dim`）+ 朱砂视口框。
- 节点、连线、段位点的画法见 SkillNode。

## 没有的东西
没有页签、跳转胶囊、状态图例（2026-09-08 定：DAG 本身一目了然）。点任意节点先开详情弹窗，解锁动作在弹窗里 —— 单次不可撤销地花几百到几千墨锭，卡面误触代价太高。

## 详情弹窗（`PerkNodeSheet.cs`）
点任意节点 —— 五种状态一律 —— 从**右缘推出一张 396 宽、上下铺满**的宣纸卡，遮罩盖住其余画面，正在看的那一片画布仍然透得出来（原先是 620×700 居中弹窗，画布能平移之后居中会把视线整个挡住）。内容区净宽 345。

三段节点：弹窗打开的是该节点的**当前段**（`PerkRules.CurrentStage`：第一个未点亮的段，全点亮取末段），门槛、价格、主钮都对着这一段；效果段印累计到本段的值。点「解锁」后若还有下一段，弹窗按新的当前段**自动重开**，可以连点三段。

自上而下：
- **头部**（高 150）：枝色浅底 `--soft`，右下角一个 88 的代表字水印（枝主色 16% alpha；五行取系名「金/木/水/火/土」，其余取枝名首字，如调息枝取「调」）。上面叠面包屑 13 `text-dim`（`{树} · {枝} · 第N层`；跨树没有层，只印 `{树} · {枝}`；三段节点再追加 ` · 第k/3段`，三段全点亮改印 ` · 已满段`）、节点名 30 宋体，右侧两枚 chip：「专属」**只给五行树**，「Lv.{门槛}」五态都挂（三段节点是当前段的门槛）。
- **效果**（18 `text-main`）+ **说明**（15 `text-dim`）两段，段标题 14 宋体 `text-dim`。效果是一句机械描述，说明是「这条实际意味着什么」。
- **数值构成**：只有三个跨树节点有（它们是缩放器）。三行 —— `基础 +{value}{unit}` / `已点亮 {count} 个… → +{value}{unit}` / `合计 +{value}{unit}`，16 / 16 / 17。计数为 0 时中间那行换成 15 `text-dim` 的提示句（如博采「还没有哪一系点到第三层。再深一层就 +1。」），不印「+0」。
- **前置链 / 跨树前置**：普通节点画一排直径 34 的圆点（已点 = 主色实心 + ✓、当前 = 空心 + 主色粗描边、未点 = `locked-bg`），下面挂节点名 12（已点或当前 `text-main`，其余 `text-faint`）；三段节点按「任一段已点」算已点。跨树节点换一套画法 —— 两格竖排（每格高 62、间距 10）逐条列谓词与满足度：`已满足({count}/{need})` / `还差 {gap} 个({count}/{need})`。
- **解锁条件**：两栏等分（高 68，`panel-inset` 圆角 12），角色等级与墨锭**各自判、各自标还差多少**（`Lv.{level} · 还差{gap}级`、`{cost}墨 · 还差{gap}墨`）：达标 `done-green`、未达标 `exit-pink`。
- **底部**（高 56，在滚动区之外、永远贴底可点）：主钮 + 「×」关闭钮（120 宽，`panel-inset` 底 `text-dim` 字）。按钮 18，黑体。主钮**只有可解锁时可按**，五档：

  | 状态 | 文案 | 底 / 字 |
  | --- | --- | --- |
  | 已点亮 | 已点亮 | `locked-bg` / `text-faint` |
  | 可解锁 | 解锁 · {cost}墨 | `cta` 石青 / 白 |
  | 墨锭不足 | 解锁 · {cost}墨（照印原价，不印差额 —— 与商城 / 宝箱位同款，2026-10-03） | `panel-inset` / `cinnabar-dark` |
  | 前置未点 | 需先点上一层（跨树：需两侧前置） | `locked-bg` / `text-faint` |
  | 等级未到 | 需角色 {level} 级 | `locked-bg` / `text-faint` |

  ⚠ 除「可解锁」外四档 `interactable = false`，而 `Ui.RoundButton` 挂的 `Button` 用的是 Unity 默认 ColorTint：底图再乘一层 disabledColor（约 78% 灰、50% 透明），实机上底比表里的 token 更淡，字不受影响。卡上按 token 记，不另造颜色。

内容整段走滚动区：普通节点占 553~593、跨树多出「数值构成」「跨树前置」两段占 795~837，而内容区净高只有 779 —— 两头都不对，靠滚动一次解决（数字取自 `PerkNodeSheet.Show` 的注释，未实测）。
