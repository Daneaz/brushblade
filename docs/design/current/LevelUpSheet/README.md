## 读法 / 交互

- **一段说一次**：`LevelRewardRules.TakeLevelUpSummary` 拿 `LastSeenLevel` 与当前等级比，取完就把 `LastSeenLevel` 推到当前并落盘，同一次升级不会弹两遍。
- **增量列三种写法**：涨了写「+N」（闪避带 %）`upgrade-text`；没涨且已是曲线终值写「已封顶」，没涨也没封顶写「—」，两者都是 `text-dim`。「封顶值」= 各曲线在等级 1000 处的值（`CapProbe`）。
- **宝箱行按等级推、不按实发**：逐级查 `TierForLevel(from+1 … to)`，同档合并成「× N」。`ShowMap` 可能早已静默补发过、或这次因箱位满没发出去 —— 弹窗照样列出，没发出的那部分靠欠箱 chip 另说。
- **只说做得到的事**：局内进不了角色页，所以里程碑只提示、不放跳转钮。
- 实际节奏：一段 4 层 × 10 + Boss 50 = 90 经验，Lv.2 起每级至少 150 —— 安全层 / 结算页每次弹，一般只升一级；「× N」合并与多级跳在当前数值下几乎碰不到。
