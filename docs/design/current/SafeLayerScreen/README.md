安全层整屏（932×430pt 横屏）：v0.7 核心循环里唯一一个主动决策点 —— 继续深入，还是收官撤退。对应实现 `GameRoot.ShowSafeLayer`。

## 为什么单独立一张卡
「取舍写在钮**下面**，不藏在小字里」这条规矩就是这一屏定义的。它存在的唯一理由是让人做这个取舍，把取舍写小了它就白存在。别处凡是要玩家在两条不可逆的路里挑一条，都照这一版。

## 版面（逻辑单位 → 稿面 pt，1pt = 2.093）
- 整屏底：`Theme.BandPaper(段, 档)` —— 该层段基色以 9%–22% 混入 `paper`，每 5 层加深一档；面板后另有一个 10% 透明度的**巨字水印**（取层段名的末字：字林=林、词渊=渊、文山=山、墨海=海）。
- 右上 `BalanceCorner`：本趟已挣墨锭的角标，也是 Boss 层那笔墨锭的飘字落点。
- 居中宣纸卡 `Ui.OutlinedPanel` 1340×620（640×296pt），圆角 25（12pt）、描边 2（1pt），左右内边距 54（26pt）。
- 卡内一列，gap 19（9pt）：

| 元素 | 字号 | 色 |
| --- | --- | --- |
| 标题「安 全 层」 | 46（22pt）宋体 | `text-main` |
| 段位行 | 22（10.5pt） | `text-dim` |
| **滚存大数字** | 71（34pt） | `gold-deep`，单位 21（10pt）`text-faint` |
| 三项状态 | 21（10pt） | `text-dim` |
| 两条岔路 | 见下 | — |

- 岔路区定宽 `1340 − 108`、定高 151：两列各 `flex:1`，列内 gap 13（6pt）。每列 = 主钮 600×84（287×40pt、字号 31）+ 钮**下面**一段定宽 600 的说明 20（9.5pt）`text-dim`。

## 硬规则
- **取舍句写在钮下面，不是 tooltip、不是一行小字。** 「深入」下写清进哪一段、打哪几层；「收官撤退」下写清「层数纪录保留，下次从第 1 层重来」。
- **朱砂给「深入」（默认推进项），`ink-soft` 给「收官撤退」。** 一屏一个朱砂主钮。不可逆的份量由钮下那句话承担，不由颜色喊。
- **滚存那行刻意不用 `InkCounter`**（没有墨锭图标）。它报的是本趟的战绩总量，不是可花的余额 —— 余额在右上角标里。
- 说明文本必须自己定宽定高。`Text.preferredWidth` 报的是不换行时的整句宽，靠 `flexWidth` 撑列会退化成「谁的字长谁就宽」。

## 使用方提供
当前深度、本趟已挣墨锭、下一段的段名与层区间、两条路的回调。

## 登塔结算（`ShowTowerSettle`）共用本骨架
同样的层段染色底 + 居中宣纸卡 + `BalanceCorner`，只换内容：headline →（可选）宝箱行 `ChestRow` → 「返回地图」。`ChestRow` 高 105 = 色块 63 + 内边距 38 + 描边 4；**立绘取 `ChestView.State.Idle` 而不是 `Ready`** —— `Ready` 的金光晕在主界面的意思是「现在能开」，画在结算页是假承诺。没破 Boss 时走「本次未破 Boss，无宝箱」空态。

## 与实现的差异（本系统记录，未改代码）
- **「滚存」是术语残留。** 半额机制 2026-08-30 取消后，`EarnedInk` 已是纯展示量。同一个数字现在有三个名字：安全层叫「滚存墨锭」、结算页叫「本趟已挣墨锭」、`BalanceCorner` 的注释叫「这趟收成」。该并成一个。
- **层段首破里程碑墨锭不计入这个数字。** `EndlessRules.TryAwardMilestone` 直接 `meta.Ink +=`，不进 `run.EarnedInk` —— 进了账户却不出现在大金数字与结算页 headline 里，玩家对账会差一笔。
- 「返回地图」用的是跨屏共用的 `common.back_to_map`（「返回地图」，无字间空格），与本屏「安 全 层」这类标题式按钮的字距处理不一致。
- **角色升级弹窗已实现**（2026-10-02，`LevelUpPopup.cs`，稿 `drafts/character/LevelUp.dc.html`），叠在本屏与登塔结算之上；现状层还没有它的卡，待补。
