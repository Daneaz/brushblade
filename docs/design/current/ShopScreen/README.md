## 数据（`ShopRules`）

- 字摊按稀有度打包卖：每捆 20/10/5/2/1/1/1 张，捆价 200/240/250/240/260/400/600（白→红）。

- 字卡广告位每档每日一次；两条补给广告每日各一次；跨 UTC 日由 `ShopRules.EnsureShelf` 复位并持久进存档。
