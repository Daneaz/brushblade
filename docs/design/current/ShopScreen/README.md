## 数据（`ShopRules`）

- 字摊按稀有度打包卖：每捆 20/10/5/2/1/1/1 张，捆价 200/240/250/240/260/400/600（白→红）。
- 宝箱位底价 230/460/700/1180/2850/3850/4870（素纸→赤霄），档位随角色等级每日掷出；箱位满（4）时不可买，按钮直接写「箱位已满」而不是点了才弹窗。
- **每日随机打折**：字摊每格与宝箱位各掷一档；常规 3~7 折，橙 / 红字与朱漆 / 赤霄匣 6~8 折。实付 = 底价 × 折扣（取整）。折扣表里没有不打折这一档，所以每格每天都挂价签、划原价。
- 字卡广告位每档每日一次；两条补给广告每日各一次；跨 UTC 日由 `ShopRules.EnsureShelf` 复位并持久进存档。

## 与稿的差异（2026-09-20 用户拍板）

- 订阅条只占位，不做成可买。
- 不标「今日推荐」：进度预告已经说清了该买哪张，再加一层推荐标是同一件事说两遍，也容易读成催购。

## 代码侧已知问题（只记录，未改代码）

- **部件分支是死代码**：`GameRoot.ShopCardPool()` 只放已拥有的**非部件**字，紫档广告位候选（`ChestCardPool`）也不含部件，`ShowShop()` 还会把混进部件的旧货架作废重摆。`ShopView.CardFace` 里的 `def.IsComponent` 分支、`shop.slot.component_note`（「合成材料,不占卡池」）与「部件不画角标牌脚」这条规则，运行时到不了。本卡因此**不画部件摊位**。
- **倒计时不走字**：`RefreshCountdown()` 只在 `Rebuild()` 时算一次，玩家停在页面上时数字是死的；跨 UTC 0 点时 `EnsureShelf` 不会重跑（它只在进页时调），货架仍是昨天的而倒计时已跳回 23:xx。
- **toast 不会自己消失**：画一次后要等下一次 `Rebuild()`（即下一笔交易）才没，停在页面上它会一直挂着。
- **字牌列高略超行高**：一格 = 牌 180 + 牌脚 17 + 预告约 22 + 钮 46 + 3 段间距 24 ≈ 289，比 `SlotRowH` 280 多约 9（按字号估算，未实机核对是被压缩还是溢出）；preview 按名义尺寸画。
