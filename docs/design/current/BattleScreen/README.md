## 版面
- 背景：层段宣纸底加一个层段巨字水印（见「层段底」）。
- 顶栏：左边是段标题 · 战斗序号 · 层数；右边依次是墨锭、回合数、「速度 ×N」、「设置」、引导「?」、退出。
- 左窄栏 68pt：常驻的相克图，下面是配字表（一行一条「字 缺 N」）。
- 中区自上而下：敌方后排 / 前排各恒定 4 格（空位也占格，贯穿/横扫按列结算）→ 分隔线 → 召唤物前排 / 后排各 4 格
  → 执笔人条（血、行动条、AP 三格、状态栏）→ 字库行（`GlyphTile` + 广告位）→ 部件池行。
  单位格一律横排：立绘在左，名字和状态在右。
- Boss 横跨中间两列、上下两排（见「Boss 格」），随从各占左右两列。
- 右栏拆合台：选中字详情 → 出 / 拆 / 弃 → 可合成列表（`ScrollList`）→ 结束回合。
- 屏幕最底下的安全区留白里有一条提示行。

## 读法
- 血条颜色：敌方红、召唤物绿（`done-green`），执笔人红。
- 行动条超过 80% 转「将行动」色：敌方朱砂，我方 `done-green`（不是翠玉 `jade`）。
- 状态 chip 按**行数**截断：敌人格和前排召唤格最多 2 行、后排召唤格 1 行，执笔人状态栏最多 2 行。
  多出来的从尾部丢掉，末尾补「+N」。「射程 · 攻击力」和护甲排在最前，永远不会被丢。
- 出手反馈是打在格子上的飘字，不用顶部提示条；文字类提示一律走最底下那条提示行。

## 使用方提供
层段与层数、敌我单位（属性、血、盾、行动条、状态；Boss 当前阶段）、手牌与部件池、选中字、可合成配方、
近缺配方、回合与 AP、墨锭余额、加速开关状态、底部提示文案。
