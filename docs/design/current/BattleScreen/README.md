战斗屏整屏参考（932×430pt 横屏），状态为选中手牌「冷」；对应实现 `BattleView.cs`。

## 版面
- 顶栏：层段 · 层数 · 场次，右侧墨锭、回合数、引导「?」与退出。
- 左窄栏 68pt：常驻相克图 + 配字表（一行一条「字 缺 N」）。
- 中区：敌方后排 / 前排各恒定 4 格（空位也占格，贯穿/横扫按列结算），分隔线，召唤物前排 / 后排，执笔人条（血、盾、行动条、增益 chip、AP 三盏）。格内横排：立绘在左、名与状态在右。
- 底部：字库手牌（`GlyphTile`）与部件池，满了走看广告扩格。
- 右栏拆合台：选中字详情 → 出 / 拆 / 弃 → 可合成列表（`ScrollList`）→ 结束回合。

## 读法
- 敌方血条红、召唤物血条绿；行动条 >80% 转「将行动」色（敌朱砂、我翠玉）。
- 状态 chip 每格最多 3–4 枚，多的收成 `+N`；底色按类别（见 Chip）。
- 出手反馈是打在格子上的飘字，不用顶部提示条。

## 使用方提供
敌我单位（属性、血、盾、行动条、状态）、手牌与部件池、选中字、可合成配方、回合与 AP。

## 敌方格（按 `BattleView.DrawEnemies` 再现，不按稿）
- **立绘**：分层字怪 `MobView`（body / face / wisp 三层等大叠放，无底无框；有状态层的怪按战斗状态点亮，示例里生僻字未读懂、罩着墨雾）。前排 60pt、后排 46pt。取不到形象（眼下只有墨海随机成语 Boss）时回落为属性色圆形字头像。
- **格子**：无底无框，格位 140×66（前）/ 140×52（后）pt。选目标态下可点的格整格压 `ink` 7%；拖字悬停时主目标同为 7%、溅射 3.5%。稿上的朱砂描边目标态与脉冲光实现里没有。
- **头行**（2026-09-19 拆两行）：只放名字（宋体约 9pt）+ 属性徽章（`<el>-glyph` 字形色底白字；未读懂为「?」、`neutral-part` 底）。
- **chip 流**：「射程图标 · 攻击力」（`paper-dim` 底）与护甲（>0 才出，`ink-soft` 底）排在最前、永不被截，后接战况，顺序即优先级 —— 蓄力、灼烧(数)、不灭、流血(数)、冻结、减速、致盲、沉默、诅咒、破甲、魅惑、能力特性；控制与减益只出图标不带数字。chip 字约 7.2pt，最多 2 行（后排召唤格 1 行），超出从尾部丢、补「+N」。集火（focus）与横扫没有 chip。
- **条**：血条（约 9pt 高）`paper-dim` 底 `cinnabar` 填充、血值白字描边约 6.2pt；行动条 >80% 转 `cinnabar`。护盾条已移除，盾只在立绘左下的金色角标上。
- 示例数值：攻击力按血量同倍率（×3）缩放自 `enemies.json`；这 8 只都不带护甲，所以头行没有护甲 chip。


## 召唤物格（按 `BattleView.DrawSummons` 再现）
- 两排各 4 个槽位（格 138×54 / 138×42pt），与敌人格同构：立绘在左、信息列在右。空槽平时什么都不画、只占位；选位态才铺翠玉高亮与淡墨落点块。未到层数的槽画压暗的「N 关解锁」（本卡 44 层，已全开）。
- 立绘是圆角方块：`<el>-soft` 底、`<el>-fg` 字（黑体，字号 = 边长 × 0.46）。
- 头行：召唤它的那张字（不是它自己的字，自己的字已印在立绘上）+ 属性徽章（字形色底）。chip 流：「射程 · 攻击力」、护甲（有增益才出）、被动特性（朱砂底，只出图标）、身上的状态（先负面后正面）；前排最多 2 行，后排 1 行。
- 血条 `done-green` 填充（友军不用红），血值叠字；行动条带百分比叠字，>80% 转 `done-green`。赭金底的状态 chip（攻、战意、暴、锐）图标压 `gold-text`。

## 执笔人条（按 `BattleView.DrawPlayerStats` 再现）
- 定高 40pt、与战场同宽 584pt，透明底。顺序：墨色立绘（护盾角标在左下，没有等级角标 —— 项目没有玩家等级）→ 信息列（「执笔人」+ 右端「血 N/M」、血条无叠字、行动条带百分比）→ AP 竖笔画格 → 状态栏（定宽 120pt，最多两行，收 +N）。
