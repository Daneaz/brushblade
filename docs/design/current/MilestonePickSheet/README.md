## 读法 / 交互

- **候选第一次打开就定死**：`MilestoneRules.GetOrCreateOffer` 从可掉落池里按该档稀有度不重复抽 3 张，新生成就立刻 `save()`；关掉（× 或点遮罩）再进还是这几张。候选池不足 3 张就有几张给几张；一张都没有时画一行 `milestone.no_candidates`（23 `text-dim`），并不落档空候选（否则红点永亮）。
- **选中**：点牌 → 这张的环变 `ink-soft`、其余透明，「收下」从 `locked-bg` 底 `text-dim` 字换成 `cinnabar` 白字。没选之前点「收下」什么都不做（钮仍可按，只是 `picked == null` 直接 return）。
- **收下**：`TryClaim` 校验（可领、在候选里、字表里还有这个字）→ 加墨锭、加卡（已有就是一张重复卡）、记已领、清候选 → 存档 → 关弹窗 → 角色页重建。
- 字表删字后的幽灵候选不画，也领不走。
- 已拥有的字照样能选，那张 chip 写清「重复卡 +1」—— 选它不亏，只是换成升级材料。
