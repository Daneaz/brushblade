## 0. 字牌与字怪的三点根本不同 —— 决定了交付什么

上一轮字怪是「一只怪一套图」。字牌**不能这么做**,原因有三:

| | 字怪 | 字牌 |
|---|---|---|
| 数量 | 19 只,固定 | 现 20 张,长线目标 300+ 字 |
| 字形 | 烘进图里(每只怪就那一个字) | **必须运行时渲染** —— 300 字不可能逐张出图 |
| 观看方式 | 被观赏 / 被攻击,低频 | **每回合都在读**,同屏最多 8 张,高频交互 |

由此定下三条:

1. **交付物是 6 套「框」,不是 20 张「牌」。** 按稀有度出六套底框模板,字形、拼音、AP 由代码填进去。
   这样扩到 300 字零增量成本。
2. **框必须是 9-slice 可拉伸的。** 字牌有 76×96 / 96×118 / 118×142 / 150×180 四种在用尺寸,
   一套素材要能撑住全部,所以四角固定、四边可拉伸(Unity `Image.Type.Sliced`,项目已在用)。
3. **动效必须克制,且强度随稀有度递增。** 同屏 8 张牌全在飘会很吵,还会干扰读字——
   而「白牌几乎不动、红牌持续流光」正好一石二鸟:既守住可读性,又让高级感成为**可感知的差异**。

## 1. 两套颜色的分工(最重要的一条规则)

字牌上同时有**属性**(六系)和**稀有度**(六档)两套颜色系统。不分工就会打架,一张牌上七彩斑斓。

| 信息 | 占据的视觉通道 | 现状 |
|---|---|---|
| **属性**(火/水/木/金/土/心) | **字形本身的颜色** + 顶部色条 | 字形已是属性色;顶部条现在是稀有度色,**建议改为属性色**(见下) |
| **稀有度**(白→红) | **框的材质、边饰、角饰、光效** | 现在只有一条顶部细色条 |

**建议调整**:把顶部色条从稀有度色改成**属性色**,与字形同色形成呼应;稀有度完全交给框去表达。
这样两套信息各占一个通道,零冲突——玩家扫一眼颜色知道属性,扫一眼框知道稀有度。

### 铁律:白底不能丢

用户明确要求保留白色背景。所以**材质递进只走边框 / 角饰 / 光效,牌面主体始终以白为主**,
最多加极淡的肌理(不超过 8% 不透明度)。高稀有度**不许**把底染成深色或大面积上色——
那会毁掉字形的对比度,也毁掉「一眼识别属性」。

### 实船色值(写死,直接用)

| 属性 | 色值 | | 稀有度 | 色值 |
|---|---|---|---|---|
| 火 | `#C53637` | | 白 | `#A19E98` |
| 水 | `#0F74C4` | | 绿 | `#2E9E52` |
| 木 | `#348F4F` | | 蓝 | `#0F74C4` |
| 金 | `#B3A382` | | 紫 | `#7945AB` |
| 土 | `#997C3C` | | 橙 | `#E1791B` |

牌面白底 `#FFFFFF`,宣纸底 `#F6F1E7`,墨 `#111622`,淡墨 `#3D4E69`。

## 2. 六级材质递进 —— 直接复用宝箱的名字

游戏里已有一套现成的六级材质语言:**宝箱**(19.5.1)。字牌沿用同一套,全局一致——
玩家开出「紫檀匣」,里面掉出的紫卡就该是紫檀质感的框。这个呼应是白捡的。

| 稀有度 | 材质名 | 框的设计要点 | 光效 |
|---|---|---|---|
| 白 | **素纸** | 最朴素:一道极细的灰边,四角微微起毛。纸的糙感,几乎无装饰 | 无 |
| 绿 | **竹简** | 边框化作两道竹青细线,左右两侧有极浅的竹节纹;四角收成竹片切口 | 无 |
| 蓝 | **青瓷** | 边框是一圈釉色,带**开片冰裂纹**(细如发丝的不规则裂纹,青瓷的签名特征);四角有釉的堆积感 | 极微的釉面反光 |
| 紫 | **紫檀** | 边框是深紫檀木框,有木纹与倒角;四角**嵌一枚小小的螺钿点**;整体开始有厚度 | 边缘一层极淡的辉光 |
| 橙 | **鎏金** | 金属边框,**錾刻回纹**(传统器物的连续几何纹);四角是浮雕云头;边缘有拉丝金属反光 | **流动的金边**(光沿边框跑) |
| 红 | **赤霄** | 最高规格:多层立体框,外层朱砂金属、内层暗纹;四角是完整的云雷纹角饰;边缘有轻微的外溢霞光 | **持续星芒 + 缓慢粒子上浮** |

> 递进的抓手是三样:**边框复杂度**(无 → 单线 → 双线 → 木框 → 錾刻 → 多层)、
> **材质厚度**(平 → 平 → 微凸 → 有倒角 → 浮雕 → 立体)、**光效**(无 → 无 → 微反光 → 淡辉 → 流动 → 星芒)。
> 三样同步爬升,高级感才成立;只加光效不加结构会显得廉价。

## 3. 交付规格

### 每级一套,共 6 套

| 文件 | 内容 | 尺寸 | 必需 |
|---|---|---|---|
| `card_<tier>_frame.png` | 9-slice 底框:边框 + 角饰 + 白色牌面 + 极淡肌理 | 192×240 | ✅ |
| `card_<tier>_glow.png` | 光效层(边缘辉光 / 流动金边 / 星芒),**透明底** | 192×240 | 蓝级以上 |
| `card_<tier>_corner.png` | 角饰单独一张(若角饰复杂到需要独立驱动) | 64×64 | 可选 |

`<tier>` = `white` / `green` / `blue` / `purple` / `orange` / `red`。

### 9-slice 硬要求

- **四角安全区 28×28 像素**(192 基准):角饰必须画在这个方块内,不能越界——越界会被拉伸拉花。
- **四边中段必须是可平铺的**:上下边中段横向重复、左右边中段纵向重复都不能出现接缝或渐变断裂。
- **中心区留白**:字形、拼音、AP 会画在上面,中心 70% 区域**不许有任何装饰**,只能是白底或极淡肌理。
- 出图后请标注四边的 border 值(px),我按它设 `Image.Type.Sliced` 的 border。

### 最小尺寸验收

**所有设计必须在 76×96 下仍然读得出稀有度。** 这是战斗字库里的实际尺寸,也是最严苛的一关。
出稿后请把图缩到 76×96 自查:开片纹会不会糊成一片脏、錾刻纹会不会变成噪点、角饰还认不认得出。
细碎到这个尺寸就消失的装饰,等于没做。

## 4. 动效规范(我来实现,设计时要为它留位)

动效强度随稀有度递增 —— 这既是高级感的表达,也是可读性的保护。

| 稀有度 | 常驻动效 | 说明 |
|---|---|---|
| 白 | **无** | 完全静止 |
| 绿 | **无** | 完全静止 |
| 蓝 | 釉面反光**极缓**扫过(周期 6s+) | 几乎察觉不到,余光才注意到 |
| 紫 | 边缘辉光呼吸(周期 4s) | 淡入淡出,不改变形状 |
| 橙 | 金边流光循环(周期 3s) | 光点沿边框跑一圈 |
| 红 | 星芒闪烁 + 粒子缓慢上浮 | 最抢眼,但仅限边框区域,不侵入牌面 |

**通用交互动效**(所有稀有度共有,与上表叠加):

| 时机 | 动效 |
|---|---|
| 选中 | 整牌上浮 6px + 外框收紧高亮(现有行为,保留) |
| 可出手 | 极轻微的呼吸(±1.5%),提示"这张能打" |
| AP 不足 | 去饱和 + 压暗,不动 |
| 新获得 | 从稀有度色的光晕中"写"出来(呼应第 13 章的逐笔书写) |
| 合成成功 | 印章"咚"一下 + 稀有度光效爆一次 |

> 对设计的要求:**光效层要与框层分离**,否则我没法单独驱动它做流动/呼吸。

## 5. 逐级 prompt

### 统一风格前缀(拼在每条前面)

> 中国水墨与传统器物美学,宣纸质感;一张卡牌的**边框素材**(9-slice UI frame),
> 正方偏竖的圆角矩形,**牌面主体纯白**,只在边框、四角、边缘做材质与装饰;
> 中心 70% 区域必须完全留白(后续会在上面渲染汉字);
> 平面 2D,无立体投影,无人物无插画;透明背景之外的部分即为牌面白底;
> 装饰克制、精致、耐看,要经得起缩到 76×96 仍可辨识。

英文:
> Chinese ink-and-artifact aesthetic on xuan paper; a **card border asset** for 9-slice UI,
> rounded rectangle, **pure white card face**, all material and ornament confined to the border,
> corners and edges; center 70% must stay empty (a Chinese character renders on top later);
> flat 2D, no drop shadow, no illustration, no character art;
> restrained and refined, must stay legible when scaled down to 76×96.

### 5.1 白 · 素纸

> 最朴素的一档。一道极细的暖灰 `#A19E98` 边线,线本身有手绘的粗细变化;
> 四角纸边微微起毛、有极轻的卷曲。牌面是纸白,可有若隐若现的纤维肌理(不超过 5% 不透明度)。
> 无光效、无金属、无装饰纹样。要的是「一张干净的纸」。

### 5.2 绿 · 竹简

> 边框化作两道竹青 `#2E9E52` 细线,内外双线,线间距很窄;
> 左右两侧边框上有极浅的**竹节**横向分段痕迹;四角收成竹片被切断的斜切口。
> 牌面仍是白,可有极淡的竹纤维纵纹。仍无光效。比素纸多一分秩序感。

### 5.3 蓝 · 青瓷

> 边框是一圈青瓷釉色 `#0F74C4`(偏灰蓝、不刺眼),釉层有厚薄变化;
> **签名特征是开片**——细如发丝的不规则冰裂纹,沿边框分布,**不要蔓延进中心留白区**;
> 四角有釉在烧制时自然堆积的厚边。牌面白中透一点点釉青。
> 光效层:一道极缓的釉面反光,沿边框斜扫。

### 5.4 紫 · 紫檀

> 边框是深紫檀木 `#7945AB` 调的木框,有清晰的**木纹**走向与 45° 倒角,开始有实体厚度感;
> 四角各嵌**一枚小小的螺钿点**(贝壳的虹彩白点,是紫檀器物的典型工艺);
> 木框内缘一道极细的描金线。牌面白,靠近边框处有一圈极淡的木色晕染。
> 光效层:沿边框内缘的一层淡辉光,用于呼吸。

### 5.5 橙 · 鎏金

> 金属边框,鎏金 `#E1791B` 色,表面有**拉丝金属反光**;
> 边框上錾刻**连续回纹**(传统器物的方折几何纹样),纹路清晰但不密集;
> 四角是浮雕**云头**造型,有明确的高光与暗部,厚度感明显。
> 牌面白,边框内缘有一圈极淡的金晕。
> 光效层:一条明亮的流光带,后续会由程序驱动沿边框循环跑动 —— 请画成可平移的长条高光。

### 5.6 红 · 赤霄

> 最高规格,要一眼看出"这是顶级"。**多层立体框**:外层朱砂红 `#CD262E` 金属、
> 内层一圈暗色底纹、最内一道细金线,三层之间有明确的层次与厚度;
> 四角是完整的**云雷纹角饰**(商周青铜器的回旋雷纹),繁复但工整;
> 边框外缘有轻微的霞光外溢(像烧红的金属)。牌面仍守住白,只在四角内侧有极淡的霞色晕。
> 光效层:星芒(边框上几个点的十字星闪)+ 缓慢上浮的细小粒子,**全部限制在边框区域**,
> 不许侵入中心留白。

## 6. 负面词

> 无插画、无人物、无怪物;中心区域无任何图案文字;
> 不要投影、不要 3D 渲染、不要发光渐变背景;
> 不要赛博朋克、不要霓虹、不要游戏氪金卡牌的浮夸金光;
> 不要把牌面染成深色或大面积上色;
> 不要细碎到缩小即消失的装饰;
> 不要西式纹章、不要欧式花体边框;
> 边框不要过宽(不超过短边的 12%),否则挤掉中心的字。

英文:
> no illustration, no character, no creature; center area completely empty;
> no drop shadow, no 3D render, no glowing gradient background;
> no cyberpunk, no neon, no gacha-game gaudy gold;
> do not tint the card face dark or heavily colored;
> no filigree so fine it vanishes when downscaled;
> no western heraldry, no european florid borders;
> border width under 12% of the short edge.

## 7. 与字怪那套的关系

| | 字怪 | 字牌 |
|---|---|---|
| 底 | 透明 | **白**(硬要求) |
| 色彩逻辑 | 墨 80% + 属性色 20% | 属性色走字形,稀有度走边框 |
| 分层 | body / face / wisp / state | frame / glow(+corner) |
| 动效 | 常驻浮动,受击反应 | **按稀有度分级**,克制优先 |
| 数量 | 19 只逐只出 | 6 套模板,覆盖 300+ 字 |

两套共用同一个水墨器物美学与实船色值,但**字怪是生物、字牌是器物** —— 一个要"活",一个要"贵"。
