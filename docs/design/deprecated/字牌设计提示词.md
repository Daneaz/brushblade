我在做一款汉字拆合卡牌游戏《字·斗》,需要一套**我方字牌的边框素材**。附件是完整规范。

注意这次要的**不是一张张画好的卡牌,而是按稀有度分档的边框模板**——
字形、拼音、AP 由代码在运行时渲染上去,所以牌面中心必须留空。

**这一轮只要两套:白级(素纸,§5.1)和紫级(紫檀,§5.4)。**
一低一高,我要先确认这个跨度对不对、"越稀有越高级"的递进成不成立,再补绿蓝橙红。
(下一轮还会要 6 个属性动效元件,见 §4.3,这轮先不做。)

硬要求:

1. **9-slice 可拉伸**:四角安全区 28×28(192×240 基准),四边中段要能无缝平铺,
   **中心 70% 区域不许有任何装饰**。出稿请标注四边的 border 值(px)。
   同一套素材要撑住 76×96 / 96×118 / 118×142 / 150×180 四种在用尺寸。

2. **牌面必须是高明度浅底**(纯白到宣纸米 #F6F1E7 之间,不得更深)。
   原因:字形要在上面承载六种属性色,而且**同一个字可能左右异色**——
   组合字「桂」左边木是木系绿、右边圭是土系褐。底一压深,金/土两系立刻读不出来。
   字形用的是 §1.2 那套加深过的专用色板,请按它验证对比度。

3. **材质递进走边框、四角、光效三样同步爬升**,不要只靠加光效——
   只加光效不加结构会显得廉价。白级是"一张干净的纸",紫级要有木框的厚度、
   倒角、四角螺钿点和描金内线。

4. **光效层与框层分开出**,否则我没法单独驱动它做流动/呼吸。
   紫级的边缘辉光请单独一张,透明底。

5. **属性色与稀有度色分占不同通道**:属性走字形与顶部色条,稀有度走边框材质。
   边框上不要出现属性色,否则两套信息打架。

6. 遵守 §5 统一风格前缀(水墨与传统器物美学)与 §6 负面词。
   特别注意:不要插画、不要投影、不要氪金卡牌那种浮夸金光。

输出:**用 SVG**,素材放 assets/,命名 `card_white_frame.svg`、`card_purple_frame.svg`、
`card_purple_glow.svg`。

出稿前请自查一遍:把图缩到 **76×96**(战斗字库里的实际尺寸)看——
紫檀木纹会不会糊成脏斑、螺钿点还在不在、四角装饰有没有超出安全区。
细碎到这个尺寸就消失的装饰,等于没做。
