# 词组补全建议

> 生成:2026-08-01,基于 `人工筛选.md`(76 字,组内按稀有度从高到低)。
> ⚠️ 编辑本表请保存为 UTF-8。

## 口径

「词组」= **两张字卡凑成一个现代汉语常用词**(炽热、滋润、剿灭、保障)。
中文二字词**词序固定**,炽热 ≠ 热炽,表里一律按正词序写;倒序也成立的会注明。

### 四种标记

| 标记 | 含义 | 你要做的 |
|---|---|---|
| 🟢 **已闭合** | 两字都在 `人工筛选.md` | 什么都不用做,现在就能用 |
| 🟩 **已纳入(另册)** | 一字在手筛单,另一字在 `字卡稀有度与入选建议.md` 的 62 字入选池或 `chars.json` | 也不用补字,只是这条线你可能没注意到 |
| 🟡 **差一字** | 一字在池,另一字要补 | 决定补不补那一个字 |
| 🔵 **整词待补** | 两字都要补(如「保障」) | 成对引进,成本翻倍 |

### 建议字的来源

补的字**基本不是新造的**,大多已经躺在你自己的候选表里,提上来就行:

| 来源标 | 含义 |
|---|---|
| 〔补·绿〕 | 已在 `补充字池(白绿卡).md`,后接该表给的档位 |
| 〔选〕 | 已在 `字卡稀有度与入选建议.md` 的 62 字入选池 |
| 〔候〕 | 在某个系的 `XX系卡池候选筛选表.md` 里出现过 |
| 〔新〕 | 三张表都没有,真要新加 |

### 稀有位次怎么读

`燃烧 = 燃⁴+烧⁵` 表示两字在各自定位组里排第 4、第 5(越小越稀有)。
**词的稀有度 ≈ 两字位次之和越小越稀有**——`劈刺 = 劈¹+刺²` 是全池最贵的一对,
`墙壁 = 墙⁵+壁⁶` 是白菜价。这决定词组联动该给多大的效果。

#### A1 · 木系救场三字:**林(已有)/ 枝 / 棘**

木系是唯一需要**结构性补字**的系。树种名之间不组词,得靠「通配后缀」串起来。

| 字 | 归系·定位 | 来源 | 能组的词 |

| **枝** | 木·召唤 | 〔补·绿〕 | 🟡 桃枝 柳枝 松枝 桑枝 梅枝 槐枝 柏枝 荆枝(**8 条**)/ 🔵 枝叶 枝蔓 |

| **蔓** | 木·召唤 | 〔补·绿〕 | 🟡 **藤蔓**(藤² 唯一能组的词)/ 🔵 蔓延 枝蔓 |

> 佐证:`补充字池` 里 **荆** 的备注原文就是「荆棘,可做带刺召唤物」,`mechanic_pool` 给 棘 打了 ★★★

## 七 · 顺带发现的问题

1. **崩 在 `人工筛选.md` 里写了两遍**(105、108 行),土系攻击组实际是 6 字不是 7 字。
2. **巍 / 岿 在词组维度上是死字**。巍只能组「巍峨」(需补 峨),岿只能组「岿然」(虚字,做不了卡)。
   两字都排在土系防御第 7、8 位——**位次不低,但词组价值为零**。如果词组要做成机制,
   这两个字的稀有度应该重估。
3. **铡 / 剖 / 刮 / 铡 组词能力弱**:铡只有「铡刀」(刀是部件,🟩),剖割/刮削都是专业术语。
   金系御物组 9 字里,真正好组词的是 剑 锤 锯 镰 钩 锥,铡 镜 偏孤。
4. **镜 是个被埋没的枢纽**:镜面/明镜/铜镜(需铜)/水镜(水本体,🟩)/镜像。语感上适合做
   「反射/复制」类效果,现在排在御物组末位(#9)可能低估了。
5. **土系防御 vs 木系召唤,闭合度差 3 倍以上**(10 : 3)。若词组要做成通用机制,
   两系的强度会天然失衡,得靠 §四·A1 的补字或掉落权重找平。
6. **水系治疗组 5 字只有 1 个词**,且 浴⁴ 的两条出路(沐浴/淋浴)都要靠已入选的 沐/淋。
   建议把 沐 淋 从「跨系入选池」明确划进水·治疗定位。
