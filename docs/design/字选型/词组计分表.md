# 词组计分表

> 建立:2026-08-25 · 规格:`docs/superpowers/specs/2026-08-25-字表重构-design.md`
> **手工维护**。这是白/绿/蓝三档定档的判据来源 —— 改词表就要重排三档。

## 口径

「词组」= **两张表内字卡**凑成一个现代汉语常用词。正倒序算一条(炽热 = 热炽,只记一次)。

### 不收(2026-08-25 用户逐条拍板)

| 不收的类别 | 例 |
|---|---|
| **本体部件词** —— 火/水/木/金/土/山/石/刀 参与的 | 焦土、火海、海水、木棍、镰刀、碎石、淬火、浴火、山崩、洪水、活水、破土、土墙、石壁、刀锋、刺刀、灭火、火焰、战火 |
| **树种 + 林** | 松林、柏林、梅林、柳林 |
| **边缘 / 书面 / 生僻** | 战刀、热土、冰凝、尖锐、锋芒、凝结、熣灿、淹溺 |
| **另一字不在表内** | 藤蔓(蔓)、荆棘(棘)、灰烬(灰)、溶解(解)、崩塌(塌,2026-08-10 已移出) |

**收**:`冰 + X`(冰是紫档合成字,不是本体部件)、跨系词、以及虽偏书面但确为现代常用词的
(炽烈、铸剑、破碎)。

### 计分

1. 每条词按**搭档字的档位**记:白/绿/蓝 算同一档「低」,紫 = 2,金 = 3,橙 = 4,红 = 5。
2. 排序**先比最高档搭档,同档再比下一档,最后比词组总数**。
3. 定档:`≥3 条 → 蓝`、`= 2 条 → 绿`、`≤1 条 → 白`;再按五行配额与语义特例调整(见 spec §1.2)。

**语义特例(词组数说不通、由设计拍板上调的 6 张)**

| 字 | 词数 | 上调理由 |
|---|---|---|
| 爆 / 炸 | 1 | 「爆炸」语义极强,两个字必须同档(用户点名) |
| 藤 | 0 | 蓝档控制召唤,入场冻结是它的定位 |
| 剑 | 1 | 金系门面兵器,蓝档攻击召唤的代表 |
| 堡 | 2 | 蓝档肉盾召唤的代表(碉 留白,碉堡拆两档) |
| 刺 | 2 | 金系蓝档需要一张纯直伤 —— 剑 转召唤后这一格空了,而它还是教程演示字 |

**零词的两张**:藤(差「蔓」)、杖(拐杖/权杖的另一字都不在表内)。两张都是靠定位留下的。
