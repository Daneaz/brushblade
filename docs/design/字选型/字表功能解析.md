> 生成日期:2026-08-23 · 基线提交:`845d885`

## 口径说明

- **收录范围**:配置表 178 条中的 **105 个可出牌字**(有配方 + 有效果)。另 73 个无配方的部件/枢纽字只作合成原料,`IsLeaf` 会被奖励池过滤,玩家拿不到牌,故不入表。
- **攻击力**:字表没有独立的攻击力字段,此列取**直伤效果的 value**(已是 2026-08-12 全表 ×10 后的量级)。
  纯辅助字记 `—`;召唤字记 `召 攻×只数`(实际输出在召唤物身上);纯 DOT 字记 DOT 量。
- **相生 ×3**:配置表填的是**基础值**,配方原料含「生本字属性」的字(燊/焚/蒸/炑/沏/刲)实战 ×3。
  本表的攻击力与功能列写成 `70×3=210` —— 基础值与实战值都留着,读表不必回头查倍率;卡面(CharInfo)同口径。只有走生克结算的效果吃这个倍率,灼烧层数/召唤血攻/驱散条数是平值。
- **AP 消耗**:全表一律 1(2026-08-03 拍板与稀有度解耦),故不设列。
- **稀有度**:白 < 绿 < 蓝 < 紫 < 金 < 橙 < 红,枚举名 = 皮肤色 = 强度序。
- **拼音 / 近代字意**:字表(`chars.json`)没有这两个字段,新华字典原始数据又不入 git、
  且其释义以「本义」(古义)为主,与「近代字意」正相反 —— 故这两列在 `gen_char_doc.py` 的 `READINGS` 表里**手工维护**。
  近代字意取**今天还在用的常用义**;古义已废、现代只作人名/商号或字典生僻条目的字,直接标「今罕用」并注明来历。
  四叠字(𣛧 / 䥱 / 㙓)与 鍂 现代字典无通行读音,拼音记 `—`。
- **一级组成**:字表 `recipe` 原文,即玩家在局内实际拆出/合成的那一层。
- **二级组成**:只在**比一级多给出五行信息**时才填,否则记 `-` —— 两种记 `-` 的情况:
  ① 二级拆出来与一级完全一致(冰 = 冫 + 水,再拆还是 冫 + 水);
  ② 整串二级里只落一个五行部件(松 = 木 + 八 + 厶,只有一个「木」),多出来的中性部件对生克读表没有意义。
  填出来的那一层规则是:把一级的每个部件再拆一层 —— 部件自己在字表里有配方的用字表配方(游戏内口径优先),
  没有的退回管线的 IDS 拆解器(`decompose.split_once`,只拆 ⿰⿱⿲⿳ 且子部件须是真实字),
  两者都拆不动的(冫、隹、里…)保留原样,它已是这套体系的终点。
  **禾 也不再拆** —— IDS 能拆成 丿 + 木,但 禾 自己已经是一个整部件,再拆没有拆合语义。
  **五行部件(土、氵、钅…)一律不拆** —— 与管线同一条规则,再往下的「土 = 十 + 一」在拆合语义里没有意义。
  ⚠ **一级(字表配方)可能跳过字形的中间层**:荆 的配方是 艹 + 刂,把 茾 整个略去了,照配方展开原地打转。
  这类字改按字本身的 IDS 拆一层再展开 —— 荆 → 茾 + 刂 → 艹 + 开 + 刂。
  ⚠ **二级里由 IDS 补出来的部件(七、几、勹…)不是游戏内对象** —— 字表里没有,玩家拿不到、也合不出。
- **排序**:三张表一律**稀有度升序**;同稀有度内**二级组成部件数越多排得越后**;再按五行(木火土金水)。
  同稀有度里拆得更深的字排在后面(楸 = 木 + 禾 + 火 三部件,排在林之后);
  记 `-` 的行按**一级组成**的部件数计(全表配方都是两部件),故一律排在填出二级的字之前。
- **PUA 字**:木/金的四叠字在 Unicode 无合适码点,用私有区 U+E625 / U+E626 + 自造字形,文中标注 `(PUA)`。

# 四 · 扫表观察

以下为读表时的数值现象记录,**未做任何改动**,供后续 E-b4b5 的 T8 重平衡阶段取用。

1. **同档同效的重复字**:墙 / 壁(护盾 70 完全一致)、埋 / 坑(伤 60 + 冻结 1)、涛 / 淹(AOE 50)、
   桑 / 梅(召 血 60/攻 20)、割 / 剖 / 沸 / 碾(单体 60)。这批字玩家看不出差别,属于凑量。
2. **档位内跳变不均**:金档单体从 刲 150 直接跳到 鑫 / 錰 400;紫档金系 4 个字挤在 160~200 无区分度。
3. **紫档低攻召唤**:蕉(血 280/攻 30)、柘(血 320/攻 40)是纯肉盾定位,攻击力低于绿档的槐(攻 40),
   紫档的价值全押在血量上,牌面读感偏弱。
4. **远程召唤**:灶(攻 20)/ 烓(攻 30)是仅有的远程召唤物,无视敌方前排优先打后排;
   **2026-08-20** 前攻击力曾为 0,输出全在「命中挂灼烧」被动上,补基础攻后灼烧仍是主输出。
5. **心系空缺**:摄心流(第 5 章)与心属性的生克中立设定都已在引擎里,但没有一个心系字可出牌。
6. **`AttackEffects` 未启用**:`CharDef` 有「拖到敌人身上改用另一套效果」的字段(2026-07-26),
   但配置表里一条都没配,水 / 土 的「治疗/加盾之外多一个攻击选项」目前不存在。
