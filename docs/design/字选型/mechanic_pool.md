# 按游戏机制风味筛选的五行字池

口径:GB 一级常用字 · 两部件(一五行部件 + 一中性部件)· 字池 1019 字。
不按字典本义判五行,按**机制定位**判:火=DoT灼烧 / 水=治疗兼少量攻击 / 木=召唤植物 /
土=防御加盾兼少量输出 / 金=攻击器械。威力档按字面意象强度分 ★★★ / ★★ / ★。

| 威力 | 字 | 机制建议 |

| ★ | 烬 炼 烘 烤 焙 燥 煽 点 | 引燃 / 增幅已有灼烧 |

> 火系是全池最小的一系(69 字),且 `烃 烯 烷` 是化学名词、`秋 羔 耿 狄 黑 灵 煞` 与火无关,
> 实际可用只有 27 字。**这是硬缺口**,火系卡池要么复用度更高,要么破例收二级字(炙 焙 烊)。
> `熄 灭` 是反义,可考虑做成「熄灭灼烧换取爆发」的机制字,反而有设计空间。

## 跨系冲突字(结构五行 ≠ 机制五行)

这批字的部件属性和机制风味打架,是双系卡或重新归属的候选:

| 字 | 结构系 | 机制风味 | 建议 |
|---|---|---|---|
| 荆 | 金(艹+刂) | 木 · 攻击型植物 | 木/金双系,或归木 |
| 刺 | 金(朿+刂) | 木/金皆可 | 双系,做「荆棘」主题 |
| 砍 | 土(石+欠) | 金 · 攻击动作 | 归金 |
| 炭 | 土(山+灰) | 火 · 燃料 | 归火,补火系缺口 |
| 渠 | 木(艹) | 水 · 水道 | 归水 |
| 栅 桩 | 木 | 土 · 防御工事 | 木/土双系,做「木栅护盾」 |
| 灌 | 水 | 木/水皆可 | 双系:灌溉(木)/ 灌注(水攻) |
| 荧 | 火 | 弱,偏光效 | 可做火系辅助 |
