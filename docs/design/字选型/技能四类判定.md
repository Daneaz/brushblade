# 技能四类判定表(攻 / 防 / 召 / 疗)

对 `人工筛选.md` 全部 139 字逐字重新判定,**不参考原表的「类型」列**。

## 判定口径

| 类 | 尺度 |
|---|---|
| 攻 | 兵器、砍杀、爆燃、毒蚀,以及减益类(恐惧、迟缓、诅咒、致盲) |
| 防 | 屏障、城墙、坚硬、金属、遮蔽、固守 |
| 召 | 呼唤聚集、生成实体(亡灵、兽、灵、草木、器物) |
| 疗 | 恢复、滋养、净化、安抚、药石 |

二级序列:
- **攻** — AOE / 单攻 / 控制 / DOT
- **防** — 减伤 / 护盾 / 免伤 / 闪躲 / 反伤
- **召** — 单体 / 多体;肉盾 / 远程;是否附带被动(反伤、DOT、控制)
- **疗** — 即时直接 / 持续缓疗 / 吸血机制 / 生命链接 / 复活

排序规则:**五行归属不动**,只在各系内部按一级类 → 二级序列 → 威能从高到低排列。同组内排在前面的威能更高。

判定优先级(三条冲突时的裁决):
1. 兵器 > 金属 —— 剑戟锤锯锥钩镰铡锹錰 归攻,不归防。唯一例外是 **镜**(功能是反射)。
2. 实体 > 效果 —— 烓/灶(器物)、林木类归召,不按其战斗表现归攻/防。
3. 纯增益、纯资源、纯状态形容不入四类,单列。

## 六 · 四条都不沾(6 字)

这些字本身不产生伤害、护盾、实体或回复,是**纯增益 / 纯资源 / 纯状态形容**,不入四类。

| 字 | 系 | 字义 | 为什么不沾 | 仍可用作 |
|---|---|---|---|---|
| 煤 | 火 | 埋于地下的可燃黑石 | 是燃料矿物(资源),不是燃烧行为本身 | 资源牌:为己方火系技能续燃/加层 |
| 剡 | 金 | 削尖,使锋利 | 是对武器的加工,不产生伤害 | BUFF:大幅加攻 |
| 锋 | 金 | 刀刃最利处 | 是刀刃部位的名称,不是攻击动作 | BUFF:加暴击率 |
| 锐 | 金 | 刃利,气盛 | 纯锋利属性形容 | BUFF:加穿透 |
| 利 | 金 | 刀快,顺畅 | 纯形容 | BUFF:加攻速/顺畅出手 |
| 战 | 金 | 交兵,争斗 | 抽象战斗状态,无具体作用对象 | BUFF:进入战意状态 |

> 判定边界说明:火系的 **炽 / 热** 同为状态形容,但火本身即伤害源(温度直接烧人),故归攻·DOT 最低档;而锋 / 锐 / 利需依附武器才生效,故不入。
