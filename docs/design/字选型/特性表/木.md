# 木系特性表

特性设计以 spec `docs/superpowers/specs/2026-10-03-字卡五特性体系-design.md` §9 为准；本表是它的可执行配置。
面：`攻` = 攻击，`生` = 五行面，`两面` = 通用。形态：`主动` / `被动`。只有「实现」列以 ✅ 开头的行会导出到 chars.json。
2026-10-15 spec A:Lv1/Lv3 按面命名;Lv6 两面各一条;数值见详表 §1.4 注。林风 / 森风 / 浮藻 / 木疾 为 Lv5·五行面·被动(木灵速度 150 自本命挪来)。
2026-10-15 spec C:柘 坚心拆两行(攻面精进 21 / 生面本命 `SelfCut 15`);𣛧 参天之力、楸 秋实 攻面改先声(45 / 26);荆 披荆、藻 水草、桂 馥郁 攻面改名精进;桂冠删「免疫控制」。
2026-10-18 群攻入口(spec `2026-10-18-群攻入口与头领编组-design.md` §1):箭 / 楸 本体改贯穿 / 横扫;楸 Lv8 秋风扫叶 改「全体 50」(灼保留;原 `hitPercent 60` 是横扫版主目标折扣,随形状一并去掉)。
专属 Lv4 在攻面不起作用的(秋实 / 披荆 / 馥郁 / 水草 / 参天之力:都是木灵本命)拆成两行(D2-木 V4,同火 / 金 / 水 / 土):生面写本命,攻面按同档「先声」/「精进」写(`Amplify X` `scope All`,先声 `if FirstCastThisTurn` X = round(15 × 档位系数):紫 26、红 45;精进 X = round(10 × 档位系数):紫 18、金 21、橙 25),名字随效果改(spec C §2;原 D2-木 V4 名字保留原名)。柘 坚心同样拆两行:攻面精进,生面本命追加 `SelfCut 15`(本字木灵受到伤害 −15%)。双木 / 三木是字形特性(拆字 / 成字)。
本命追加(E37):非替换特性里的 `Summon 1`(0 血/攻 0) 不是一只 0 血召唤,而是把本命字段并进本面第一条本体召唤(随嫁接带走);本面没有召唤就空转。折桂 `battleLimit 1` = 每场 1 次(E49,击杀时;满库不入、不计次)。
书写顺序即结算顺序:林立先改形(1 只 → 2 只各 60%,E48)再挂光环;万木回春的复活排在本体召唤之后(Q28);绿潮的嘲讽挂在并入后的藻灵上。
专属数值(良弓 200、磐固 10 / 50、林荫 5 / 20、森严 25 / 3、蟾宫 10、桂花雨 75、桂冠 50、林立 60 / 20、擎天 30、落木 300、硬弓 400、撼天 200、柘弓 200、森罗 20、众木 10、林深 50 / 10、万木回春 30、荆刺 30、荆天棘地 30、一叶知秋 30、移花接木 100、林间 20、柘刺 59、森生 20、桂馥 50、落叶 30、花种 9、流血 35 等)是起值,由 Plan F 定标。口径见 `docs/superpowers/plans/2026-10-11-字卡特性-D2-木-专属.md`「已定口径」Q1–Q30。
