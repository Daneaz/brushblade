# 土系特性表

特性设计以 spec `docs/superpowers/specs/2026-10-03-字卡五特性体系-design.md` §9 为准；本表是它的可执行配置。
面：`攻` = 攻击，`固` = 五行面，`两面` = 通用。形态：`主动` / `被动`。只有「实现」列以 ✅ 开头的行会导出到 chars.json。
专属 Lv4 两面通用、但在一面意思不同或不起作用的拆成两行(D2-土 V4,同火 / 金 / 水):塔基 攻面 = 镇压 `armorStrike`、固面 = 护盾 + 护甲 × 3(`armorShield`,Q11);深厚 固面 = 护甲回合 ×2;攻面按 spec C §6 重做为厚积薄发伤害 +30%(`Amplify 30` `scope Spend`),名字不变。
同面多条 `Reshape` 的 `shieldStrike` / `armorStrike` **相加**(E27):塔 Lv8 攻面 = 塔基 300 + 镇塔 500;㙓 的山压 / 地动旧版已随 spec C §6 下架。三山改散射后,移山的 `shieldStrike 30` 留在三山首发(Q13,叠加设计);三山镇压逐发结算(`armorStrikeEach`,E31)。
书写顺序即结算顺序(Ruling 13):塔倾的 `ShieldSpend` 写在伤害之后(先打、后扣盾);厚德载物「翻倍」= `Amplify 100 scope Shield`,与 Lv5 厚土同轴相加。杜门不出 `battleLimit 1` = 整条特性每场 1 次(E35),第二次出字只剩本体。
专属数值(碉楼 / 载物 50%、闭门 63、叠土 126、三土 75、重土 63、堡垒 44、叠嶂 / 对峙 38、山岳门槛 50 / 破甲 38、圭角 32、杜门不出 −60%、铜墙铁壁 10% 等)是起值,由 Plan F 定标。口径见 `docs/superpowers/plans/2026-10-11-字卡特性-D2-土-专属.md`「已定口径」Q1–Q22。
2026-10-13 换新(spec `docs/superpowers/specs/2026-10-13-护盾回合保留与木灵替换-design.md` §2,护盾不再按回合清空、取消留存护盾):垒 Lv8 固 积土成山(脉冲护盾 16 = 本体 63 × 25% 四舍五入,按来源字等级缩放)、塔 Lv8 固 七级浮屠(出字结算完后按护盾计层)、㙓 Lv8 固 厚德载物(`turns -1` = 本场,木灵各得玩家当前护盾 10%)。数值为起值,交 Plan F3 定标。
2026-10-15 spec A:Lv1/Lv3 按面命名;Lv6 两面各一条;数值见详表 §1.4 注。
2026-10-15 spec C:碉 / 堡 Lv5 固改 池·培土;崩 / 㙓 攻击面以「厚积薄发」为核心重做(Lv1 / Lv3 / Lv4 深厚 = 厚积薄发伤害 +30% / Lv5 聚土·山积 释放前加层 / Lv6 崩裂·厚壤 按释放层数破甲 / Lv8 山崩 ≥8 层翻倍·地动 释放后全体护盾);崩的池·震地 / 池·余震 / 地裂、㙓 的山压 / 地动旧版下架。
