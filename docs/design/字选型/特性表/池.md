# 特性池表

特性设计以 spec `docs/superpowers/specs/2026-10-03-字卡五特性体系-design.md` §9 为准;本表是「池」词条的可执行配置。
各系特性表的行可写池引用:`名` 列写 `池·名`(系池,系须与该字一致)或 `通·名`(通用池),`形态` 与 `效果配置` 写 `—`;
管线按本表补全名称、形态、触发与效果,并校验槽位、面与池条目一致。

数值规则(D7):效果配置里的 `X` 是占位,展开为 `round(X基 × 档位系数)`(四舍五入,半入),
档位系数 白 1.0、绿 1.2、蓝 1.45、紫 1.75、金 2.1、橙 2.5、红 3.0;档位取自详表。spec 写死的数字不放大。
X 的起始值由 Plan F 定标。
