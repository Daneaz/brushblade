# 火系特性表

特性设计以 spec `docs/superpowers/specs/2026-10-03-字卡五特性体系-design.md` §9 为准；本表是它的可执行配置。
面：`攻` = 攻击，`燃` = 五行面，`两面` = 通用。形态：`主动` / `被动`。只有「实现」列以 ✅ 开头的行会导出到 chars.json。
专属 Lv4 加成在燃面不起作用的(焚风、干涸)拆成两行:攻击面写原条目,燃面按同档「先声」/「精进」写(`Amplify X` `scope All`,先声 `if FirstCastThisTurn` X = round(15 × 档位系数)、精进 X = round(10 × 档位系数)),名字随效果改(spec C §2)。气盛是 `scope All`,燃面也加本字灼的火力(G3),不拆(Ruling 9)。
焚天「保留 1/3 层」写 `retain 34`:保留按 ⌊N × R%⌋ 取整,灼上限 10 以内 ⌊N × 34%⌋ 与 ⌊N/3⌋ 逐位相等(写 33 会在 3 / 6 / 9 层少 1 层)。
2026-10-15 spec A:Lv1/Lv3 按面命名;Lv6 两面各一条;数值见详表 §1.4 注。
2026-10-15 spec C:燃面 Lv1/Lv3 慑 → 燃意(`Kindle`,拖到我方,全体字 `pick AllAllies`);燃面不再选敌,依赖主目标 / 本次灼的特性改 `pick MostBurn` / `Random` / `All`(上炎、焚心、焚城、炽焰、四火、焦土、炎炎、炫目、流光);燥 干涸、燚 四火拆两行;焚风燃面改先声;热 / 燥 Lv5 燃改 池·引火。炎 双焰、灿 火山(拆字,作用在部件出手上)不动。
