# 水系特性表

特性设计以 spec `docs/superpowers/specs/2026-10-03-字卡五特性体系-design.md` §9 为准；本表是它的可执行配置。
面：`攻` = 攻击，`润` = 五行面，`两面` = 通用。形态：`主动` / `被动`。只有「实现」列以 ✅ 开头的行会导出到 chars.json。
专属 Lv4 两面通用、但在一面不起作用的(冰封 / 怀山:润面无冻结;汪洋 / 沐恩:攻击面无治疗;淋漓:润面无减速;湮灭:润面无击杀)拆成两行:生效面写原条目,空转面按同档「先声」/「精进」写(`Amplify X` `scope All`,先声 `if FirstCastThisTurn` X = round(15 × 档位系数):金 32、橙 38;精进 X = round(10 × 档位系数):紫 18、金 21、橙 25、红 30),名字随效果改(spec C §2;原 D2-水 Q2 名字保留原名)。
「被本字冻结 / 减速」类(`pick FrozenByThisCast` / `SlowedByThisCast`:冰封、寒彻、冰水、淋漓、池·冰缚)推迟到本面效果循环末尾施加(E16),所以同面 Lv8 新冻上的目标也吃得到;代价是同面排在它后面的伤害吃不到它挂的标记。冰晶的 `ShieldFrost` 必须写在同面 `ShieldFromHeal` 之后(按本次已给的护盾判定)。
同面多条 `Reshape` 按非缺省字段逐项叠加(D2-金 / D2-土 的剁、锥、鑫、碉、垒等都靠这一条);唯一例外是改成 `shape Scatter` 且自己没写 `hits` 时,前一条的多段(`hits` / `hitPercent` / `perHitFrom`)重置为缺省 —— 散射只有首发吃主目标多段,叠上去不成立。所以淋 Lv8 攻面是纯暴雨(5 发 × 30%,每发减速),倾盆的多段与 `extend` 不再残留(D2-水 Ruling 14 修订)。
管线按格内书写顺序落表(D2-水 Ruling 13,D2-土 前置修复),出字按这个顺序结算:濯身的 `Cleanse` 写在 `HealSelf 50` `per Cleansed` 之前,回复读到的就是本次清掉的条数。无数值 token(`Cleanse`、`Reshape`、`DispelAll`、`WellspringFill` 等)不必再改写成带数值的形式来占位。
专属数值(冷却减攻 50、淋漓 30、濯身 50、浇熄 50、大雨滂沱 45、沐雨 63、春雨 17 / 水大无际 40 的跨场润泽)是起值,由 Plan F 定标。口径见 `docs/superpowers/plans/2026-10-10-字卡特性-D2-水-专属.md`「已定口径」Q1–Q28。
2026-10-15 spec A:Lv1/Lv3 按面命名;Lv6 两面各一条;数值见详表 §1.4 注。
2026-10-15 spec C:湮灭攻面改击杀时随机冻结、润面拆出精进;冷 / 海 Lv5 润改 池·化水;冰封 / 汪洋 空转面改先声,淋漓 / 沐恩 / 怀山 空转面改名精进;溃 / 㵘 攻击面以「涌泉相报」为核心重做(Lv1 / Lv3 / Lv5 引泉·汇流 / Lv6 回澜·浩荡 / Lv8 决堤·滔天,㵘 Lv4 攻面怀山 = 涌泉相报伤害 +30%,`minSpent` 读本次释放层数);泽被删 Reshape 改净化 + 治疗 +30% + 溢疗转盾,泽及四方删 Reshape。
