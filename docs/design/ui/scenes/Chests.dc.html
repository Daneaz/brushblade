七档宝箱立绘

七只箱是七种材质，不是七种颜色——原先格子里画的是一个色块加「素」「竹」这样的首字， 七档只有色相之差，玩家分不出「哪只更值得等」。改法是让工艺随档位递进： 纸 → 竹 → 瓷 → 木 → 金 → 漆 → 铁函，越往上五金越多、轮廓越"抬头"，赤霄那只干脆关不严。
已落地（2026-08-30）：本页的 SVG 就是游戏里那批素材——tools/design/build_chests.py 逐字抄这里的 path 出 PNG，接 ChestAssets / ChestView。改这一页就重跑那个脚本。
画法与 mob 素材同规格：1:1 方图、四周留 10% 白、墨线 #111622、纸底 #FFFDF7； 属性色只铺一块大面积平涂（盖或身）——40px 缩略图里认色全靠它，细节那时一概看不见。 色值逐条取自 Theme.ChestColor，数值取自 ChestRules。

本页的 SVG 可以直接当素材用——箱子是器物不是活物，矢量墨线画得住，还省一套 512 方图。 要与 mob 那批painterly 立绘统一，再按下表出图：底稿用本页 SVG 作 ControlNet 输入， 让模型只长材质与光，轮廓一律不许改——七只箱的辨识度全在轮廓上。 分层沿用 mob 那套 body / face / wisp，箱子对应 body（器物）、 face（五金与封条）、wisp（光与气）；赤霄那只的缝隙光单出 state 层， 好让「已就绪」直接换层强度，与焦痕的火芯同一套做法。
