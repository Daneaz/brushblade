详情页数值口径

字表里字卡本身没有攻/血字段，只有效果。四格数值都是从 effects 现算的—— 有则出、无则整格不占位，绝不显示「攻击 —」。
数值格取自写法例该字详情显示
攻击 DamageSingle / DamageAll 效果值；全体伤在副标注「全体，每个目标」 冷 攻击 90（单体）
攻击 Summon.attack 召唤字的「攻击」是召唤物的，副标注「召唤物每击」 藤 攻击 40 · 血量 80
血量 Summon.value 召唤物血量，副标注只数 ×N 楸 血量 88（召唤物 ×2）
护盾 Shield 盾值 垒 护盾 50 · 攻击 30
治疗 HealSelf / HealAll / HealOverTime 单次回复量；持续治疗的每回合量 澡 治疗 50 · 攻击 70
不进数值格 Burn / Freeze / Slow / ArmorBreak
Morale / Dispel / Revive / …		 没有可比数量级，全部走下面的「字卡功能」整句 焦 只有功能行，无数值格
两重缩放都已算进显示值： 卡等级按 MetaRules.ScaleByCardLevel 缩放； 相生「他生我」的 ×3 直接计入并在字头挂一枚相生 ×3徽标—— 照旧只作用于伤害／护盾／治疗，召唤血攻、灼烧层数不乘，与 CharInfo.IsWuxingScaled 同一套判据。
