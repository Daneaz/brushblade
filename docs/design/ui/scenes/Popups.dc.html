飘 字 与 全 屏 反 馈
战斗屏 2026-08-15 把顶部那条提示带撤了（搬到屏幕最底部只留一行）， 从那以后「这一下打中没有、打了多少」全靠飘字——它是局内唯一的即时反馈通道， 所以口径必须固定：颜色说的是「谁干的」，不是「好事坏事」。
朱砂 = 你打出去的直伤；赭 = 持续伤害自己在烧；靛 = 护盾与治疗；翠玉 = 无效化与分裂； 墨 = 击杀；赭金 = Boss 换相。小字号（13）留给一拍里会连着冒好几条的那些（灼烧跳伤、敌方自增益）， 免得糊成一团盖住战场。
