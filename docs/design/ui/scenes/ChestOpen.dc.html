出什么字 五道闸，按 TryOpen 的实际顺序

①池的快照
箱是掉落那一刻就把奖励池抄进 CardPool 的。放着不开不会跟着后来的进度变 —— 早拿的箱按早的池开。
②前置过滤
配方里含非叶子原料而你还没有的字，先剔出去（叠字前置）。滤空则整条限制让路，回退未过滤的原池——出满数优先。
③稀有度权重
按箱档掷稀有度，单位是千分比：红在鎏金匣只有 0.1%，百分比装不下这一档。再在该稀有度的字里等概率取一个。
④单箱保底
青瓷保 1 张蓝，紫檀及以上保 1 张紫。金 / 橙 / 红不在这里 —— 两套保底叠在一起会让高稀有度过量。
⑤计数保底
开满 N 只够档的箱还没见过该档，下一箱强制替一张进来：红 20 只赤霄 / 橙 10 只朱漆+ / 金 5 只鎏金+。自然掉出的也算，所以它只兜非酋、不抬产出。
鎏金匣一张牌的稀有度分布（千分比，合计 1000）——白字整档不出，金 5%、橙 1%、红 0.1%：

三条节奏阀，都不是每日上限：
· 箱位 4 只，满了再掉的箱进暂存，开一只补一只；
· 同一时间只有 1 只在计时，已就绪的不占位；
· 广告每箱只能用一次，墨锭加速 1 墨 / 2 分钟（向上取整）。

命名冲突，落地前拍板：卡的第 6/7 档在 strings 里叫橙 / 红， 而箱的第 6/7 档叫朱漆 / 赤霄；卡组稿里另给稀有度起了「赤金 / 朱漆」的雅名 —— 「朱漆」现在同时是一档箱名和一档卡名。本稿一律用 strings 的白绿蓝紫金橙红。

落地清单 ⚠ 稿子先行的四件

  1. 结果面板改左右分栏：ShowChestResult 现在是 VStack + 每行 8 张写死。改成左信息栏 + 右网格，牌宽按张数在 96 / 70 两档之间取。
  2. 面板尺寸：0.16~0.84 的锚点换成安全区内定尺 814×380 —— 横屏下按比例锚点会随机型漂，而这一屏的排布是按牌数算死的。
  3. 新字要标得更重：现在新卡与重复卡的 chip 只差颜色（ExitPink vs AdGreenBg），一眼扫过去分不出。稿把新字牌脚做成实心胭脂底 + 加粗字距。
  4. 本页无新增游戏文案：五个 key（result_title / new_badge / upgrade_progress / claim_button / common.maxed）都已在 strings 里， 不必重跑字体子集 —— 但「满级」若要改写成别的词，就得跑一次 tools/fonts/subset_fonts.py。
