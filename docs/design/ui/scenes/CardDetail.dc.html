1

数值

攻击 / 治疗 / 护盾 / 血量,有则出、无则不占位。格子里不再有下面那行小注 (「单体,每次」之类)—— 那句话现在由第 2 段整段来说,留在格子里是同一件事说两遍。 数字已按本场卡等级缩放,印的就是这一级真正打出来的数。

2

攻击模式

这一记打谁、护谁:单体攻击 / 全体攻击 / 单体护盾 / 全体护盾 / 单体治疗 / 全体治疗。 一格一条,行尾补一句形状上的限定(越过前排、贯穿溅射、共几段)。 双方向字(水 / 土)两面各占一格,前面那枚色点就是方向 —— 朱砂是攻、翠玉是护。

3

召唤

只有召唤字才出这一段,而且排在最前。召唤字的一切都是这几只的 —— 先看清召出来的是什么、几只,后面那三段才有主语。

召几只就画几只,不写「×2」也不写说明:数出来的比读出来的快, 血与攻就在下一段,再写一遍是同一件事说两遍。

这一支的另外两段标题都点名(召唤物) —— 数值(召唤物)、特性 · 技能(召唤物)。 召唤字自己不打人,不点名的话玩家会把「攻击 44」读成这张牌的伤害。 攻击模式对召唤物是近战 / 远程(它够不够得着后排),不是单体 / 全体。

4

特性 · 技能

原来的「字卡功能」整块文字换成这一段,与召唤物 / 敌人详情里那块逐像素同款: 一条一张小卡,头是「图标 chip + 名」,下面一行说明。玩家在三处读到的是同一种东西。

图标走 Icons.cs 那 30 枚(灼烧 / 致盲 / 荆棘 / 破甲 / 战意…); 没有图标的退成纯文字 chip(偷袭、嘲讽、斩杀、分段…), 宽度与带图标的一致,行与行仍然对得齐。
