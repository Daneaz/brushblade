| 已就绪 | 「已就绪」23 → 10.99 `upgrade-text` **宋体** | 「开箱!」`gold` 底 `gold-text`，150×50 → 23.89 高、字号 22 → 10.51 |

- 按钮行开了 `childForceExpandWidth`：**150 / 72 是 preferredWidth 不是定宽**，余量按 flexible 均分 —— 单钮铺满整行、双钮各占一半。
- 宝箱同时只能开一只：`start.interactable = !AnyChestTiming()`，其余格的「开始开启」置灰。uGUI 只把 disabledColor(0.78,0.78,0.78,0.5) 乘在**底图**上，子节点的 `Text` 不受影响 —— 底色淡成半透、白字仍是纯白。
- 广告缩短的量是 `AdReductionSeconds[tier-1] / 60`：素纸 5m / 竹简 30m / 青瓷 40m / 紫檀 60m / 鎏金 90m / 朱漆 105m / 赤霄 120m；卡片示例的鎏金匣是 `-90m`。墨锭价 = `⌈剩余秒 / 120⌉`。
- 「已就绪」是主界面唯一的常驻动效（`ChestView.Update`，周期 1.6s、三段同相）：光晕 alpha 0.45↔1、盖缝 0.55↔1、箱身起伏 = **边长 × 2.5/120**（84 的立绘上是 1.75 逻辑单位 ≈ 0.84pt；稿上写的 2.5px 是 120 画布里的量，不是屏上的量）。
- 三态**只换叠加层、不换底图**：一只箱一张 `body` 素材 + 一张 `seam`，另有与箱型无关的 `chest_fx_ready` / `chest_fx_timing` 两张。箱色 `Theme.ChestColor(tier)` 已于 2026-08-30 委托给 `RarityColor(RarityOf(tier))`，与卡牌七档同一套色，也与 `tools/design/build_chests.py` 烤进 PNG 的 TIERS 表逐档对上。

## 读法

- 主钮上只放动作，层段与层数放在按钮下 —— 523 的钮里排不下「续爬 ·「文山」第 44 层」。
- 没有断点存档时：主钮文案换成「登 塔」，钮下只有一行「每 5 层一位 Boss，战胜后可收官或深入」，**不出**血条、账目与断点说明。
- 四格红点各有各的判据，都问 Core：收集 = 有字能升 **或** 有没看过的新字；图鉴 = 有已解锁未查阅的条目；技能 = 有技能现在就能升；商城 = `ShopRules.HasRedDot`。亮着而点进去无事可做是最烦人的那种假消息。
- 页签图标 PNG 缺失时**什么都不画**（名字就在旁边），不补兜底汉字。

## 已知差异

- 出阵表已于 2026-09-06 废止，角色栏底部改成卡池摘要（`MetaRules.PlayableCards` = **已拥有的非部件字**，不是整张字表；顶档那几张正是起手第 6 格保底会抽到的池子）。卡上原来的「出阵 8/15」小牌墙已移除；画布上「每排 6 个折行、上限 15 → 最多三排」那一段是幽灵，实现里只画最高一档、最多一行。
- **Unity 的 `UI.Text` 没有字距设置**：稿上所有 `letter-spacing` 在实现里恒为 0。标题里的间隔是**写进字符串**的空格（「字 · 斗」「续 爬」「登 塔」），不是排版属性。
- 段位行与本趟账目在稿上把数字挑出来放大加朱砂（`<b>`），实现里各是**一个** `Ui.ThemedLabel`、一种颜色 —— Unity 的 `Text` 不分段着色。
- 广告钮上的「-90m」这行文案**硬编码在 `MapView.cs:516`**（`$"-{cut / 60}m"`），没走字符串表；用的是 ASCII `-`，不是设计系统规定的 `−`（U+2212）。

## ⚠ 共用文件的问题（本卡就地绕开，根因待统一修）

`component/bundle.css` **尾部 208–255 行是一整块过期的旧稿样式**，与文件开头 74–133 行的实现版同名同特异度而排在后面，于是 **Dialog / NavTab / InkCounter / ProgressBar 四组全站取到的都是旧稿值**：

| 类 | 实际生效（旧块） | 应该是（实现） |
| --- | --- | --- |
| `.zd-ink` | 26 高胶囊 + `ink-bar` 底 + 1px 描边 + `radius-pill`、字号 12 | 没有胶囊，字号由调用点给（顶栏 11.94） |
| `.zd-bar` | 高 4px、轨道 `quiet`、填充 `rarity-gold`、圆角 `radius-bar` | 轨道恒 `paper-dim`、圆角 4.78，高与填充由调用点给 |
| `.zd-bar--band` / `--band-off` | 被旧块的 `.zd-bar > span` 压掉 → 四条层段条全画成赭金 | 当前段 `cinnabar`、其余 `#676F7A` |
| `.zd-bar--run` | 填充 `fire-glyph` | `cinnabar-dark` |
| `.zd-tab` | 44 高 / 1px 描边 / `radius-card` / 图标 20 / 名 14 + 字距 2px / 红点 7·9 | 43.96 / 0.96 / 9.08 / 17.20 / 13.86 无字距 / 红点 7.64·7.64 |

另外三处同名类只有一份，但那一份与实现对不上：`.zd-chip` 圆角写成 `9999px`（`Ui.Chip` 恒用 `Theme.Rounded(14)` → 6.69，与字号无关；本页的暂存 chip 只有 12.90 高，6.69 已经超过半高、看着就是胶囊，但 `--warn` 那类更高的 chip 会露馅）；`.zd-btn--ad` 的字号/圆角照抄了 `.zd-btn--chest`（`Ui.AdBadge` 按高度相对稿基准 63 缩放，72×46 这枚应是字号 7.17、圆角 10.99、描边 0.72、宋体）；`.zd-tab__sub` / `.zd-bar--band-off` 读一支 `--lock-gray`，而 `tokens.json` 里没有这个名字 —— `Theme.LockGray` 就是 `#676F7A`，即 `--text-faint`。

`preview.html` 里用 `.dev .zd-*` 提一级特异度把实现值拿了回来，并在注释里标了出处；**bundle.css 那一块删掉之后，那整段覆盖都可以删。**
