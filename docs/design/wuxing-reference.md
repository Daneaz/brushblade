# 五行规则规格

> v1.0 · 2026-07-05 收口(原「五行参考文档」升格为正式规格)
> 本文档是战斗属性生克的**唯一规则来源**,第 3 / 6 / 8 / 10 章与本文档保持一致。
> 历史说明:本规格源自浏览器 demo 实测(2026-06-07 wuxing-fix-earth 修正),demo 代码已随仓库重置移除,规则以本文档为准。

## 属性集

六属性 = **真五行(木、火、土、金、水)+ 心**。

- 生克圈只含五行,采用经典口诀,玩家零学习成本。
- **心系中立**:不参与生克,与所有属性互为 1.0x。心系机制(心魔)随摄心流 DLC 设计。
- **土**:真实属性(部件 / 字 / 字怪都存在),但不做完整流派——定位为跨流派「防御 / 护盾」工具字家族(见第 10 章 10.3.6)。

## 相克

口诀:木克土,土克水,水克火,火克金,金克木

| 攻方 | 克制对象 | 伤害倍率 |
|------|---------|---------|
| 木 | 土 | 1.5x |
| 土 | 水 | 1.5x |
| 水 | 火 | 1.5x |
| 火 | 金 | 1.5x |
| 金 | 木 | 1.5x |

被克方对克制者伤害 0.5x。心系不参与相克,与所有系均为 1.0x。

## 相生

口诀:木生火,火生土,土生金,金生水,水生木

**触发规则(2026-07-05 收口;2026-08-04 收紧为「他生我」):**

1. 取字卡配方的原料属性集合并**去重**。
2. 集合中存在某属性 **生本字属性**(母 → 本字)→ 该字效果 **×3**。
3. **只认「他生我」**:本字属性去生原料属性(我生他)**不算**相生,不升档、不加倍。
4. **多对不叠乘**:无论配方含几个母属性,至多 ×3。
5. 相生 ×3 与相克 ×1.5 **相乘**,理论最高 ×4.5。
6. 第 10 章字表数值均为**基础值**,生克乘数在战斗结算时套用。

例:

- 焚(火系,林+火 = 木+火)→ 木**生火** → 基础 7 AOE → 21;对金系再 ×1.5 → floor(7×3×1.5) = 31。
- 刲(金系,圭+刂 = 土+金)→ 土**生金** → 基础 15 伤 → 实战 45。
- 蒸(火系,艹+烝 = 木)→ 木**生火** → 基础 3 伤 → 实战 9。
- **反例** 灶(火系,火+土)→ 火生土 是「我生他」→ **不算相生**,×1。
- **反例** 淋(水系,氵+林 = 水+木)→ 水生木 是「我生他」→ **不算相生**,×1。
- **反例** 崟(土系,山+金 = 土+金)→ 土生金 是「我生他」→ **不算相生**,×1。

> **平衡观察项(挂第 18 章 R6)**:×3 是 demo 实测的爽感值;与相克叠算后摆幅达 4.5 倍,Playtest 阶段重点观察含相生配方的字是否碾压同阶无相生字。

## 相生对与代表字(MVP 视角)

> 「他生我」口径下,一个字要吃到 ×3,配方原料里必须含**生它的那个属性**。下表按此重新盘点(2026-08-04)。

| 母 | 子 | 代表字(已落地) | 状态 |
|----|----|----|----|
| 木 | 火 | 燊(焱+木)、焚(林+火)、蒸(艹+烝) | 已落地 3 字 |
| 火 | 土 | — | **缺口**:土系字的配方均无火部件(嶘=山+棧、崟=山+金) |
| 土 | 金 | 刲(圭+刂)→ 基础 15 伤 → 45 | 已落地 |
| 金 | 水 | 沏(氵+切)→ 基础 7 伤 → 21 | 已落地(依赖 `切` 判金,见下) |
| 水 | 木 | — | **缺口**:木系字的配方均无水部件 |

**复合部件的属性判定**:非部首的复合部件(如 `切`)递归到部首取属性,多个属性部首时**取能成相生的那个**
(`切` = 七+刀,`刀` 在部首属性表里属金 → `切` 判金,使 沏 成立)。这条规则目前只作用于 `切` 一处。
