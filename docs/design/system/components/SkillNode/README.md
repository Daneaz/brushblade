技能星域的节点：52 逻辑单位见方、圆角 20（近乎正圆），里面一枚图标 + 两字名；对应实现 `PerkView.BuildNode`。

## 画布上只分三类
| 类 | 画法 |
| --- | --- |
| `zd-node--own` 已点亮 | 枝色浅底（`--soft`）+ 2 逻辑单位枝色边；图标枝色，名 `text-main` |
| `zd-node--buy` 可解锁 | 白底 + 枝色边 + 枝色外发光（墨晕外扩 10）—— 全屏最亮的那一格 |
| 未解锁（默认） | `locked-bg` 纯灰底、不描边。墨锭不足时图标仍是枝色、名 `text-main`；前置未点 / 等级未到（`zd-node--gated`）图标与名一起压成 `text-faint` |

五种判据（已点 → 前置 → 等级 → 墨锭）在代码里仍然分开，但**差几级、差多少墨、缺哪侧前置只在详情弹窗里说**；画布要的是「能点 / 不能点 / 已经点了」这一眼的层次（2026-09-08 定）。

## 其余元素
- **跨树节点**：外圈 16 个小圆点的虚线环（离节点边 7），gated 时一起压灰；不画任何连线，前置关系在详情里说。
- **连线**：3 逻辑单位直线连同枝上一层。L2 以上按**上一层是否已点亮**上色；L1 连树根，这一段按 **L1 自己是否已点亮**上色（树根是分区标记、没有点亮态）。未点亮一律 `panel-border`。
- **中心「斗」**：直径 88 的 `ink` 圆，宣纸色宋体。**树根**：直径 64 的 `panel-inset` 圆，写树名，不可点。
- **图标**：15 枚撑起 43 个节点。五行 L1–L3 跨五系共用（L1 `perk_draw` / L2 `perk_loot` / L3 `perk_amplify`），L4 各系专属（金 `morale` · 木 `focus` · 水 `perk_wellspring` · 火 `burn` · 土 `perk_heft`）；被动、机制树一枝一枚；跨树用它放大的那个效果的图标（相济 `attack` · 融会 `crit` · 博采 `perk_draw`）。
  ⚠ L2 那枚 `perk_loot`（兜底字「获」）是**旧效果的遗留**：2026-09-13 五行 L2 已从「战利品保底 1 张该系」改成五系各不相同的机制（锋芒 / 归根 / 溢流 / 余烬 / 反震），`PerkNodeIcons` 没跟着改，五枝现在共用一枚语义错位的图标。记录现状，待代码侧修。

## 枝色
五行脉 = 该系 `<el>`；被动 元 `cinnabar` · 力 `shop-nav` · 锋 `gold` · 御 `ink-soft`；机制 博闻 `split-blue` · 广纳 `water` · 慧眼 `gold` · 一气 `jade`；跨树统一 `heart`。浅底 = `panel-paper` 往枝色走 18%（五行用 `<el>-soft`）。

## 缩放
画布 1220 见方，缩放 0.36–1.15，默认 0.7；低于 0.55 只画色块 —— 节点的图标与名、**以及三个树根上的树名**一起隐藏（连线、中心「斗」、虚线环照旧画）。切换只在跨过 0.55 那一下发生一次，不逐帧判、更不重建节点。卡片里按 2× 放大展示。
