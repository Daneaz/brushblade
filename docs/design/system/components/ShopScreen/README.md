## 代码侧已知问题（只记录，未改代码）

- **部件分支是死代码**：`GameRoot.ShopCardPool()` 只放已拥有的**非部件**字，`ShowShop()` 还会把混进部件的旧货架作废重摆。`ShopView` 里的 `def.IsComponent` 分支、`shop.slot.component_note`（「合成材料，不占卡池」）与「部件不画角标牌脚」这条规则，运行时到不了；`ShopView.cs:36` 那句「卡位池：部件 + 已拥有的字」的注释也已过时。本卡因此**不画部件摊位**。
- **开箱时长 chip 会露出浮点数**：`shop.chest.duration_chip` 收的是 `DurationSeconds / 3600f`，素纸匣渲染成「0.0833333 小时」、竹简匣「0.5 小时」。
- ~~档名压白卡对比度不足~~ **2026-09-21 已修**：档名原先用稀有度原色压 `#fff`（素纸 2.27、鎏金 2.27、朱漆 3.03:1），改成 `text-main`（17.32:1）。档位色仍由上方 84 高的宝箱立绘承担 —— 那块比 11pt 的名字显眼得多，色信息一点没丢。
- **倒计时不走字**：`RefreshCountdown()` 只在 `Rebuild()` 时算一次，玩家停在页面上时数字是死的；跨 UTC 0 点时 `EnsureShelf` 不会重跑（它只在进页时调），货架仍是昨天的而倒计时已跳回 23:xx。
- **toast 不会自己消失**：画一次后要等下一次 `Rebuild()`（即下一笔交易）才没，停在页面上它会一直挂着。
