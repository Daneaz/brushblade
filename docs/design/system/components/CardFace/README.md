卡组网格的一格：103×128 的 GlyphTile + `CardBadges` 角标 + 牌脚进度；卡组网格、开箱结果、商城字摊、详情弹窗的头共用同一套角标（`CardBadges.Apply`）。

## 角标（尺寸一律按牌高宽算比例，基准 103×128）
| 部件 | 位置 | 含义 |
| --- | --- | --- |
| `zd-bdg--lv` | 左上 | 等级 `Lv.N`，`ink` 底白字；满级 `zd-bdg--max` 换 `gold` 底 `gold-text`「MAX」 |
| `zd-rdot` | 右上 | 稀有度色点（直径 13/103 牌宽） |
| `zd-bdg--up` | 左下 | 「▲ 可升」，`jade` 底 —— 份数与墨锭都够才出现 |
| `zd-bdg--new` + `zd-halo` | 右上角 / 牌外 | 新字：朱砂小方标顶到牌角、盖住色点，牌外一圈 `gold` 墨晕 2.6s 呼吸（只改 alpha 不改尺寸，一排牌才不会跟着挤）；点开即消 |
| `zd-bdg--lock` + `zd-rdot--dim` | 左上 / 右上 | 未拥有：`text-faint` 16% 透明的圆底 + **`ink-soft`**「锁」字（2026-09-21 从 `text-faint` 压深，3.52 → 5.86:1），直径 17.25/128 牌高（比等级角标大一圈，占同一个位子）；色点按 `lerp(locked-bg, 稀有度色, 0.42)` 掺灰，留四成色相；其余角标一概不画 |

比例表（除以 103×128pt，牌一缩角标跟着缩）：角标距牌边 5/128 · 等级与可升带高 15/128 · 角标字号 8.5/128（下限 10 逻辑单位）· 稀有度色点 13/103 牌宽 · 新字角旗见方 34/103 牌宽 · 牌脚高 12/128 · 牌脚进度条高 4/128。

## 牌脚 `zd-foot`
不进牌面：牌面说「这是什么字」，牌脚说「离下一级还差多少」。
- 进度条宽 62% 牌宽、高 4/128，轨道 `paper-dim`；够升填 `jade`，不够填 `text-faint`；右侧 `份数/所需`（够升 `upgrade-text`，否则 `text-dim`）。
- 满级：整条填满（仍是 `text-faint`，不转绿），文字「满级」`gold-deep`，不再拿分母吊着人。
- 未拥有：只写「未拥有 · 宝箱产出」，`text-faint`，没有进度条。

## 所需份数怎么来的
`ceil(CopiesToUpgrade[当前级−1] × 稀有度系数)`，最少 1。基准表 `{1,2,3,5,40,80,150,300,500}`（满级 Lv.10），系数白 1.0 / 绿 0.7 / 蓝 0.4 / 紫 0.25 / 金 0.15 / 橙 0.1 / 红 0.05 —— 所以紫以上前几级一律「1 张」，卡片上那些 `0/1` 不是占位。

## 已撤掉的旧角标
「出阵」底带随出阵概念一起废止（2026-09-06，起手改为从卡池抽）；稿上的 45° 斜角旗在 uGUI 里做不出，实现是右上角一枚方标。稿上「可升徽标遇出阵带自动上移」的避让也随之取消，可升徽标恒在左下角。
