《字·斗》是一款汉字拆合卡牌肉鸽，锁横屏的移动端游戏。视觉地基只有一句话：**字即画** —— 游戏内容本身就是文字，美术的主角是一个个写得漂亮的汉字，不是插画。世界是褪色的水墨宣纸，色彩只属于字与力量：玩家每「正」一个字，颜色就回来一分。

## 设计原则

- **纸与墨为地，色只给字。** 界面底一律 `paper` / `panel-paper`，文字 `text-main`；五行色与稀有度色只出现在字牌、属性元件、状态与特效上。
- **推进 = 石青。** 一屏的主推进钮（续爬 / 登塔、挂起离塔、深入、结束回合、收下、领取赏钱、确认类主钮）用 `cta` 实底白字（`Theme.Cta`）。一屏最多一颗主钮。花墨锭的主钮（解锁技能、确认升级、领取里程碑）语义不同，仍用 `gold` + `gold-text`；中性钮仍用 `locked-bg` / `panel-inset` / `ink-soft`。（2026-10-04 拍板，比稿 `demos/cta-color/推进色比稿.html`）
- **朱砂 = 危险 / 威胁。** `cinnabar` 只表示危险与威胁：DoT、威胁类状态与能力 chip、红点、伤害飘字、血条、不可逆后果的正文标红。不再做推进钮的底。
- **不可逆钮 = 朱砂描边。** 不可逆操作（弃塔、确认退出 / 认输等）用 `cinnabar` 描边 + `cinnabar-dark` 字、宣纸底（`Ui.DangerButton`；`Ui.Modal` 的按钮元组传 `Ui.DangerOutline`），不做实底、不抢主钮——最醒目的那颗留给默认推进项，避免误触。退出塔的弹窗里石青给「挂起离塔」，「弃塔」走描边钮；不可逆的份量还由正文标红与 `warn-bg` 告警条承担，见下一条。
- **凡是不可逆的，都要在按下去之前说清楚。** 不可逆后果在弹窗正文里标红（`fire-glyph` 加粗），或做成 `warn-bg` 告警条；取舍写在按钮下面，不藏在小字里。
- **只说做得到的事。** 屏上不写玩家点不到的功能；红点亮着就必须点进去真有事可做。
- **禁止霓虹、赛博、氪金感视觉**：没有渐变按钮、没有发光描边的商店卡、没有闪烁价格。

## 文案

- 语气是说书人式的短句中文，平实、不喊口号：「汉字不是一成不变的符号——拆开，才看得清它由什么部件构成。」「部件不是废料，是备用零件——凑对了就能拼回一个字。」
- 称呼玩家为「你」；玩家在世界里的身份是「执笔人」。
- 两到四字的标题、按钮在字间加空格作为装饰：「离 塔」「登 塔 结 算」「字 · 斗」。操作钮不加（「挂起离塔」「知道了」）。
- 引用字、部件、选项用「」：「爆」需要 1 AP。拆出的部件用『』：『朿』『刂』。
- 结构化信息用 ` · ` 分隔：「养元 · 起始生命上限」「重复卡 2/4 · 墨锭 300/300」。区间用 `→`：「新纪录 · 12 → 15 层」。
- 墨锭数额（余额、增量、收入、价格）一律千分位：「2,480」「+1,200」「售价 1,500 墨锭」，代码统一走 `Ui.InkText`（`N0` + `InvariantCulture`）。其他数字（伤害、生命、层数、张数）不加。
- 不用 emoji。符号只用字体里确实有的：`· × — → − ≥ ±`；关闭钮是 `×`（U+00D7），不是 `✕`（字体里没有）。
- 稀有度叫**白绿蓝紫金橙红**；宝箱按材质叫「xx 匣」（素纸匣、竹简匣、青瓷匣、紫檀匣、鎏金匣、朱漆匣、赤霄匣）。单字说的是卡，带「匣」说的是箱。
- 所有玩家可见文案走字符串表，不硬编码；字形、拼音、释义是配置数据。新增汉字必须重跑字体子集，否则真机显示豆腐块。

## 颜色

- **纸面阶梯**：`paper`（全屏底）→ `panel-paper`（面板、弹窗卡，配 1pt `panel-border`）→ `card-face`（字牌面）。面板内凹槽条用 `panel-inset`，进度条底用 `paper-dim`，两者不要互换。浅卡压浅底必须带描边。
- **文字**：`text-main` 正文与标题；`text-dim` 说明（paper 上 5.3:1），也是有色淡底（稀有度底、页签底、墨锭条）上小字的最浅一档；`text-faint` 图注与拼音，只用在 `paper` / `panel-paper` / `card-face` 上（4.5:1）；`text-mute` 是**装饰档**（3:1），只给空格位提示、水印这类删掉也不丢信息的字。
- **推进与危险**：`cta` 石青是主推进钮底（白字 6.78:1）；`cinnabar` 朱砂只给危险 / 威胁，`cinnabar-dark` 做描边危险钮的字与深朱砂文字。
- **中性按钮与信息**：`ink-soft`（白字 8.4:1）；深墨块用 `ink`。
- **五行**：每系四支 —— `<el>` 色块、`<el>-soft` 淡底、`<el>-fg` 淡底上的前景、`<el>-glyph` 字形。**字形必须用 `-glyph`**：金系原色 `metal` 对白只有 2.5:1，`-glyph` 在白、宣纸、淡底上均 ≥4.5:1。金偏冷灰、土偏红褐是刻意的，好让「桂」这类组合字左右两半分得开。
- **生克**：倍率以 `docs/design/wuxing-reference.md` 为准；稿上不画相生（已取消）。
- **稀有度**：`rarity-<白绿蓝紫金橙红>` 做 2pt 牌框与色点，`-soft` 做小字牌底。宝箱七档与卡牌七档**同一套色**。
- **层段**：六段按序 `band-zilin`（字林）/ `band-zhusha`（朱砂）/ `band-wenshan`（文山）/ `band-jinshi`（金石）/ `band-mohai`（墨海）/ `band-ciyuan`（词渊）以 9%–22% 混入 `paper` 作该段背景（每 5 层加深一档），并以 10% 透明度作面板巨字水印。
- **遮罩**：模态 `scrim`（55%）；局内浮层 `scrim-soft`（42%，要看得见底下的战场）；胜负横幅 `scrim-paper`（纸色，不压暗战场）；新手引导弹层 38%。

## 对比度

本系统所有文字配对达到 WCAG AA：正文 4.5:1，24px 以上或 19px 以上粗体 3:1。`tokens.json` 里的值已按此调深（`Theme.cs` 同值）。

规则：
- 主推进钮 `cta` 白字 6.78:1；危险描边钮的 `cinnabar-dark` 字压 `panel-paper` 7.6:1（压 `paper` 7.2:1）。
- 属性色块上压白字时用 `<el>-glyph` 作底，不用 `<el>`（金系原色白字只有 2.5:1）。
- 血条上的 6pt 数值是白字压在血条与轨道之上，靠 1–2px 深色描边保证可读，不单靠底色。
- 非激活态（未拥有、前置未点、等级未到、已阵亡、禁用钮）不在对比度要求之内，刻意压浅。
- **余量只剩一线的配对**（都已达标，但任何一边再动一档就会掉下去，改色前先回来看这行）：`earth` 白字 4.50、`jade` 白字 4.51、`shop-nav` 页签 4.51、`gold-deep` 压 `gold-soft` 4.52、`done-green` 白字 4.57。
- 面板描边 `panel-border` 对宣纸只有 1.3:1：面板不是可操作控件，按「以描边立物」的品牌处理保留；可点的控件靠底色与文字区分，不靠描边。

## 字体

- 两支字体：**思源宋体**（`serif`，Noto Serif SC）给字形、标题、页签；**思源黑体**（`sans`，Noto Sans SC）给按钮、正文、数值、chip、角标、战斗飘字（粗体）。
- 按钮一律黑体、不加粗（`Ui.RoundButton` / `PillButton` 走 `BodyFont`）；唯一例外是广告徽章 `Ui.AdBadge`，宋体。字间那一格靠文案里的空格（「续 爬」），Unity `Text` 没有字距。
- 打包的是子集字体（宋体 700、黑体 500，各约 1,225 字，只含游戏里实际出现的字）。网页里缺字会落到 Songti SC / PingFang SC；游戏里缺字就是豆腐块 —— 新文案上线前必须重跑子集。
- 字号阶梯（稿面 pt）：字牌字形 `card-glyph` 46 / `tile-glyph` 28；标题 `title` 21、`screen-title` 19；主钮 `cta` 18、`pill` 15、`button` 11；页签 `tab` 14；弹窗标题 `dialog-title` 13；正文 `body` 11、`dialog-body` 10；`chip` 10；`caption` 9；角标 `badge` 8.5；拼音 `pinyin` 8。
- 数字一律 `font-variant-numeric: tabular-nums`。

## 布局与尺寸

- 设备基准 iPhone 16 Pro Max 横屏 **932 × 430pt**，锁横屏。纵向永远是紧的那一维，不要按竖屏思路推断。
- 安全区左右 `safe-x`（59）、底部 `safe-bottom`（21）；所有可点元素都在框内。
- 本系统的数值单位是稿面 pt；Unity 侧 `CanvasScaler` 为 1600×900 按高匹配，**1pt = 2.093 逻辑单位**，改一边同步另一边。
- 骨架：顶栏 `topbar-height`（38）/ 内容区 / 底部导航 `nav-height`（44）。主界面三栏：角色 187 · 书塔（弹性）· 宝箱 232，栏间 `space-10`；三栏一律 `border-box`，宽度含内边距与描边。
- 触控目标至少 `tap-min`（44），视觉更矮的钮用透明扩边补足。
- 实现侧 Unity `Text` 从不折行：稿与网页再现一律 `white-space: nowrap`，放不下就让它顶出来，一眼能发现。

## 形状、阴影与动效

- 圆角按物件分档：进度条 `radius-bar` · 迷你牌 `radius-mini` · 小字牌 `radius-tile` · 宝箱格 `radius-box` · 大字牌/页签 `radius-card` · 面板 `radius-panel` · 宣纸卡 `radius-sheet`；所有按钮、chip 用 `radius-pill`。
- 以描边立物，阴影极轻：大字牌 `shadow-card`，朱砂主钮 `shadow-cta` / `shadow-cta-lg`，选中 `ring-selected`，新字 `halo-new`。
- 字牌始终按 **0.8 竖版比例**定尺（框素材 192×240），富余宽度让给间距，不拉伸牌框。
- 不做骨骼与帧动画，打击感全靠程序：墨迹飞溅、墨晕、字形辉光、震屏、字「一笔一划写出来」。立绘只做轻微浮动、受击抖动、缩放。
- 常驻动效只有两种呼吸：新字赭金光 2.6s；宝箱「已就绪」光晕 + 箱身起伏 2.5pt + 盖缝透光 1.6s，三段同相。拖拽期间不重绘。

## 视觉母题

**印章**（按钮、确认、法宝边框）、**竹简**（字库陈列）、**卷轴**（菜单与地图展开）；墨迹「飞白」作特效肌理。字怪是墨色凝成的妖魔化汉字 —— 半是字形半是凶相，同一个 prompt 家族。

## 图标

- 状态、技能、导航图标是一套自绘 SVG（44 枚：30 枚战斗状态、4 枚底部导航 `icon_nav_*`、9 枚技能树 `icon_perk_*`，外加攻击模式等）：64 方画布、**纯白单色** `#fff`、粗描边圆头（stroke 5–6）。它们永远压在有色 chip 上（`cinnabar` / `jade-deep` / `shield-blue` / `earth` / `ink-soft`），或在导航页签上被着成 `tab-*-fg`；放在浅底上看不见，这是预期的。
- 图标是管线产物：手写 SVG（`tools/icons/svg/`）→ PNG（`tools/icons/build_icons.py`），不要手改 SVG 或手画 PNG。每枚都有一个兜底汉字（`Icons.cs` 的 `Glyphs`：灼烧=炎、冻结=冰、护盾=盾、治疗=愈…），PNG 取不到时回落成汉字徽章。新增一枚要同改 `ICONS`、`test_icons.EXPECTED`、`Glyphs` 三处。
- 不用 emoji，不用第三方图标库。

## 宝箱

- 七档七种材质、七种轮廓：素纸匣 `paper` → 竹简匣 `bamboo` → 青瓷匣 `celadon` → 紫檀匣 `rosewood` → 鎏金匣 `gilded` → 朱漆匣 `vermilion` → 赤霄匣 `crimson`。越往上五金越多、轮廓越「抬头」，赤霄那只关不严、缝里透光。
- 每档两层：`*_body`（箱身，墨线 `#111622` 描边 + 该档稀有度色平涂）与 `*_seam`（盖缝的光）。箱色 = 同序稀有度色（`rarity-*`）。
- 三态只改叠加层：未开始（满不透明）/ 计时中（箱身 `opacity-timing` + `chest_fx_timing` 沙漏角标）/ 已就绪（`chest_fx_ready` 金光晕 + 盖缝透光 + 箱身 2.5pt 起伏，1.6s 同相呼吸）。
- 40pt 缩略图下认的是外形与那一块平涂色。源图 `tools/design/chests/svg/`；改色要同步 `tools/design/build_chests.py` 的 TIERS 并重出 PNG。

## 字牌素材

- `card_<rarity>_frame.png`：七档稀有度牌框，192×240（0.8 竖版比例）。牌一律按这个比例定尺，不拉伸 —— 拉了纹样就变形。
- `card_<rarity>_glow.png`：蓝档以上的材质光效层（白、绿两档没有）。迷你牌不挂光效。
- `elem_<element>.png`：五行属性元件，128×128，叠在牌面上标属性；50pt 以下的迷你牌不画它（会糊成一团）。

## 字怪形象

- 分层水墨立绘，512×512 方、透明底，放在 `paper` 或层段背景上。拆 `body` / `face` / `wisp` 三层按此序叠放（`MobAssets.Layers`），战斗里另叠 `state` 层；属性气场并在 `wisp` 里，没有独立 aura 层。示例见 `drafts/scenes/MobLayers.dc.html` 的「窑变」三层。
- 构图硬约束：`wisp` 不与 `body` 相接（它要能独立飘出去），`face` 不画进 `body`（body 对应位置只留一个浅墨窝）；轮廓要经得起 ±4.5% 的呼吸缩放。
- 立绘是管线产物：手写 SVG（`tools/design/mobs/svg/`）→ `tools/design/rasterize_mobs.py` → `Brushblade/Assets/_Project/Presentation/Mobs/Resources/`，SVG / PNG / `.meta` 一一对账，**PNG 不能手写**。中文 id ↔ 拼音 slug 的对照表有两份且必须一致：`MobAssets.MinionSlugs` / `MobAssets.BossStages` 与 `rasterize_mobs.py` 的 `MINION_SLUGS` / `BOSS_STAGES`。
- 字形由 Noto Serif SC 供给、**一笔不改**；墨的浓淡、毛边与飞白全部由滤镜生成 —— 先一眼认出是哪个字，再看出它是活物。
- 属性色只落在眼睛与要害，占画面不超过两成；其余是墨。
- 每只的造型讲一件机制：灯花钩尖爆出的火星就是落在你身上的那 1 层灼烧；悬针只有一只眼，因为它只认一个目标；护甲不画壳，靠材质（干笔、釉面开片、龟裂墨壳）说服人。
- 按实机尺寸验收：图鉴格 80pt（立绘占 82%）必须认得出是哪个字；48pt 压力测试可以糊，但不能糊到分不清彼此。

## 技能树

- 树的结构与版面（环形星域、节点数、扇区）是现状，见 `current/PerksScreen`。
- 枝色复用既有语义色，不新造：五行脉 = 该系色；被动树 元 `cinnabar`、力 `shop-nav`、锋 `gold`、御 `ink-soft`；机制树 博闻 `split-blue`、广纳 `water`、慧眼 `gold`、调息 `jade`；跨树节点统一 `heart`（同类同色，靠虚线外环与图标区分）。
- 画布上的节点只分三类：已点亮 / 可解锁 / 未解锁；差几级、差多少墨只在详情弹窗里说。可解锁态必须是全屏最亮的那一格。见 SkillNode。
