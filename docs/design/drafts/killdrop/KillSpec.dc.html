③ 规则

  • 从哪来就从哪飞:击杀得字(斩获、折桂)一律从阵亡的敌人格飞来;回合开始掉字照旧从字库行右侧滑入(现状不变)。玩家一眼分得清「这张是杀出来的」还是「回合给的」。
  • 敌人回合的击杀也走这条(木灵、灼、流血杀死):不再并进 SplitOutDrawn 的右侧滑入。同一拍里先播击杀得字,再播回合开始掉字。
  • 折桂并进同一条路径:原来只有名签 + 光晕、牌凭空出现,现在同样冒字 → 飞入。
  • 群攻连杀:每张 token 在自己那只阵亡的时刻冒出(逐目标 0.05 s 的节奏自然错开),停到批尾一起起飞,按落位顺序错开 0.12 s。
  • 本回合已掉满 2 张:不掉、不演、不提示(上限是规则,天天碰到,提示会变成噪音)。
  • 字库满:不冒 token;阵亡格飘划线的「斩获 字库满」(沿用现状「被挡下」样式:α .6 + 删除线),批尾字库计数「字库 10/10」cinnabar-dark 闪一下(0.45 s,scale 1.25)。每回合只提示一次。
  • 当拍胜利:结算不画字库 → token 冒出、停 0.25 s 后原地 0.3 s 淡出,不飞(字照样进字库)。
  • 加速:四拍与名签全部 ÷ 倍率(×2 / ×3)。
  • 出画:后排 token 停点夹在战场顶 + 半个 token 以下;落点 = 字库牌实际位置(按张数同比缩,16:9 满 10 张 ≈ 37pt 宽),两档屏宽都在中区内,不越过拆合台。
