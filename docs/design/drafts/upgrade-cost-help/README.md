# 收集界面 · 升级成本说明弹窗

需求:收集界面(`current/CollectionScreen`,`CollectionView.cs`)顶栏加一颗「?」,点开说明弹窗,列两张 7 档 × 9 次升级的表 —— 升级所需重复卡、升级所需墨锭。新数值本批同时落进 Core。

## 画板
- `Tabs.dc.html`:**方案 A(推荐)**,页签切换。底部可切「入口 / 弹窗」「重复卡 / 墨锭」「基准机 / 16:9」;点「?」开、点遮罩或「知道了」关。
- `Stacked.dc.html`:方案 B,两表上下并列。
- `Spec.dc.html`:入口实尺寸与 × 3、两档屏宽验算表、规则对账结果。
- 数据 `uhc.js`:两张表原样抄录,并按规则重算逐格对账(不一致会在画板上标红;当前 126 格全部一致)。

## 入口「?」
- 照抄主界面宝箱栏栏头那颗(`MapView`:`Ui.RoundButton`,直径 40 → 19.11pt、`panel-inset` 底、`text-dim` 黑体 20 → 9.56pt),**不新造图标**,不走 icons 管线;
  「?」是 ASCII,子集字体已有(`map.chest.help_button` 同字)。
- 位置:顶栏标题「收集」右侧,间距 = 顶栏间距 21(放标题边上 = 「这一页怎么玩」;墨锭计数旁留给账目)。
- 命中区透明扩到 `tap-min` 44pt(同战斗「?」引导钮的 Hit 子节点做法)。
- 顶栏首选宽 ≤ 840 + 40 + 21 = 901,16:9 净宽 1354 仍余约 450。

## 方案 A(推荐)· 页签切换
**外壳**:`Ui.Sheet` 984 × 620(470 × 296pt),屏幕正中,`scrim` 55%,`dismissable: true`(纯说明,点遮罩即关)。外壳尺寸与屏宽无关。

自上而下(行距 14):
| 段 | 内容 | 尺寸(逻辑) |
| --- | --- | --- |
| 头行 | 标题「升 级 所 需」左;右端页签「重复卡」「墨锭」二选一,默认「重复卡」 | 行高 46;标题宋体 34 `text-main`(同升级确认弹窗标题);页签 = 筛选栏拥有态 `Toggle` 同款:高 46、左右内距 19、字 20,选中 `ink-soft` 白字、未选 `panel-inset` / `text-dim` |
| 说明 | 「升一级要同时交够重复卡与墨锭;下表是每一级各要多少。」 | 19 `text-dim`,行高 27 |
| 表 | 表头 + 7 档行 | 见下 |
| 规则注 | 当前页签那张表的规律,一行 | 17 `text-faint`,行高 24 |
| 钮 | 「知道了」居中 | 180 × 50、`cta` 白字 20(同宝箱说明的「知道了」) |

**表**(两页同一套列宽,切页签时表格不跳):
- 列:行头 72 + 9 次升级各 84 + 「升满累计」104 = **932**(弹窗内宽 984 − 48 − 3 = 933)。
- 表头行高 36、字 17 `text-faint`:角格「升级」,列头「1→2」…「9→10」,末列「升满累计」(`text-dim`)。表头下 2 单位 `panel-border` 线。
- 行高 42、行间 1 单位 `panel-border` 细线;**行头** = 稀有度色点(12 圆点,`rarity-*`,同右栏「卡池概览」的色点)+ 档名宋体 22 `text-main`。
  不把档名本身染稀有度色:白档 `rarity-white` 压 `panel-paper` 只有约 2.6:1,不达 AA;色点是装饰,名字照常可读。
- 数字黑体 20 `text-main`、`tabular-nums`、右对齐(右内距 10)—— 右对齐让位数一眼可比。
- 「升满累计」列铺 `panel-inset` 底、数字加粗:Lv1 → Lv10 一共要多少,玩家最常问的就是这一格。
- 数字格式:**墨锭千分位**(`Ui.InkText`,「24,000」「47,380」);**重复卡不加**(规范「文案」:张数不加千分位,「6561」「9841」)。
- 规则注:重复卡页「每升一级,张数约为上一级的:白 ×3 · 绿 蓝 ×2.5 · 紫 金 ×2 · 橙 红 ×1.5」;墨锭页「各档按白档 × 系数:绿 ×1.5 · 蓝 ×2 · 紫 ×2.5 · 金 ×3 · 橙 ×3.5 · 红 ×4」。
  用「约」是因为有取整;不写取整细节(表才是准数)。这一行可删,删了弹窗高减 38。
- **一格数字都不在 Presentation 手抄**:表与累计全从 Core 的公开升级成本表读(同宝箱说明「全部从 `ChestRules` 的公开表读」)。

**为什么推荐 A**:一次只答一个问题(「还差几张」/「要多少墨」),行高 42、数字 20 号读得舒服;竖向余 280,以后加一行说明或一列「当前持有」都有余量。B 把两张表硬塞进 900 高,字和行都要压一档,上下只余 35。

## 方案 B · 两表上下并列

## 待确认
- **用词「重复卡」**:需求写「同名卡」,游戏里同一个东西现叫「重复卡」(`collection.side.cost.copies`、升级条件不足弹窗「重复卡 {copies}/{needed}」)。稿按「重复卡」出,与全站一致;要改成「同名卡」需全站一起改。
- **重复卡的取整口径**:需求写「逐级向上取整」,但抄录值符合的是 **⌈倍率^(n−1)⌉**(先连乘、最后取整):绿档 2.5² = 6.25 → **7**;若真「逐级」(上一级取整后的 3 × 2.5 = 7.5 → 8)会得 1,3,8,20,50,125,313,783,1958。白、紫金不受影响,**绿蓝、橙红两组差了**。稿上用的是抄录值;Core 落数时请按抄录值对齐,并把需求里的规则描述改成「连乘后向上取整」。
- 墨锭表与「⌊白档 × 系数⌋」逐格一致。
