# 字卡详情 · 技能说明区改版(2026-10-15 出稿,`待审`)

需求来自 session `card-ability-system-redesign`(用户反馈五条)。改的是 `traits/` 的 CardSheet / CardSheetBattle / Glossary
三块已实现稿里的「技能说明区」,外壳(头、等级条、右栏、脚)不动。画板:`SheetTall`、`SheetBattle`(可交互)、`Spec`(规格)。
本地看:`python3 -m http.server` 起在 `docs/design/`,开 `_preview/canvas-abilitytext.html`。稿内数值取 2026-10-15 的 `chars.json`,只作示意。

## 要点

1. **取色(方案 A)**:正文 `text-quiet`(12.0:1),词条 `<el>-fg` 加粗(≥7.0),数字 `text-main` 加粗;
   spent 全行 `text-dim`;off 不变(正面 `text-faint`、背面 `text-dim` 78%)。不新增 token,只扩两条 token 的用途。
   B 案(词条只加粗)与现状并列在 `Spec` ② 与画板「配色」开关里。
2. **两面 = 一张网格的两列**:每一级一行,同级并排、行高取较高者;Lv1 / 3 / 4 / 5 / 6 / 8 至多 6 行。
   Lv1 进面:攻击面写本体效果,五行面写本体效果(木系 = 本命)。两面完全相同的级才进底部「两面」条。一面缺某级画空槽。
3. **本命行**:Lv 标 + 本命 chip(朱砂,同战场)+ 本命名(荆棘)+「本命 · 被动」+ 按当前等级写的效果句;左缘 2pt 朱砂。
   五行面数值格里那枚只有图标的「本命」格删掉。
4. **名 + 图标**:每行行头在 Lv 标与名之间放一枚图标 chip(= 战场 chip 的方形缩小版,同图标同底色);无图标不画。
   词条气泡每条也带同一枚 chip。点击粒度不变(整行 / 整格)。
5. **文案**:`term.spirit.desc` =「木系召唤的单位」;召唤物一律叫「木灵」。改后重跑字体子集。

## 两档宽

一面内字宽 基准 246.8pt / 16:9 190.2pt;最长行头约 177pt,两档都放得下;数值格 3 格时 16:9 每格约 65pt。纵向超出走现有 ScrollList。

## 待确认(见 `Spec` ⑨)

- Q2 攻击面也给 Lv1 一行(与数值格略重复)。
- Q3 多条本命(林:成林 + 速度)时,行头图标取本命名对应那条,与战场 chip 的优先级(速度)不一致。
