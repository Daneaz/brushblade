# 字卡详情 · 技能说明区改版(2026-10-15 出稿;同日 r2 / r3 按用户拍板修订,`待审`)

需求来自 session `card-ability-system-redesign`。改的是 `traits/` 的 CardSheet / CardSheetBattle / Glossary 三块已实现稿里的
「技能说明区」,外壳(头、等级条、右栏、脚)不动。画板:`SheetTall`、`SheetBattle`(可交互,样例 荆 林 炎 剑 冰 塔)、`Spec`(规格)。
本地看:在 `docs/design/` 下 `python3 -m http.server`,开 `_preview/canvas-abilitytext.html`。数值只作示意。

## 定稿要点

1. **取色 = A 案(已拍板)**:正文 `text-quiet`(12.0:1),词条 `<el>-fg` 加粗(≥7.0),数字 `text-main` 加粗;
   spent 全行 `text-dim`;off 不变。不新增 token,`text-quiet`、`<el>-fg` 的 usage 各补一句。
2. **全平铺**:两面是同一张网格的两列,每一级(Lv1 / 3 / 4 / 5 / 6 / 8)两面各一行,同级并排、行高取大;
   两面效果相同也各写一遍。「两面」条取消(SharedStrip / CompactRow 删)。现数据缺的级画「待补」斜纹占位。
3. **数值格(每面第一行)**:攻击面只列「攻击」;五行面按系 ——
   金 反击 · 格挡次数 · 战意|水 治疗(+回合,仅「涓」)|火 慑 · 回合 · 灼|木 木灵生命 · 木灵攻击|土 护盾 · 护甲 · 回合。
   数值格不再重复 Lv1 特性。
4. **各系 Lv1**:攻击面 火 灼 / 水 冻结或减速 / 木 种 / 金 战意 / 土 破甲;
   五行面 火 慑(原减攻)/ 水 润泽(涓 多回合少量 · 涌 单回合大量 · 苏 复活)/ 木 本命 / 金 格挡(按次数)/ 土 护甲。
5. **本命行**:Lv1 + 本命 chip(朱砂)+ 本命名 +「本命 · 被动」+ 当前等级的效果句;左缘 2pt 朱砂。林本命只留「成林」,
   速度改为五行面 Lv5 被动(替换原新芽)。
6. **名 + 图标**:行头 Lv 标与名之间一枚图标 chip(= 战场 chip,同图标同底色);词条气泡每条同样带 chip。点击粒度不变。
7. **文案**:`term.spirit.desc` =「木系召唤的单位」;减攻 → 慑;新增 涓 / 涌 / 苏,润泽改为总称。改字符串表后重跑字体子集。
