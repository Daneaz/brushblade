## 1. 配方转盘
**外壳**:同升级弹窗 `Ui.Sheet` 1256 × 745(600 × 356pt),屏幕正中、scrim 55%、点遮罩不关。16:9 无刘海净宽 1354 ≥ 1256、基准机 ≈ 1951,两档放得下,内部排版与屏宽无关。
抬头「配 方 转 盘」(KickerRow,`cta`)+ 副标「第 N 层 · 精英 / Boss 战后 · 紫 ×4 + 金 ×1」。左转盘、右说明列(落定后换结果卡)。

**概率怎么画 —— 扇区角度 = 概率**:低档 4 格各 81°、高档 1 格 36°。理由:面积就是概率,玩家看到的就是真的,不会被「五格等宽 = 各 20%」误导;
窄窄一条金边扇区在转动时一次次从指针下掠过、最后才停,本身就是期待感。高档格另加三道识别:`gold` 3pt 描边、外缘标「稀有 10%」(`gold-deep` 粗)、右列对应行 `gold-soft` 底。
每格外缘写各自概率(低档「22.5%」`text-faint`)。

**转盘**:直径 208 → 435 逻辑(约 208pt),外圈 3pt `ink` 环;扇区底 = 该档稀有度淡底(`rarity-*-soft`),目标字 = 字形色宋体粗 22pt(高档格 18pt,扇区窄),径向朝外;
指针在正上方(`ink` 倒三角 + `gold` 小圆);轮毂 = 「转」钮(`cta` 实底白字宋体,48pt 圆,命中区外扩到 56)。

**右列(转前)**:5 行图例,每行 = 迷你字牌(稀有度牌框)+ 字 + 「紫 · 木」+ 配方「木 + 秋」(不写概率,概率只在转盘扇区上);高档行 `gold-soft` 底。底下一句说明(开 Wrap):
「转出的那张配方记入本局,拆合台从此能合;合出的字为 [疏] 生疏:效果 ×70%,按 Lv1 计。」—— 转之前就把代价说清。

**交互与时长**
| 拍 | 时长 | 说明 |
| --- | --- | --- |
| 点「转」 | — | 结果先由 Core 定好(独立随机流),动画只负责落到那一格;轮毂变灰「…」,不可再点 |
| 转动 | 3.6s | 顺时针 5 圈多,`cubic-bezier(.12,.62,.1,1)`:起步快、长尾慢停;落点在目标扇区中段 ±30% 抖动,不压线 |
| 落定 | 0.7s | 中奖扇区 `cta` 3pt 描边 + 提亮,其余扇区与右列压灰;轮毂显示「中」 |
| 结果卡 | 0.25s 滑入 | 右列换成结果卡:大字牌(稀有度牌框 + 拼音)· 字 + 「金 · 水 · 稀有格」· 配方「氵 + 木 → 沐」(部件用部件池方块样式)· `jade` 勾「已记入本局配方」· 生疏一句 ·「继续 · 选字」`cta` |

不加跳过钮:3.6s 一次、只在 Boss / 精英层出,不长;结果卡出来前点遮罩无效,避免误关。

## 2. 「生疏」手牌标记
- **签**:字牌左上角一枚「疏」方印,`ink-soft` 实底白字宋体粗,见方 = 牌宽 × 0.27(战斗字库牌 96 → 26 逻辑 / 12.4pt;牌按张数缩时同比缩,最小 20),圆角 5,外描 1.5 `panel-paper`;
  向外骑出 4 逻辑。左上角在战斗字牌上是空的(面印在底部正中;CardBadges 只用在卡组 / 开箱,生疏不会出现在那里),不冲突。
- AP 不够整牌去饱和时,签不去色:它说的是「这张弱」,不是「用不了」。选中描边、新到手光晕照旧。
- 选色:`ink-soft` = 规范里的「中性信息」;不用灰(读成禁用)、朱砂(读成危险)、金(增益)。白 / ink-soft 8.4:1。
- **详情**(长按 / 拆合台选中):头行 Lv 写「Lv1(局外 LvN 压浅)」;其下一条 `panel-inset` 底行「[疏] **生疏**:效果 ×70%,按 Lv1 计 · 本局由配方转盘得来」;技能数值按 ×70%、Lv1 显示。
- **拆合台「可合成」行**:合出来就是生疏字的配方,出字后挂同一枚小签(20 → 9.6pt),合之前就知道。
