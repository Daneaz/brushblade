「生疏」手牌标记

生疏字 = 由配方转盘得来、在本局合出的字:效果 ×70%,按 Lv1 计。只在局内出现(卡组 / 开箱的 CardBadges 用不到它)。
标记 = 左上角一枚「疏」方印(浓墨 ink-soft 实底白字):左上角在战斗字牌上是空的(面印在底部正中,新到手光晕绕整张牌,AP 不够时整牌去饱和但「疏」印不跟着灰)。

⑤ 规格

  • 签:见方 = 牌宽 × 0.27(战斗字库牌 96 宽 → 26 逻辑 / 12.4pt;牌按张数缩时同比缩,最小不低于 20 / 9.6pt);圆角 5;ink-soft 实底、白字宋体粗,字号 = 签宽 × 0.62;外描 1.5 panel-paper 细边让它从牌框上分出来;对比度白 / ink-soft 8.4:1。
  • 位置:锚牌的左上角,向外骑出 4 逻辑(2pt);层级在字之上、选中描边之下;AP 不够去饱和时签不去色(它说的是「这张弱」,不是「用不了」)。
  • 选色理由:ink-soft 在规范里就是「中性信息」;不用灰(会读成禁用)、不用朱砂(会读成危险 / 负面状态)、不用金(赭金是增益)。
  • 详情行:panel-inset 底条,签 + 「生疏」粗 + 说明;Lv 行写「Lv1(局外 LvN 压浅)」。新文案:char.shu.badge「疏」、char.shu.line「生疏:效果 ×70%,按 Lv1 计」、char.shu.source「本局由配方转盘得来」(重跑字体子集)。
