  4. StatusText.Of:削甲那条返回 Info("armorshred", …)
  5. BattleView 敌人 chip 列表:破甲那枚之后紧跟削甲,BattleChipColor 落 _ => InkSoft(与破甲同组墨蓝),白图标、不带数字;召唤物 AddSummonStatusChips 的 Flag 同口径
  6. CharInfo.EffectsText / EnemyInfo / PlayerInfo / UnitDetail:削甲另起一行,点数在详情弹窗里写(「削甲 12」)

⑤ chip 宽(逻辑单位,Ui.ChipWidth:半角 0.55 × 字号、带图标 + 18 + 3)

形态算式宽16:9 前排 153 一行能放
只图标(推荐)10 + 1828攻 47.5 + 甲 47.5 + 1 枚;第二、三行各 4 枚
带点数「12」10 + 18 + 3 + 16.547.5与「甲 18」同宽同色,并排像两枚护甲,易误读
带点数「−12」+ U+2212 全角 1562.5更宽,且挤掉别的减益
只图标的理由:2026-09-02 拍板「数字只留给跟随回合消亡的 DoT / HoT」;削甲点数在挂着期间恒定,而头行「甲」chip 已经显示扣完之后的值,再标一次点数是重复信息。spec §3 写的「过渡期同一枚图标 + 点数」在新图标落地后撤掉。
