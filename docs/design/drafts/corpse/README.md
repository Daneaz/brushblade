# 木灵尸体标识

需求来自 session `card-ability-system-redesign`(2026-10-18)。用户反馈:「不知道复活的是什么」—— 尸体格平时不画,
选目标 / 拖放 / 召唤选位时只有一块 LockedBg 灰底 + 灰字形,看不出是哪只木灵、复活后回来什么、召唤到那格会顶掉谁。

## 画板
- `Corpse.dc.html`:七态 × 两档屏宽(召唤格按已落地的 battlegrid 尺寸),可切「字库有无复活字」。
- `CorpseSpec.dc.html`:尸体格样式与常显规则、复活签与血量预演、召唤覆盖提示、两档屏宽验算。

## 方案一句话
尸体格与活木灵同构(立绘 + 头行 + 攻 / 本命 chip + 空血条),立绘与 chip 去色、属性徽章保留原色、头行加「阵亡」;
字库有复活字时平时常显淡态,否则不画。复活态血条斜纹预演复活血量,预估签「复活 林 · 生命 75 · 盾反」;
召唤选位时尸体格写「召唤到这里会覆盖它」,字库有复活字时改朱砂「覆盖后无法复活」。

## 文件
`corpse.js` 几何与各态模型;`corpse.css` 样式(battlegrid grid.css 副本);`data.js` 图标(traits-data.js 副本);`support.js` → `../dc-runtime.js`。

## 待核
- 阵亡时身上的状态是否随死亡清空(`ReviveAt` 只清护盾与行动条);若不清,复活签 / 详情要写「带回状态」。
