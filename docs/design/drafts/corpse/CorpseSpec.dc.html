木灵尸体标识 · 规格

① 尸体格长什么样

  • 结构与活木灵同构(立绘在左、信息列在右),玩家一眼认得「这格是林」: 立绘块 locked-bg + 字形 text-faint(同现状);头行 = 字名(text-dim)+ 属性徽章保留原色(身份,嫁接换过属性就显示换后的)+「阵亡」text-faint 13 号。
  • chip 行:攻 + 本命,一律压成 locked-bg 底 text-dim 图标 —— 本命图标形状不变,认得出是盾反 / 附灼。
  • 血条:空轨 + 「0/上限」;行动条位置留白(不画,保持格高不跳)。
  • 常显规则:字库里有带复活的面(BattleEngine.HasRevive 扫字库)→ 平时常显淡态(只画立绘 + 头行,α .5);没有 → 同现状什么都不画。 这样「这里有一只能救」只在你真能救时提醒,平时不添噪音。
  • 选目标 / 拖放 / 召唤选位这些态 → 全量显示(不淡)。

② 复活:签与预演

  • 点选(点了沐「苏」):可救的尸体铺翠玉 10% + 翠玉描环 1.5pt;血条里预演复活血量:翠玉斜纹填到 ⌈上限 × N%⌉,叠字「→ 75/150」(text-main 粗)。
  • 拖放:所有可救尸体挂落点(描环 = 朝上那面的字形色、5% / 9% 墨底,同现有 FaceMark);悬停那只挂预估签 「复活 林 · 生命 75 · 盾反」—— 签会压住头行,所以签里重写字名;本命名作第二段压浅(白 55%)。
  • 复活全部(㵘):悬停任一具,所有可救尸体一起加深(同全体面);签「复活全部 · 2 只」。受存活上限截断时写实际只数。
  • 复活带回什么(Core ReviveAt):字、属性(含嫁接后的)、攻击、生命上限、本命 —— 原样回来;血 = ⌈上限 × N%⌉(沐 50%、㵘 60%;0 = 半血);护盾清零、行动条从 0 攒。 详情弹窗(长按尸体)写全这句:「复活后:生命 75/150,本命盾反照旧;护盾与行动条清零」。
  • ⚠ 请实现方核对:阵亡时身上的状态(格挡 / 战意 / 灼…)是否随死亡清空;若不清,复活会带回,签与详情要改口。

③ 召唤到尸体格

  • 选位:真空位照旧「淡墨块 + 召唤到这里」;尸体格保留身份(立绘 + 头行),chip 行换成一句提示: 「召唤到这里会覆盖它」(wood-fg);字库里有复活字时换成「覆盖后无法复活」(cinnabar-dark)—— 只在真会损失时才警告。
  • 拖生面悬停尸体格:预估签「覆盖 林」,有复活字时接第二段「 · 无法再复活」(压浅)。描环翠玉 / 木字形色同现状。
  • 建议:Core 自动落位已是「先真空位、再尸体」(NextEmptySlot);选位态里空位与尸体的翠玉底同深,文案已区分,不另加层级。
  • 新文案(进字符串表,重跑字体子集):battle.corpse.tag「阵亡」· battle.corpse.overwrite「召唤到这里会覆盖它」· battle.corpse.overwrite_warn「覆盖后无法复活」· battle.estimate.revive「复活 {name} · 生命 {n}」· battle.estimate.revive_all「复活全部 · {n} 只」· battle.landing.overwrite「覆盖 {name}」· battle.landing.overwrite_warn「无法再复活」。
