待拍板的取舍

  • ① 主钮用石青 cta。2026-10-04 推进色由朱砂改为石青,朱砂只表示危险 / 威胁;「确认购买」是这窗唯一的推进项,按新规走石青实底(原稿是墨色 ink)。若把购买算作不可逆,改为朱砂描边钮 Ui.DangerOutline。
  • ② 不可逆怎么说:一行 text-dim 告知「墨锭付出后不退回」,没标红、没上 warn-bg 告警条。规范写的是「标红或告警条」,但这里价格很小、每天都在买,红条会把日常操作说成危险操作;且实现侧本没有正文内标红(见 component/Dialog)。要更重就换成 warn-bg chip。
  • ③ 墨锭不足这一态怎么进来。现在价格钮在墨锭不足时 interactable = false,点了没反应,弹窗根本打不开。要这一态,就得让红价钮可点、点开即本窗(顺带把那条走不到的「买不起」Ui.Alert 换掉)。否则这两块板作废。推荐可点:点红价没反应是哑操作。
  • ④ 墨锭不足时写「还差 N」。10-02 拍板把价格钮上的「差 N 墨」撤了(钮上放不下、读着像催),弹窗里有地方,写出来省得玩家心算。不要就只留余额。
  • ⑤ 箱位写「2 / 4 → 3 / 4」,与余额行同一种「前 → 后」写法;需求原话是「买后箱位 3 / 4」,要那种就改成单值。
  • ⑥ 字卡「新字」口径到不了:墨锭摊位只从已拥有的字里摆(GameRoot.ShopCardPool),新字只出现在紫档广告位,走广告不弹本窗。见「买后效果四种口径」板 ④。
  • ⑦ 字卡「可升」只说凑够了张数:升级本身还要墨锭(MetaRules.InkRequired),买完未必升得起。沿用货架预告口径,不在弹窗里另算升级墨锭;要不要加一行「升级还需 N 墨」由你定。
