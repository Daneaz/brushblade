# shopconfirm/ · 商城确认购买弹窗(2026-10-04 出稿,同日拍板)

现在点价格钮直接成交;改成先弹一张确认窗,把「买到什么、花多少、买完怎样」一次说清。
两种:字摊墨锭摊位的一捆字、右栏「今日补给」的宝箱。外壳走 `Ui.Sheet`(弹窗族,见 `component/Dialog`)。

| 画板 | 内容 |
| --- | --- |
| `Card.dc.html` | 买字卡 · 买得起:货架同款字牌(等级 / 稀有度点 /「2张」/「6折」)+ 字名稀有度 + 一捆张数 + 重复卡前后 + 升级预告 + 价格(折后 + 划线原价)+ 余额前后 |
| `Chest.dc.html` | 买宝箱 · 买得起:箱卡立绘 + 折扣垂旗 + 色点箱名 + 产出(与升级弹窗奖励卡同口径)+ 价格 + 余额 + 箱位前后 |
| `CardPoor.dc.html` | 字卡墨锭不足:价格标 `cinnabar-dark`(与货架价格钮同规则)、余额写现有 +「还差 N」、主钮置灰「墨锭不足」、取消改「知道了」 |
| `Forecast.dc.html` | 字卡「重复卡」一行的四种口径:凑够可升 / 没凑够 / 已满级 / 新字(新字当前到不了) |
| `Notes.dc.html` | 规格(逻辑单位)、屏比验算便签、待拍板的取舍、示例数据 |

尺寸:880×520 逻辑单位(420.45×248.45pt),16:9 最窄档 1354 与基准机 ≈1951 都放得下,验算见 `Notes`。

## 已拍板(2026-10-04,详见 Notes 板)

1. 主钮用石青 `cta`(2026-10-04 推进色改色后由 `ink` 改来);若算不可逆则改朱砂描边。
2. 不可逆只写一行 `text-dim`「墨锭付出后不退回」,不标红、不上告警条。
3. 字卡墨锭不足:红价钮改可点、点开本窗(不足态)。**宝箱墨锭不足前置拦截**:价格钮照旧不可点,不进本窗。
4. 不足时余额旁写「还差 N」(10-02 只从价格钮上撤了这句)。
5. 箱位写「2 / 4 → 3 / 4」而非单值「买后箱位 3 / 4」。
6. 「新字」口径到不了(墨锭摊位只摆已拥有的字,`GameRoot.ShopCardPool`)。
7. 「可升」只说张数凑够,不另算升级还要的墨锭。
