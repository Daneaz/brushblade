## 一个记号贯穿全部界面

所有字**正面都是攻击**,**背面都是五行面**(v6.2):

| | 正面 · 攻击 | 背面 · 五行面 |
| --- | --- | --- |
| 印 | 墨色「攻」印:`ink` 实底 + 白字(`.seal.atk`),五系同一枚 | 本系面印:燃(火)铠(金)润(水)固(土)生(木),`<el>-glyph` 实底 + 白字 |
| 纸 | 纸白(`card-face`) | 本系淡底:手牌用 `<el>-soft`,详情大块用 `--tint`(`<el>-soft` 34% 混 `card-face`) |
| 朝上 | 默认朝上;出手后回到正面 | 点已选中的牌翻过来 |

面印只有一式(实底白字),手牌上不再有主副标记(旧稿的白文副印与折角已撤)。
**两面平等**(v7):不再有主面 / 副面,每一面都有自己的 Lv5 与 Lv8(Lv8 仍叫「招牌」,那一行写「主动 · 招牌」);
Lv1 / Lv3 / Lv4 两面通用,Lv6 写明作用面。一张字共 6 个特性槽,低档字有几条取自词条池,几张字之间会重复 —— 界面不标「池」。

同一枚印出现在手牌、拆合台、详情、升级预览、出手飘字、开局卷轴 —— 玩家只认这一个东西。
不新增 token:`--tint` 是 `<el>-soft` 与 `card-face` 的定比混色(Unity 侧 `Color.Lerp`),
五个值写在 `traits.css`,其上 `text-faint` 4.52–4.63、`text-dim` 5.30–5.44、`<el>-fg` ≥ 6.8,全部过 AA。

**两面都按 100% 结算**(Core 保留 `SideFacePercent` 缺省 100)。

## 已拍板(2026-10-04,spec v6.1 `3e6394a2`、v6.2 `3024245a`、v7 `4960e26b`)

1. **叫法与记号**:特色面 → 五行面;攻击面 → 攻击,统一「攻」记号;焚斩涛震刺五枚攻击面印取消。
2. **翻面手势**:点一下 = 翻面,取代原来的「点已选中的牌 = 出字」;出字走拖出或「出」钮。
   **第一下仍是选中**(拆、弃都要先选中),翻面作用在已选中的那张上 —— 对一张没选中的牌是「点选中,再点翻」。
   ⚠ spec §2.1 只写了「点一下 = 翻面」,实现时按这条细则来(`BattleView.OnLibraryCharClicked` 第二次点击那一支)。
3. **副面暂不打折**:两面都按 100% 结算,稿上去掉全部 60% 标注与折算值。
4. **正面恒为攻击、背面恒为五行面**(v6.2)。
5. **「攻」印用墨色**(v6.2,用户同意)。
6. **两面平等,每面各有 Lv5、Lv8**(v7):取消主面 / 副面,详情页删去「主面 · Lv8 招牌」签;
   等级条 Lv5 / Lv8 格拆两枚记号;升级预览 Lv5 / Lv8 一次展示两条。正面攻击、背面五行面、翻面手势不变。

此前与实现侧确认过的两条:

- **翻面状态**:跟着这张牌直到出手,出手后回到正面(攻击);回合结束不重置。Core 不存翻面状态,出字时由表现层传面。
- **剩余场数**:卷轴上「剩 N 场」含本场,落印后减一;减到 0 显示「用完」。Core 开局生效、战斗结束减一,照稿做即可。
