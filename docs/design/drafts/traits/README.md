## 一个记号贯穿全部界面

一张字两面:**攻击**与**五行面**。每一面一枚方印:

- **五行面**用本系面印:燃(火)· 铠(金)· 润(水)· 固(土)· 生(木),吃该系 `<el>-glyph`。
- **攻击**不分五行,一律一枚「攻」印,墨色(`ink`)—— 与彩色的五行面印一眼分开(v6.1 用户拍板;墨色是稿的取色)。

| | 主面 | 副面 |
| --- | --- | --- |
| 印 | 朱文:实底 + 白字(五行面 `<el>-glyph` 底,「攻」`ink` 底) | 白文:纸底 + 1pt 描边 + 同色字 |
| 纸 | 纸白(`card-face`) | 背面纸:手牌用 `<el>-soft`,详情大块用 `--tint`(`<el>-soft` 34% 混 `card-face`) |
| 手牌另加 | — | 右上折角(9pt 三角,`<el>-glyph`):金系淡底与纸白只差一线,靠它兜底 |

同一枚印出现在手牌、拆合台、详情、升级预览、出手飘字、开局卷轴 —— 玩家只认这一个东西。
不新增 token:`--tint` 是 `<el>-soft` 与 `card-face` 的定比混色(Unity 侧 `Color.Lerp`),
五个值写在 `traits.css`,其上 `text-faint` 4.52–4.63、`text-dim` 5.30–5.44、`<el>-fg` ≥ 6.8,全部过 AA。
「攻」印是 `.seal.atk`:只把 `--glyph` / `--elFg` 换成 `ink`,其余与五行面印同一套。

**两面都按 100% 结算**(v6.1:副面暂不打折,Core 保留 `SideFacePercent` 缺省 100)。稿上不再出现 60%,
标签只写「主面 / 副面」—— 主副仍有意义:主面是默认朝上的那面,Lv8 挂主面、Lv5 挂副面。

## 已拍板(2026-10-04,spec v6.1 提交 `3e6394a2`)

1. **叫法与记号**:特色面 → 五行面;攻击面 → 攻击,统一「攻」记号;焚斩涛震刺五枚攻击面印取消。
2. **翻面手势**:点一下 = 翻面,取代原来的「点已选中的牌 = 出字」;出字走拖出或「出」钮。
   **第一下仍是选中**(拆、弃都要先选中),翻面作用在已选中的那张上 —— 对一张没选中的牌是「点选中,再点翻」。
   ⚠ spec §2.1 只写了「点一下 = 翻面」,实现时按这条细则来(`BattleView.OnLibraryCharClicked` 第二次点击那一支)。
3. **副面暂不打折**:两面都按 100% 结算,稿上去掉全部 60% 标注与折算值。

此前与实现侧确认过的两条:

- **翻面状态**:跟着这张牌直到出手,出手后回到主面;回合结束不重置。Core 不存翻面状态,出字时由表现层传面。
- **剩余场数**:卷轴上「剩 N 场」含本场,落印后减一;减到 0 显示「用完」。Core 开局生效、战斗结束减一,照稿做即可。
