# 升级宝箱 · 主动领取

需求来自 session「角色升级宝箱主动领取」(2026-10-19)。现状:每级宝箱回地图 / 结算时自动塞进空箱位(`LevelRewardRules.GrantLevelChests`),
箱位满就欠着,玩家控制不了时机、也看不清还欠几只。改为:升级只记一只「待领」,玩家在角色页一只一只主动领。
用户已拍板:一只一只领、不做「全部领取」;档位规则不变(Lv.2–5 竹简 · 6–10 青瓷 · 11–20 紫檀 · 21–30 鎏金 · 31–40 朱漆 · 41+ 赤霄)。

底稿是 `../character/` 的 `Character.dc.html` / `LevelUp.dc.html`,本稿只动下面列出的部分;颜色按 `current/` 现状(领取钮、「知道了」、「升 级」用 `cta` 石青)。

## 画板
- `Claim.dc.html`:角色页整屏 + 底部控件切换五种待领状态与「全部待领」弹窗。
- `LevelUp.dc.html`:升级弹窗(一档 + 一条里程碑)。

## 1. 角色页 · 「升级宝箱」领取区
**位置**:左档案栏底部(取代原「待发 N 只」欠箱 chip)。左栏定宽 419、不随屏比变、不在 HScrollFill 里 —— 两档屏宽排版完全相同,不用另算横向。
为腾出纵向空间,封顶说明从栏底两行字收成属性标题行右端的一枚短注「Lv.50 封顶」(`character.cap_note` 改文案;「之后升级只给宝箱与里程碑」由领取区本身说明)。

**纵向验算**(逻辑单位):栏内净高 362.66 − 25×2 ≈ 709(338.8pt)。头像 100 + 经验 ≈ 40 + 属性标题 30 + 属性六行 6×44 + 5×6 = 294 + 领取区 130 + 间距 19×4 = 76 → **670 ≤ 709**,余 39。

**领取区卡**:`OutlinedPanel` `card-face` 底、描边 2(0.96)`panel-border`(有待领时描边换 `cta` 45%)、圆角 17(8.12);内边距 13/15(6/7pt)、竖排 8(3.82)。卡内净宽 = 419 − 50 − 30 = 339(162pt)。
- **标题行** 高 25:「升级宝箱」21(10.03)宋体 `text-main` +「待领 N 只」18(8.60)`cta` 粗 + 弹簧 +「全部 ›」18 `ink-soft`(待领 ≥ 2 才出;命中区撑到 92,点了开「全部待领」弹窗)。
- **队首一行** 高 44:箱立绘 `ChestArt` Idle 42(20pt)+ 箱名 22(10.5)宋体 + 「Lv.N」18 `text-faint` + 弹簧 +「领 取」`Ui.PillButton` `cta` 白字 21(10.03)、高 44(21pt)、最小宽 92(44pt)。
  队首 = **等级最低**的那只(待领按等级升序)。
- **产出行** 高 23:`levelup.chest_yield` 原文 18(8.60)`text-dim`,撑满卡宽。最长「16 种 136 张 · 400 墨 · 12 小时」≈ 297(142pt)≤ 339 ✓。
- 标题行 + 队首行最宽(「待领 3 只」+「全部 ›」/ 赤霄匣 + Lv.41 + 领取钮)都 ≤ 339。

**四种状态**
| 状态 | 画法 |
| --- | --- |
| 无待领(空态) | 标题行只有「升级宝箱」;下面一行:淡化的下一档箱立绘(α .45、去色 60%)+「暂无待领 · 升到 Lv.21 得一只鎏金匣」18 `text-faint`(等级 = 当前 + 1,箱名 = `TierForLevel(L+1)`)。卡描边 `panel-border`。 |

**「全部待领」弹窗**:`Ui.Sheet` 宽 1256(600pt;16:9 无刘海净宽 1354 放得下)、高随行数(最多 5 行,再多在 `ScrollList` 里滚)。
标题「待领升级宝箱」29(14)宋体 + 副标「共 3 只 · 箱位 2 / 4」19 `text-faint` + 关闭钮。每行(高 96 → 46pt,`card-face`、圆角 17):
立绘 75(36pt)→ 箱名 26(12.5)宋体 /「Lv.19 升级所得」18 `text-faint` → 档位 chip「Lv.11–20」(同升级弹窗)→ 产出 20(9.56)`text-dim` → 弹簧 →「领 取」`cta`(高 50、宽 126)。
**弹窗里每只各一颗领取钮、不限顺序**(箱位只剩 1 格时玩家可以挑高档先领);底注:有空位「领取 = 放进一个空箱位(不占暂存位);可按任意顺序领」/ 箱位满「箱位已满 —— 开掉一只再来领,待领的箱子不会作废」。
同屏多颗 `cta`:每行是一个独立决策区,同角色页里程碑「领 取」的口径(一个决策区最多一颗)。
