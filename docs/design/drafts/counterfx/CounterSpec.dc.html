5群攻与连续

· 一击打到多个带格挡的目标(敌人横扫 / 全体):① ② 两拍所有目标同帧;③ 反击线按目标顺序每条错开 0.05 s 发射,数字在攻击者上方纵向错开 12pt。≥ 3 条合并成一个「反击 ×3 · 147」(最后一条命中时出)。
· 连续多只敌人:每只仍是一个步距,格挡反击在步内打完,不额外插停顿。
· 多段反击(一次格挡打 hits 下):线每段间隔 0.08 s,数字逐段飘、同样错开 12pt;≥ 3 段合并。
· 反击被 60% 反伤预算削到 0 / 攻击者已死:只演 ① ②,不射线、不飘「反击 0」。
· 按住加速:上表全部时长 ÷ 倍率(Beat / Dt);顿帧也 ÷ 倍率 —— ×3 时 0.018 / 0.03 / 0.075 变成 6 / 10 / 25 ms,手感仍在但不拖。飘字寿命同样 ÷ 倍率。

7实现需要

Core 事件:现在格挡只体现为「EnemyAttack 掉血少了」+ 之后若干条 Source = BlockCounter 的伤害;反击被削到 0 或攻击者已死时表现层根本不知道这次挡过。建议加一条 BattleEventKind.BlockUsed(TargetIndex = 攻击者,SecondIndex = 木灵格 / −1 玩家,Amount = 剩余次数),发在 EnemyAttack 之后、反击伤害之前;反击伤害的事件上带「是否吃了 CounterBoost」(或表现层读 CounterBoost 状态)。
文案(字符串表):juice.popup.source.block_counter =「反击 {amount}」;合并 =「反击 ×{n} · {amount}」;角签「×2」/「+{pct}%」。改后重跑字体子集。
图标:不需要新图标 —— 盾印用 block,加倍角签用 riposte。半弧 / 反击线 / 外扩环是程序画的(Theme.RoundedRing 与拉伸的圆角条)。
与代码口径的差异:代码里格挡是「减伤 40% + 反击」,不是整击抵掉;稿按代码演(伤害数照出,只是更小)。若机制要改成整击抵掉,① 拍的伤害数换成「挡」字即可,其余不变。
