⚠ 这里的「反击」是 `DamageSource.BlockCounter`(格挡反击),与 Juice 的 `Countered`(五行被克)无关,不复用它的褪色 / 内收环。

## 三拍(1×,以敌人扑击命中为 0)

1. **挡**(0–0.30):格挡 chip 的 `block` 图标放大成 22pt 铜绿(`jade`)盾印压在受击者中心,0.07 s easeOutBack 到 1.15;
   34pt 朝敌半弧 0.18 s 外扩淡出。受击者后坐 0.45、**不白闪**、震屏 ×0.45;伤害数 0.78 倍挪到头顶偏右;顿帧 0.018。
2. **扣**(0.06 起):受击者自己那枚格挡 chip 载体闪 0.45 s + 次数跳格 0.16 s easeOutCubic;扣到 0 → chip 缩没 0.18 s。
3. **反**(0.16 起):`metal-glyph` 3pt 一划从受击者射向攻击者,0.12 s easeInQuad;0.28 s 命中:后坐 0.6 + 外扩环 + 顿帧 0.03 +「反击 N」。

全部落在现有敌方步距 0.42 s 之内,不加时长;下一只敌人起点 = max(0.42, 末次反击命中 + 0.10)。

## 情形

- 落点玩家 / 木灵:盾印、chip、线的起点都跟着受击者走;木灵不震屏(同现状)。
- **反击加倍**:0.12 s 先闪玩家身上的 `riposte` chip;线换 `gold` 5pt 带晕、环加粗;数字 `gold-deep` 14pt +「×2」角签;顿帧 0.075 + 小震屏。
- 群攻同挡:①② 同帧,③ 每条错开 0.05 s,数字纵向错开 12pt,≥3 条合并「反击 ×3 · N」。多段反击每段 0.08 s。
- 反击被 60% 预算削到 0 / 攻击者已死:只演 ①②。
- 按住加速:全部时长、顿帧、飘字寿命 ÷ 倍率。
