# 格挡反击 · 动效(2026-10-15 出稿,`已落地`)

需求来自 session `card-ability-system-redesign`(用户提出:反击现在只飘数字,看不出是格挡触发的)。
画板:`CounterFx`(可播放,可切倍速 ×1/×2/×3 与屏宽 基准 / 16:9)、`CounterSpec`(规格)。
本地看:在 `docs/design/` 下 `python3 -m http.server`,开 `_preview/canvas-counterfx.html`。

⚠ 这里的「反击」是 `DamageSource.BlockCounter`(格挡反击),与 Juice 的 `Countered`(五行被克)无关,不复用它的褪色 / 内收环。

## 三拍(1×,以敌人扑击命中为 0)

1. **挡**(0–0.30):格挡 chip 的 `block` 图标放大成 22pt 铜绿(`jade`)盾印压在受击者中心,0.07 s easeOutBack 到 1.15;
   34pt 朝敌半弧 0.18 s 外扩淡出。受击者后坐 0.45、**不白闪**、震屏 ×0.45;伤害数 0.78 倍挪到头顶偏右;顿帧 0.018。
2. **扣**(0.06 起):受击者自己那枚格挡 chip 载体闪 0.45 s + 次数跳格 0.16 s easeOutCubic;扣到 0 → chip 缩没 0.18 s。
3. **反**(0.16 起):`metal-glyph` 3pt 一划从受击者射向攻击者,0.12 s easeInQuad;0.28 s 命中:后坐 0.6 + 外扩环 + 顿帧 0.03 +「反击 N」。

全部落在现有敌方步距 0.42 s 之内,不加时长;下一只敌人起点 = max(0.42, 末次反击命中 + 0.10)。

## 情形

- 落点玩家 / 木灵:盾印、chip、线的起点都跟着受击者走;木灵不震屏(同现状)。
- **反击加倍**:0.12 s 先闪玩家身上的 `riposte` chip;线换 `gold` 5pt 带晕、环加粗;数字 `gold-deep` 14pt +「×2」角签;顿帧 0.075 + 小震屏。
- 群攻同挡:①② 同帧,③ 每条错开 0.05 s,数字纵向错开 12pt,≥3 条合并「反击 ×3 · N」。多段反击每段 0.08 s。
- 反击被 60% 预算削到 0 / 攻击者已死:只演 ①②。
- 按住加速:全部时长、顿帧、飘字寿命 ÷ 倍率。

## 出画

反击数锚攻击者立绘中心上 14pt、升 18pt,夹 y ≥ 16、x 在安全区内减半宽;后排怪与最右列在基准 932 / 16:9 764 两档都验过。

## 实现需要

- Core:建议加 `BattleEventKind.BlockUsed`(攻击者、木灵格 / −1、剩余次数),否则反击为 0 时表现层不知道挡过。
- 文案:`juice.popup.source.block_counter`「反击 {amount}」、合并「反击 ×{n} · {amount}」、角签「×2」;重跑字体子集。
- 图标:无新增(`block`、`riposte` 复用);半弧 / 线 / 环程序绘制。
- 口径:代码里格挡是「减伤 40% + 反击」不是整击抵掉,稿按代码演。

## 回填记录

2026-10-15 实现(分支 `feat/counterfx`):Core 加 `BattleEventKind.BlockUsed`(末尾追加,玩家侧紧跟 EnemyAttack、木灵侧紧跟 SummonHit / EndureSaved,
反击伤害之前;反击为 0 / 攻击者已死照发);表现在 `Presentation/JuiceCounter.cs`,`Juice.ApplyBatch` 的 EnemyAttack / SummonHit / BlockUsed /
Damage(BlockCounter)四处接线。时长、尺寸、颜色、文案按稿;与稿的差异:

- **群攻 ①② 不同帧、③ 不错开 0.05** · 为什么:Core 里一击打多个目标的只有首领横扫类大招,现有 Juice 对每个受击目标本来就逐个串行(各隔 StepGap)演,
  改成同帧要动首领大招的既有节拍,超出本稿范围。于是每个目标的格挡各自在自己那一步里演完三拍;「≥3 条合并」按**单次格挡**后跟的反击条数
  (多段 / 贯穿)计,跨目标不合并。
- **chip 闪、震屏、被挡伤害数不随按住加速缩短** · 为什么:三者沿用现有件(TriggerFx 载体闪 0.45s、`Shake`、`Popup` 0.7s 曲线),它们走真实时间;
  本稿新画的盾印、半弧、跳格 / 缩没、反击线、命中环、反击数、受击 / 攻击者后坐与三档顿帧都已 ÷ 倍率。被挡伤害数的上浮也是 `Popup` 原曲线,不是稿上的 lb 曲线。
- **加倍 chip 闪的位置** · 为什么:代码现状里反击加倍 chip 画在**持有格挡者**的状态行(玩家行只在玩家自己有格挡时才画)。木灵格挡 + 加倍时闪木灵行那枚,
  玩家行若也有就一起闪。
- **玩家被挡时不闪屏缘** · 为什么:玩家侧没有立绘白闪,对应「不白闪」的是受击屏缘那一下属性色微闪,一并去掉。
- 盾印没画稿上的 1px/4px 投影(只有 1.5pt 纸色描边);命中也用金属声(`_hitClip` pitch 1.25)。木灵立绘自带的受击抖动(`SummonView.PlayHit`)保留。
