② 改了什么(相对现状 4 × 2)

  • 格宽 293 → 396(16:9:214.5 → 292)。16:9 的新格宽 ≈ 旧基准机格宽,所以立绘两档都不再缩(删 FieldScale 对敌人立绘的缩放)。

  • 前排敌人 chip 2 → 3 行(头行 24 + 3×20 + 2×3 + 血 19 + 行动 6 + 间距 4×3 = 127 ≤ 138)。后排 109 只够 2 行,召唤格 2 / 1 行沿用。

  • 召唤槽顺序:前排 中 → 左 → 右,再后排 中 → 左 → 右;解锁层 1 / 7 / 13 / 19 / 25 / 31。
  • Boss / 精英 / 头领 = 一列竖块(中列),见 ③;随从 / 小怪占左右两列共 4 格。
  • 16:9 后排召唤只放得下 攻 / 甲 + 1~2 枚,其余收「+N」(纵向只有 88,无法加行;现状 16:9 信息列 127 更紧,这一格是改善不是退步)。
