`docs/superpowers/specs/2026-10-18-群攻入口与头领编组-design.md` §2 / §5 / §6,现状卡 `../../current/BattleScreen/`。

## 画板
- `Battle3x2.dc.html`:整屏,四种局面(普通层满 6 只 / 头领层 / Boss 层 / 精英层)× 两档屏宽,可开尺寸标注。
  格宽、chip 宽、排行与「+N」截断全部由 `grid.js` 按 `Ui.ChipWidth` / `Ui.ChipFlow` 的同一套公式算出,
  画面上看到的收行就是实现会收的行。
- `GridSpec.dc.html`:两档逐栏验算表、改动清单、竖块解剖、档位签、头领立绘画幅、实现要改的常量。
