## 回填(稿不成立,改了实现与稿不同的值)

前三条(格距 / 保底栏行距 / 三选一卡高)原先只记了账、稿没改,2026-10-04 一并改进稿里。

- **2026-10-04 · 角色页里程碑轨道格距 13 → 8**:「X字 3 选 1」一行实算要 99.9 逻辑单位,格内净宽只有 98.6,
  Unity `Text` 不折行会探出卡边。格距取 `space-4`(4pt = 8 逻辑单位)后净宽 103.1。
- **2026-10-04 · 角色页保底栏行距 15 → 8、「3 / 5」布局高压到 30**:三块首选高合计 333 > 页面区 304,
  uGUI 会按比例压扁。改后 287;数字照常居中显示。
- **2026-10-04 · 里程碑三选一卡高 745 → 785、行距 21 → 14**:按字体真实行高(宋体 1.437 / 黑体 1.448)
  实算需要 752 > 净高 684,候选牌会被压成横向偏胖。牌尺寸与 0.8 比例不动;改后需要 710、可用 724。

以上三条都是按 932pt 宽屏算的。1600×900(16:9)下右栏只剩约 914 逻辑单位(932pt 基准下 1265),
里程碑卡与统计栏都会溢出 —— 2026-10-04 用户拍板:右栏(里程碑 + 统计)改成横向滚动区,不足 1265 时按 1265 排、横向滚出来(`Ui.HScrollFill`)。
