## 需求来源

- session confident-proskuriakova(2026-10-20)转用户原话:「在 setting 中新增开关,快速施法,选中我方为五行面,选中敌方为攻击面,开启后无需提前翻转」。
- spec:`docs/superpowers/specs/2026-10-20-快速施法-design.md` §1 行为、§3 表现层、§4 设计稿。
- 现状参照:`SettingsView.cs`(760×560 面板)、`current/BattleScreen`(3×2 战场、落点描环、预估签、底部提示行)、
  `drafts/traits` 的 HandFlip / FlipSpec(落点描环色 = 那一面的面印色,攻击面墨)。

## 方案要点

1. **设置页**:在「背景音乐」下面加第三行,走现成 `ToggleRow(title, desc, …)` 带说明行(行高 78)。缺省关,即改即存。
2. **两侧同时点亮**:敌方侧按攻击面点亮(墨环)、我方侧按五行面点亮(本系字形色环)。描环色规则不变(=该侧那一面的面印色,
   `Ui.FaceSealColor`),只是两侧各取各的面;底色、粗细、悬停加深、预估签、「召唤到这里」全部沿用现状。**不新增颜色**。
   「溃」Lv5+ 敌方侧两面都能落 → 按朝上的面(五行面朝上时两侧同一面、同一色)。
3. **跟手牌随悬停侧翻面(★ 新增,建议做)**:拖起的那张牌悬停到哪一侧就翻成那一侧会出的面(面印 + 五行面淡底),
   离开落点回到朝上的面;两侧同面时不翻。颜色之外再给一层「这下出的是哪一面」的冗余。缩短版翻面动效 scaleX 0.14s。
4. **提示文案**:拖拽提示、选中后缀、拆合台提示、长按详情脚注各加一条快速施法版;再点 / 点「出」后的双向点选态沿用现成
   `pick_dual_target` / `pick_dual_summon`,不新增。
5. **切换条件**:只在「开快速施法 且 两侧都有落点 且 两侧的面不同」时用快速施法版文案;单面字、部件池、教程锁面、
   「溃」五行面朝上、我方侧当下无落点 → 原文。

## 需要拍板的取舍

1. **跟手牌随悬停侧翻面**:建议做(颜色之外的第二层提示,实现量是拖拽期间换一次面印 + 底色)。不做也成立,
   只靠两色描环 + 悬停预估签。
2. **「溃」Lv5+ 的文案口径**:提示统一写「敌方用攻击面」,而「溃」五行面朝上时敌方侧其实出五行面。稿里的处理是这时两侧同面 →
   退回原文提示;选中后缀仍写「敌方用攻击面」(全字表只此一张、且只在五行面朝上时不准)。可接受,或给它单出一条后缀。
3. **开关位置**:放在音效 / 音乐之后(最后一行)。如果希望更显眼可放第一行,纵向预算不变。
