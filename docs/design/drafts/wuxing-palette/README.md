# 五行配色 · 金土分家

需求(2026-10-19,session「角色升级宝箱主动领取」转用户):「当前五行的颜色,土系和金系很接近,一时间无法通过颜色区分」。
旧色板里金(#B3A381 卡其金)与土(#8F7332 赭)同是黄褐:主色 ΔE 26、淡底 ΔE 7、字形 ΔE 23。

## 方案(用户审后从简:只拉开金和土)
- **金 → 古金**:金黄,取偏暗一档,让主色上的白字过 4.5。
  选它而不选「金主色改深字」:后者要把所有「主色底 + 白字」的地方(属性 chip、元件、同源徽标、战场徽章…)按系改字色,是代码改动;古金只换 token 值,代码一行不动。
- **土 → 红褐**:明显更深、更红。
- 木、水、火不动。
