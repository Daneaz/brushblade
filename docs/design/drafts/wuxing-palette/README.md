# 五行配色 · 金土分家

需求(2026-10-19,session「角色升级宝箱主动领取」转用户):「当前五行的颜色,土系和金系很接近,一时间无法通过颜色区分」。
旧色板里金(#B3A381 卡其金)与土(#8F7332 赭)同是黄褐,主色 ΔE 26、淡底 ΔE 7、字形 ΔE 23。

## 方案
- **金 → 铁青钢色**(冷、低饱和、带一点青):五行古意「金白」,也和牌框锋光已在用的冷钢 `#5B6B7A` 同族。带青是为了躲开 UI 的中性色(`neutral-part`、`ink-soft`、`locked-bg`),不让金看起来像「无属性 / 禁用」。
- **土 → 土黄**(去掉红褐,更黄):五行「土黄」,同时把土字形色从红褐 #82552A 挪开,和火的字形色拉开。
- **木主色压深一档** #348F4F → #2E8449:原值白字只有 4.05,不达 4.5 的约束(顺手修)。
- 水、火不动(火与 `cinnabar` 同值,是危险色,不宜动)。

## 可分性(ΔE,CIE76;色觉 Machado 2009 严重度 1.0)
- 金 / 土:主色 26 → **62**、淡底 7 → **30**、字形 23 → **54**;绿弱 / 红弱下同样 ≥ 29。
- 火 / 土:主色 53 → 57、字形 38 → 50(常规);**绿弱下主色 1 → 11、字形 5 → 11 —— 仍难分**。
- 代价:淡底 金 / 水 27 → 13、金 / 木 14 → 13。淡底五系都是浅色,ΔE 天然小;淡底永远和深前景字一起出现(部件方块的「钅 / 氵」),字层 金 / 水 ΔE 35 可分。

## 色弱
木 / 火 / 土在红绿色弱下只剩明度差,不动火就救不回来。现有缓解是属性徽章、chip、相克图都写着「金木水火土」字。
后续可选(本稿不做):a. 部件方块与字牌角加 6pt 五行小纹;b. 设置页「色弱辅助」开关(面印与部件方块改「色 + 字」双编码);c. 牌框光效元件(锋光 / 尘石)已按系分形状,可当字牌第二通道。
