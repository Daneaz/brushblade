③ 色弱下的结论与辅助手段(后续选项)

  • 金 / 土:新色板在三种色觉下都 ≥ 50,问题解决。
  • 木 / 火 / 土在红绿色弱下仍会挤成一团橄榄色(火 / 土主色绿弱 ΔE 1 → 11):红、绿、黄在这类色觉里只剩明度差,任何不动火的方案都救不回来;火又和 cinnabar(危险色)同值,不宜动。
  • 现有缓解:战场属性徽章、属性 chip、相克图本来就写着「金木水火土」字,不靠颜色。
  • 后续可选(本稿不做,需要时另出稿):
    a. 部件池方块与字牌角落加一枚 6pt 的五行小纹(金 = 斜线锋、木 = 竖纹、水 = 波、火 = 焰尖、土 = 横层);
    b. 设置页加「色弱辅助」开关:打开后五行面印与部件方块改为「色 + 字」双编码;
    c. 牌框光效元件(CardFrameView 的锋光 / 尘石)已按系区分形状,可作为字牌上的第二通道。
