技能页整屏（932×430pt 横屏）：一张 1220 见方的环形星域画布，屏幕只是它的视口，默认缩放 0.7；对应实现 `PerkView.cs` + `PerkLayout.cs`。

## 版面
- **43 个节点分四类**：五行 5 枝 × 4 层 = 20、被动 4 枝 × 3 层 = 12、机制 4 枝 × 2 层 = 8、跨树 3。跨树不是第四棵树 —— 它的三个节点 `Depth` 恒为 1、不在任何一条直链上，前置走显式谓词。
- 画布满屏铺开（不套卡片），顶栏浮在画布之上，底下垫两层半透明宣纸渐隐，免得节点滑到标题后面糊成一团。顶栏与其余外层页同款，多一行手势提示「双指缩放 · 拖动平移」。
- 中心「斗」→ 半径 100 处三个树根 → 各枝向外。五行占上半圈（180°–360°），被动占右下（0°–108°），机制占左下（108°–180°）；三棵树第一圈半径不同（190 / 200 / 280），最外层共用 475。
- 跨树三节点在半径 545：相济、博采并排在五行正上方（262° / 278°），融会在机制扇区中线外沿（144°）。不画连线，只画虚线环。
- 右下角圆形缩略图（156）：43 个点（已点亮用枝色，其余 `paper-dim`）+ 朱砂视口框。

## 没有的东西
没有页签、跳转胶囊、状态图例（2026-09-08 定：DAG 本身一目了然）。点任意节点先开详情弹窗，解锁动作在弹窗里 —— 单次不可撤销地花几百到几千墨锭，卡面误触代价太高。

## 详情弹窗（`PerkNodeSheet.cs`）
点任意节点 —— 五种状态一律 —— 从**右缘推出一张 396 宽、上下铺满**的宣纸卡，遮罩只盖左边那块画布，正在看的那一片仍然看得见（原先是 620×700 居中弹窗，画布能平移之后居中会把视线整个挡住）。内容区净宽 345。

自上而下：
- **头部**（高 150）：枝色浅底 `--soft`，右下角一个 88 的代表字水印（枝主色 16% alpha；五行取系名「金/木/水/火/土」，其余取枝名首字）。上面叠面包屑 13 `text-dim`（`{树} · {枝} · 第N层`；跨树没有层，只印 `{树} · {枝}`）、节点名 30 宋体，右侧两枚 chip：「专属」**只给五行树**，「Lv.{门槛}」五态都挂。
- **效果**（18 `text-main`）+ **说明**（15 `text-dim`）两段，段标题 14 宋体 `text-dim`。效果是一句机械描述，说明是「这条实际意味着什么」。
- **数值构成**：只有三个跨树节点有（它们是缩放器）。三行 —— 基础 / 已点亮 N 个 → +M / 合计，16 / 16 / 17。计数为 0 时中间那行换成「再深一层就涨」的灰字提示，不印「+0」。
- **前置链 / 跨树前置**：普通节点画一排直径 34 的圆点（已点 = 主色实心 + ✓、当前 = 空心 + 主色粗描边、未点 = `locked-bg`），下面挂节点名 12。跨树节点换一套画法 —— 两格竖排（每格高 62、间距 10）逐条列谓词与满足度，「还差 N 个（x/y）」。
- **解锁条件**：两栏等分（高 68，`panel-inset` 圆角 12），角色等级与墨锭**各自判、各自标还差多少**：达标 `done-green`、未达标 `exit-pink`。
- **底部**（高 56，在滚动区之外、永远贴底可点）：主钮 + 「×」关闭钮（120 宽）。主钮**只有可解锁时可按**，其余四态置灰并写明原因，五档文案 = 已点亮 / 解锁 · {cost}墨 / 墨锭不足（还需 N 墨）/ 需先点上一层（跨树换成「需两侧前置」）/ 需角色 N 级。

内容整段走滚动区：普通节点占 553~593、跨树多出「数值构成」「跨树前置」两段占 795~837，而内容区净高只有 779 —— 两头都不对，靠滚动一次解决。
